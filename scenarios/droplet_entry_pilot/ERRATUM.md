# ERRATUM — MP-DROP-0 先导观察量勘误（2026-10-25）

适用范围：本目录 `outputs/verdict.json`、`outputs/observables_lbm.json`、
`outputs/observables_sph.json`（v1 抽取器产物）及其入库报告（平台报告 id=59，
PR #54）。**FAIL 判决方向维持且证据升级（场级），但 v1 的全部定量对比数字撤回。**

## 撤回的数字（v1 → 判定）

| v1 数字 | 判定 | 依据 |
|---|---|---|
| 穿透深度误差 85–98%（4 marker） | **度量无效，撤回** | LBM `drop_mask` 阈值用逐帧全场 max（≈0.6），整个水池（均值 0.8）被选为"液滴"，"穿透深度"实为全池质心位移 5.4–8.1D，而水池总深仅 8D——物理上不可能的穿透 |
| "LBM t*≈0.8 前已融合" | **运动学不可能，撤回** | 液滴底缘初始高度 12 格、u0=0.01、g=5e-5 → 运动学接触 t*=0.921；t*=0.8 时液滴尚未接触水面 |
| 形状比 λ 对比（含 SPH t*=1.5 的 8.69） | **度量无效，撤回** | SPH `y>pool_depth` 每帧掩膜把两侧水舌粒子误标为液滴（t*≈3 峰值时 4.6% 全域粒子在水面以上） |
| marker 时刻 {0.5,1.0,1.5,2.0} 有效 | **部分无效** | LBM 接触 t*=0.921 → 前两个 marker 在接触前；SPH 接触 t*=1.050 → 前两个 marker 在接触前 |

## 场级证据（FAIL 方向的更强依据）

对全部 10 帧 LBM 快照的分区统计（水组分 ρ_water）：

- 水池深处均值自 0.8 漂移至 0.40–0.77，不再回稳；
- 气相监测框（右上角，远离液滴路径）均值自 0.04 升至 0.55（14×）——
  水组分污染整个气相，16 格/直径下 Color-Gradient 界面扩散失控；
- 液滴初始盘区均值序列 0.50 → {0.43, 0.45, 0.30, 0.54, 0.11, 0.33, 0.05, 0.04, 0.06}，
  t*≈1.3 后液滴结构消散，全程无凹坑/水舌成形。

结论：该配置下 LBM 场不可用，观察量未定义——这不是"液滴行为与 SPH 不一致"，
而是"液滴从未被该求解器在该分辨率下正确模拟"。

## 修复（本 PR）

`extract_observables.py` v2：

1. LBM 液滴 = 配置常数阈值 + 初始水面以上区域 + 初始液滴 x 邻带；
2. **气相纯度门**：右上监测框均值峰值 > 0.25×界面阈值 → 全部观察量
   `valid=false` 并给出量化理由（本数据集实测 0.544 > 0.150，触发）；
3. **运动学接触自检**：`config.u0`（`run_lbm.py` 已补记录；旧工件可用
   `--u0 0.01` 回溯）解 gap=u0·t+g·t²/2 → t*=0.921；每个 marker 标注
   pre/post-contact；
4. **物理上界护栏**：|d/D| 超水池深度+1D 即判 mask 语义破裂（v1 的 8D 值
   会被此护栏当场拦下）；
5. SPH 液滴 = 首帧 `y>pool_depth+dx` 索引块（实测 [32768, 33567]，800 粒子）
   全程追踪，不因没入而丢失、不误纳水舌；穿透深度统一以水面为零点向下为正。

v2 对既有工件的重抽取结果（`outputs/observables_*.v2.json`，随本 PR 入库）：

- LBM：contact_t*=0.921（kinematic）；field_pure=False（0.544>0.150）；
  全部 marker d/D=null（观察量未定义，理由量化入 JSON）；
- SPH：contact_t*=1.050；t*=1.5/2.0 d/D=−0.075/+0.183（质心相对水面，
  接触前 marker 如实标注无效）。

Shan-Chen 或重构 CG + ≥32 格/直径（Latva-Kokko & Rothman 2005）+ 与 SPH

marker 窗放在运动学接触之后 + 报告图跨帧比较必须固定色标。
