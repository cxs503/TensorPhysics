## 规则 1：船体梁尺度的"移动载荷共振"不可能来自经典 `V_cr = ω_n L/(nπ)`

- **机制**：`ω_n L/π` 与 `L` 成正比、与 `f_n` 成正比。150 m 船 `f₁ = 1.2 Hz` 时
  `V_cr = 360 m/s`（本算例简支参考梁 158.8 m/s），远高于任何航速 ⇒ 5 m/s 下准静态
  （实测 DAF = 1.030）。
- **正确做法**：航速相关的共振必须由**接触重复频率**提供：`f_ice = V/s`，`V_cr = s·f_n`。
  先由 `s`（浮冰/冰脊间距）反推 `V_cr`，再判断任务给定航速是否落在共振点。
- **反例**：直接把 5 m/s 当成 `V/V_cr = 1.0`（把经典临界速度当船速）会得到一个既非共振、
  又没有物理量级的结果；本算例把 `s = 4.13 m` 显式设计成 `V_cr ≈ 4.96 m/s` 并写明二者区别。

## 规则 2：`FNV = a/(g f)` 的加速度必须与除数**同频同源（窄带）**

- **机制**：碎冰冲击是宽带激励，`max|ü(t)|` 由多个模态的高频振铃叠加，与"主导频率"不同源；
  相除等于拿高频抖动除以低频，指标失去意义。
- **做法**：`f_dom` 取稳态窗加速度谱最大峰；`a_band` 在 `f_dom` 上做 Hann 加权
  `A cos + B sin` 最小二乘幅值。**同时输出** `FNV_raw`（字面口径）作透明对照。
- **量级**：本算例 `FNV_raw / FNV` = 1.3–6.7（离共振越远差距越大）。
- **回归守卫**：`tests/test_ice_moving_load_fnv.py::test_dominant_frequency_recovers_sine_and_band_amplitude`
  （纯正弦幅值恢复误差 <1 %）与 `test_fnv_value_and_tiers`（分档边界）。

## 规则 3：自由-自由梁的"中点静力挠度"不是 `PL³/(48EI)`

- **机制**：`PL³/(48EI)` 是简支边界下的跨中相对挠度；自由-自由梁的弹性模态投影量是另一回事
  （本算例 0.0321 m ≈ 0.46 × `PL³/(48EI)` = 0.0703 m，因刚体模态被剔除）。
- **做法**：静力判据（A1）固定在简支配置；自由-自由的"动力放大因子"分母用同一模态基下的
  静态投影量，并在报告里写明，避免与简支基准混用。

## 规则 4：单力穿越的**阶跃起始**会伪造出 1.5 倍"动力放大"

- **现象**：`t=0` 把满值载荷瞬间放上梁，阶跃振铃在 `ζ = 0.5 %` 时衰减 26 s，
  峰值可达静态的 1.5 倍，与"移动载荷共振"完全无关（本算例 `run_moving_point_load` 直接中招，
  DAF 假值 1.497；改用闭式解后真值 1.030）。
- **做法**：低阻尼 + 短的穿越时间时，不要用时域单次穿越去论证"准静力/共振"；
  用闭式解或让载荷有有限上升时间。

## 规则 5：本机 `scipy.linalg.eigh(K, M)` 在数十阶矩阵上**段错误**，用 Cholesky 白化替代

- **现象**：42×42 广义对称特征值问题直接 SIGSEGV（`eigvals_only=True` 亦然），
  而 `numpy.linalg.eigh` 与 `scipy` 小规模调用正常 ⇒ 镜像内 LAPACK 广义驱动缺陷。
- **做法**（结果与解析一致到 <1e-6）：
  ```python
  chol = np.linalg.cholesky(M)
  lam = np.sort(np.linalg.eigvalsh(0.5 * (A + A.T)))      # A = L^{-1} K L^{-T}
  ```
- **回归守卫**：`tests/test_ice_moving_load_fnv.py::test_free_free_frequencies_match_beam_fem`
  （解析 vs Hermite 梁 FE，三阶误差 <1 %，实测 <1e-6）——若谁换回坏驱动，该测试会崩而不是静默。

## 附：可复用的实现要点

- 模态基容器（`ω_n, m_n, k_n = m_nω_n², c_n = 2ζ_nω_nm_n` + 振型/曲率求值器）能让下游与支承
  条件解耦；写新结构动力学模块时优先复用它。
- 模态空间对角化后，能量四分量（输入功/应变能/动能/阻尼耗散）逐时间步可算，A4 类守恒判据
  残差自然到 1e-6 量级（Newmark + 梯形积分，`dt` 二阶收敛）；这是最便宜的正确性守卫。
- 冰载荷相干性决定共振能否建立：浮冰长度 `cv = 35 %` 使 FNV 从 1.17 掉到 0.24。
  凡报告"冰致共振"必须同时交代间距规整度，否则结论不可复现。
