## 1. 案例介绍（物理背景 / 几何 / 参数）

纵向加筋板架在总纵弯曲下受压侧的渐进崩溃（Smith 1977 方法）由三类能力竞争：板格局部屈曲
后的有效宽度丧失、筋材柱屈曲-屈服交互、以及两者在同一缩短量下的并联装配。本节点的基准
板格为典型内底板：

| 参数 | 符号 | 值 |
|---|---|---|
| 横向框架间距（柱长） | a | 2.400 m |
| 筋距 | b | 0.700 m |
| 板厚 | t | 12.0 mm |
| 腹板高/厚 | h_s / t_w | 200 / 10 mm |
| 翼板宽/厚 | b_f / t_f | 100 / 15 mm |
| 材料 | E, ν, σ_y0, H | 206 GPa, 0.3, 313 MPa, 1.0 GPa |
| 板格柔度 | β = (b/t)√(σ_y0/E) | **2.274**（Faulkner Φ = 0.686） |

模型常数（声明值，未对标定）：残余应力因子 0.15、峰后软化斜率 0.05E、初始挠度 a/1000、
冰带压力律 P₀ = 1.0 MPa @ A₀ = 0.5 m²、指数 −0.3。

## 2. 怎么做的（方法 / 关键设置）

1. **本构（von Mises + 线性各向同性硬化 σ_y = σ_y0 + H ε̄_p）**
   * 一维闭式解 `uniaxial_closed_form`（弹性段 / 硬化段，返回 dσ/dε）；
   * **独立**增量积分器 `uniaxial_incremental`（1-D 径向返回，按状态推进）；
   * 三维径向返回 `j2_return_mapping` + **一致切线** `j2_consistent_tangent`
     （Simo & Taylor 1986 闭式：`C = K1⊗1 + 2μβI_dev − 2μγ n⊗n`）。切线的正确性由
     **返回映射自身中心差分**判据（这就是 "consistent" 的定义），不是自证。
2. **板架 collapse（Smith + 弹塑性单元曲线）**：等应变并联装配。
   * 板单元：弹性板屈曲 σ_cr = kπ²D/(b²t)（k=4）→ von Karman 后屈曲支
     σ_avg = √(σ_cr·σ_edge)，其中 σ_edge 用**含硬化的弹塑性应力**（硬化抬高平台）→
     Faulkner 极限 Φ·σ_y,current·(1−0.15) → 声明软化支；
   * 筋单元：**Perry-Robertson 弹塑性柱**（σ_u = ½[σ_y+σ_E(1+η) − √(…²−4σ_yσ_E)]），
     η = δ₀c/r²，即屈曲-屈服交互；
   * 沿应变路径积分到峰值 → σ_u、ε_u、峰后比、切线模量。
3. **基准（Paik & Thayamballi 2003 简化法）**：按第 5 章「单元刚性塑性求和」独立实现
   （Faulkner 板极限 + Johnson-Ostenfeld 弹塑性柱），**不依赖**上面的纤维求解器。
   注意：其经验闭式极限强度公式**未使用**，因离线无原文（WITHHELD），绝不凭记忆抄系数
   —— 基准为方法级（method-level），报告已声明。
4. **板弹性屈曲**：Timoshenko 闭式 k(m)=(mb/a+a/(mb))² 对比**独立**有限差分特征值解
   （13 点双调和模板 + 中心差分几何项，简支边用**奇延拓虚拟行**保证 w=0 与零弯矩），
   三级网格 + Richardson 外推。
5. **IACS 冰带压力-面积律**：P = P₀(A/A₀)^−0.3，并用对数-对数最小二乘做**反问题**
   （指数可辨识性：干净样本 = 实现自一致；5% 对数正态扰动 = 指数在噪声下的稳定性）。

## 5. 注意点（踩过的坑 / 局限）

* **`scipy.linalg.eigh(a, b)` 在本环境直接段错误**（LAPACK `?sygv` / BLAS 崩溃）→ 改用
  Cholesky 白化 + `numpy.linalg.eigvalsh`，并记录在模块 docstring 里。
* **简支边虚拟行必须做奇延拓**（w₋₁ = −w₁）；直接丢掉越界点会把特征值抬高 9.6%，
  且会让一阶模态竞争错位（本节点实测 375 MPa vs 218.9 MPa）。
* 一致切线的 **shear 列因子 2**：应变 6 向量用张量剪切分量时，扰动 ε_kl 同时进入 (k,l) 与
  (l,k)，Jacobian 列需乘 2；gamma 项在本模块 ε̄_p = √(2/3)·1.5Δγ 的归一化下为
  `2μ/(2μ+H) − (1−β)`（不是文献里 f=√(3/2)‖s‖−σ_y 归一化的 `1/(1+H/3μ)`）。
* **Faulkner 公式在 β<1 变负**（原始经验式只拟合 β≥1）；已钳到 Φ=1，否则 stocky 板格
  会给负极限（本次即由负控测试抓出）。
* 局限：本模型是 Smith 纤维模型，单元曲线均为已发表闭式 → 三层壳单元级别的膜应力重分布、
  筋材 tripping/LTB 不在此验证面（tripping 见 N03 的 `tripping_mode`）；Paik 基准是方法级
  （非试验、非经验闭式）；IACS/ISO 条文 WITHHELD，只声明数值反演与可辨识性。

| 关键量 | 基准 | 误差 | <3%? |
|---|---|---|---|
| 单轴 σ-ε | 解析双线性 | 1.9e-16 | **是** |
| 一致切线 | 返回映射中心差分 | 5.3e-10 | **是** |
| σ_cr 板屈曲（5 个长宽比） | Timoshenko 闭式 | 0.32–0.39%（Richardson 0.002–0.003%） | **是** |
| σ_u 基准板架 | Paik & Thayamballi 简化法 | −3.7% | **否**（<10% 判据下 pass） |
| σ_u 9 组合最大偏差 | 同上 | −6.72% | **否**（同上） |
| 冰压力律指数 | 给定模型指数 −0.3 | 干净 0.0000；含噪最大 0.0333 | 干净**是**；含噪**否**（判据为带宽） |

结论：解析锚（本构、屈曲）全部远优于 3%；**板架极限强度与文献简化法的偏差为 3.7%–6.7%
（未达 3%）**，原因是本模型含初始挠度的梁柱折减而简化法不含——方向为保守侧，量级在
文献分散带内，判据 (<10%) 通过，但**不粉饰为 3% 级吻合**。冰带指数判据本身是带宽
[−0.35,−0.25]，含噪最大偏离 0.033（判据内）。
