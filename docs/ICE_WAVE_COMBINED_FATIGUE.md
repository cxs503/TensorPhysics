## 1. 案例介绍

### 1.1 物理背景

冰区船舶的船体梁疲劳同时承受两类交变应力：

1. **冰致应力**：艏部冰挤压载荷（碎冰接触、破碎、卸载）经船体梁模态传递到细部；
   其频谱在挤压事件率（本算例 0.43 Hz）及其谐波附近有能量，**同时**把一阶垂向弯曲
   模态（0.559 Hz）激起——后者即 *whipping*（惯性放大），把高频能量注入应力时程。
2. **波浪致应力**：海浪垂向弯矩，峰值频率 0.1 Hz 量级，远低于船体梁一阶频率，
   因此波浪部分是准静态的（DAF ≈ 1）。

设计问题的关键：两者**同时发生**。工程实践中常见做法是分别算 `D_ice`、`D_wave`
再相加。本节点检验这个做法，并在其失效处给出替代规则。

## 2. 怎么做的

### 2.1 工具链与两级实验设计

工具链：Python 3.11 + numpy/scipy/matplotlib。全量算例 13 s 单核，
外协方 所 loong64 双节点集群（n315）执行（`stage_dir` 直投工作树），
输出逐位相同（`results.json` 中 `law_max_err_pct = 8.1526 %` 本地/集群一致）。

**两级设计**（关键：组合律必须在受控条件下测，物理链必须独立验证）：

* **Level A（受控叠加）**：两个零均值、限带高斯应力分量直接相加。
  - 冰带：高斯形应力谱，中心 f_ice = 0.43 Hz，相对带宽 15 %；
  - 波浪带：JONSWAP 形（γ 可调）或双峰形（涌/风浪峰分离 r_p 可调）**应力谱**
    （RAO 幅值折入谱内——因 f_w ≪ f₁ 时船体梁 RAO 在波浪带内接近常数）；
  - 扫掠 `f_ice/f_w ∈ {0.3, 1, 3, 10, 100}` × 幅值比 `σ_wave/σ_ice ∈ {0.3, 0.6, 1.0, 2.0}`
    × 6 个随机种子；另加「等单分量损伤」归一化模式 5 × 6。
  - 记录长度 1800 s、采样 20 Hz；雨流真值取各实现值、种子间标准差一并报告。
* **Level B（物理链）**：DEM 冰载荷 → 模态叠加 → 热点应力；JONSWAP 波浪谱 →
  自由-自由 EB 波浪 RAO → 波浪应力 → 三者叠加；DNV F3 双斜率 + Goodman + 板厚修正。
  3600 s、dt = 10 ms、3 个波浪种子。

### 2.2 判据与先验阈值（动手前声明）

| 判据 | 阈值 | 判读方式 |
|---|---|---|
| (a) 线性叠加 | ρ = D_comb/(D_ice+D_wave) ∈ [0.97, 1.03]，在 f_ice/f_w ≥ 10 | 否则必须给非线性组合律 + 机理 |
| (b) 谱方法 | Dirlik / TB 对雨流真值损伤误差 ≤ 10 %（3 档谱宽） | 逐档判定 |
| (c) whipping 口径 | 误计入放大 A 与 whipping 份额互推偏差 ≤ 2 个百分点；慢变工况份额 < 8 % | 三项子检 |
| (d) 雨流可交换性 | 分段/闭合块重排后损伤偏差 ≤ 1e-9 | 另设朴素反例 |
| (e) 负控 | 关波浪后退化到 m5528，误差 ≤ 2 % | 15 个量逐项 |

3 档谱宽（(b) 的声明档）：`γ = 6.0`（窄）、`γ = 3.3`（中）、`双峰 r_p = 3.0`（宽）；
另报 `γ = 1.0`、`双峰 r_p = 1.6` 两个补充档（不参与判定）。

### 2.3 关键实现点

1. **流式雨流**（`rainflow_stream.StreamingRainflow`）：4 点法栈上保留残差，
   分块喂入与整段喂入给出**同一循环表、同一顺序**，因此损伤逐位相同 → 判据 (d) 的必要工具。
2. **组合律**：由两个精确极限插值——
   分离频带（雨流循环互不干涉）、合流频带（幅值在同一循环内相加）。
   权重为两带**谱重叠度** β = ∫min(S₁,S₂)df / min(∫S₁df, ∫S₂df)（无拟合参数），
   分离极限为 `D_rider + κ(r,N)·D_carrier`，合流极限为合并谱的 Tovo-Benasciutti 损伤。
3. **κ 标定**：`κ = 1 + a·r^b·N^c`，r = σ_rider/σ_carrier，N = f_rider/f_carrier。
   标定集只用**分离频带子集**（β ≤ 0.05，且 f_ice/f_w ∈ {10, 100}），
   留出点为 f_ice/f_w ∈ {0.3, 3.0}（预测性检验，不参与标定）。
4. **whipping 双口径**：峰值口径 `max|σ−σ_qs|/max|σ|`（m5528），
   RMS 口径 `rms(σ−σ_qs)/rms(σ)`，以及**损伤口径** `D_whip/D_true`。
5. 全部随机量带种子；`results.json` 记录种子、长度、采样率、git commit（8aeb46b）、
   Python/numpy/scipy 版本。

### 3.2 判据 (a)：线性叠加律被否证

25 个扫描点（5 个频带比 × 4 个幅值比 + 等损伤模式 5 点），雨流真值：

| f_ice/f_w | σ_w/σ_i | ρ 真值 | ρ_TB | ρ_law | β | 合并谱 ε |
|---|---|---|---|---|---|---|
| 0.3 | 0.6 | 1.635 ± 0.024 | 1.553 | 1.502 | 0.000 | 0.648 |
| 1.0 | 1.0 | 1.447 ± 0.059 | 1.402 | 1.457 | 0.759 | 0.306 |
| 3.0 | 1.0 | 1.443 ± 0.035 | 1.407 | 1.503 | 0.060 | 0.433 |
| 10.0 | 0.3 | 1.045 ± 0.005 | 1.032 | 1.046 | 0.003 | 0.291 |
| 10.0 | 1.0 | **1.307 ± 0.018** | 0.963 | 1.309 | 0.002 | 0.630 |
| 10.0 | 2.0 | **1.568 ± 0.036** | 0.983 | 1.552 | 0.005 | 0.773 |
| 100.0 | 1.0 | **1.074 ± 0.007** | 0.732 | 1.075 | 0.000 | 0.706 |
| 100.0 | 2.0 | **1.215 ± 0.023** | 0.511 | 1.222 | 0.000 | 0.886 |
| 等损伤 100 | σ_w = 1.97 MPa | **1.466 ± 0.058** | 0.332 | 1.466 | 0.000 | 0.965 |

* 分离频带（f_ice/f_w ≥ 10）的 10 个点中只有 **1 个**落在 [0.97, 1.03] →
  **线性叠加假设被否证**（honest FAIL），且失稳方向是**不安全侧**：
  `D_comb/(D_ice+D_wave) ∈ [1.010, 1.635]`，全扫描 25 点均值误差 **22.6 %**、最大 **38.8 %**
  （即叠加式低估组合损伤最多 38.8 %）。
* **机理**（§3.3 直接测量）：高频"riding"分量既被自己按全幅计了一个循环，
  又把低频"carrier"循环的极值**撑大**了 riding 幅值——同一幅值被计了两次。
  因此这个非可加性**与频带间隔无关**（ratio = 100 时仍有 +21 %），
  只与**幅值比**和**循环率比**有关。这与文献中"whipping/VIV 叠加波浪必须联合计数"
  的结论一致，本节点给出定量形式。
* 阈值内的唯一情形是 riding 幅值可忽略（σ_rider/σ_carrier ≤ 0.3 且 N 大）：
  ρ = 1.010（ratio 100, σ_w/σ_i = 0.3）。**工程判据**：
  叠加式误差 ≈ 3·r·(D_carrier/(D_ice+D_wave)) 量级，故 r ≤ 1 % 才可忽略。

### 3.3 非线性组合律与机理

**机理测量**（`mechanism`）：分离频带上"carrier 平均跨距"的增大 Δ：

| f_ice/f_w | σ_rider / σ_carrier [MPa] | r | carrier 平均跨距 单独 → 叠加中 [MPa] | 实测 Δ [MPa] | 预测 2√(π/2)σ_r [MPa] |
|---|---|---|---|---|---|
| 10 | 0.426 / 0.918 | 0.464 | 1.182 → 3.198 | **2.015** | 1.068 |
| 100 | 0.426 / 1.965 | 0.217 | 1.835 → 2.672 | **0.837** | 1.068 |

载波循环的跨距在叠加后**增大 1.7–2.7 倍**（Δ/D_carrier_damage ∝ (Δ/R+1)³），
实测增大与 `2√(π/2)·σ_rider` 同量级（比值 1.9 与 0.78，方向一致、量级正确）。
注意上表 Δ 只统计了"大循环族"（range > 4σ_rider），由它立方反推的 κ 是**上界**；
律里使用的是由**损伤比**标定的 κ（同点 3.77），两者不等价，报告不混用。）

**组合律**（可直接用于设计）：

```
D_comb = (1 − β)·[ D_rider + κ(r, N)·D_carrier ] + β·D_TB(S_ice + S_wave)

β = ∫min(S₁,S₂)df / min(∫S₁df, ∫S₂df)          # 谱重叠度，0=分离、1=合流
κ(r, N) = 1 + a·r^b·N^c,  r = σ_rider/σ_carrier, N = f_rider/f_carrier ≥ 1
a = 1.1406, b = 1.3253, c = 0.3850             # 分离频带子集标定（10 点，拟合残差 ≤ 3.2 %）
```

> rider = 两分量中**频率较高**者；carrier = 频率较低者。
> D_TB 是合并谱的 Tovo-Benasciutti 损伤率（合流极限）；D_rider/D_carrier 是两分量各自
> 的雨流（或窄带）损伤。

**精度（程序化评分）**：

| 规则 | 全 25 点最大误差 | 平均误差 | 留出点（0.3, 3.0）最大误差 |
|---|---|---|---|
| 线性叠加 ρ=1 | 38.8 % | 22.6 % | — |
| 仅 Tovo-Benasciutti（合并谱） | 77.3 % | 13.9 % | — |
| **本组合律** | **8.15 %** | **2.24 %** | **8.15 %** |

工具改进倍数 10.1×（平均误差 22.6 % → 2.24 %，最大 38.8 % → 8.15 %）。留出点从未参与标定，
8.15 % 是**预测性**精度，不是拟合优度。

**Level B（物理链、真实海况）**：冰 rms 8.95 MPa、浪 rms 11.30 MPa、f_ice/f_w = 3.90；
ρ = **1.553**（单斜率 m=3）/**1.550**（DNV 双斜率 + Goodman）；
组合寿命 1.02 yr（相对单冰 2.66 yr）。即真实工况下叠加式低估组合损伤 **约 55 %**。

### 3.4 判据 (b)：谱方法能力（FAIL）

合并谱 → 雨流真值 vs Dirlik / Tovo-Benasciutti / 窄带 Rayleigh（m = 3, C = 1，
三者与真值共用同一限带 PSD 与同一 S-N 常数）：

| 谱宽档 | f_ice/f_w | α₂ | Dirlik | TB | 窄带 |
|---|---|---|---|---|---|
| γ=6（窄） | 1 | 0.658 | −1.3 % | −1.3 % | −1.3 % |
| γ=6（窄） | 10 | 0.430 | **−11.5 %** | **−37.3 %** | +7.0 % |
| γ=3.3（中） | 1 | 0.628 | −1.0 % | −1.7 % | −1.7 % |
| γ=3.3（中） | 10 | 0.433 | **−11.7 %** | **−36.2 %** | +5.7 % |
| 双峰 r_p=3（宽） | 1 | 0.602 | +1.1 % | −1.6 % | −1.6 % |
| 双峰 r_p=3（宽） | 10 | 0.420 | **−12.6 %** | **−48.2 %** | **+19.3 %** |

* **合流频带（ratio = 1）三者都在 2 % 内** —— 谱方法在单峰窄带/中等谱宽下完全可用。
* **分离频带（ratio = 10）**：Dirlik −10 ~ −12.6 %（超出 10 %）、TB −34 ~ −48 %
  （TB 的 λ 修正把双峰谱当作宽带单峰，α₂² 权重严重低估）、窄带 +4 ~ +19 %。
  → 判据 (b) **FAIL**（Dirlik 最差 12.6 %，TB 最差 48.2 %）。
* **工程结论**：冰+浪（=双峰、分离）情形**不要**直接用 Dirlik/TB；
  要么用合成时程 + 雨流（本节点工具），要么用 §3.3 的组合律（8.2 %）。

### 3.5 判据 (c)：whipping 口径自洽（FAIL，机理清楚）

`A = D_mis/D_true`，`D_mis = D(σ) + D(σ−σ_qs)`（把 whipping 残差当独立分量再加一遍）；
三种"份额口径"的互推：

| 工况（f_pulse） | 峰值份额 s_peak | RMS 份额 s_rms | 损伤份额 D_whip/D_true | 实测 A | 峰值口径 A=1+(s/(1−s))³ | 偏差 |
|---|---|---|---|---|---|---|
| 挤压 m5528（0.45 Hz） | 0.351 | 0.759 | **0.971** | **2.178** | 1.158 | **16.3 pp** |
| 谐波慢变（0.05 Hz） | 0.015 | 0.007 | 0.000 | 1.000 | 1.000 | 1.3 pp |
| 时基拉伸准静态（0.05 Hz） | 0.267 | 0.260 | 0.620 | 1.437 | 1.049 | 16.4 pp |
| 只降压入速率（0.05 Hz） | 0.252 | 0.479 | 0.896 | 1.555 | 1.038 | 19.9 pp |
| 快速漂移（1.0 Hz） | 0.502 | 0.860 | 0.964 | 2.192 | 2.020 | 1.3 pp |

* **子检 c1（m5528 "<8 %"）成立**——但前提是**载荷本身准静态**（谐波 0.05 Hz → 份额 1.5 %）。
* **子检 c2（DEM 脉冲列在 0.05 Hz）不成立**：份额仍有 25–27 %。原因：DEM 的**卸载段**
  仍有 τ_dec = 0.15 s 的快速跌落，它照样激起 0.559 Hz 模态。也就是说
  m5528 的 "<8 %" 是**谐波口径**结论，不能推广到脉冲列。
* **子检 c3（2 pp 互推）不成立**：峰值口径把 whipping 的损伤角色低估 16.3 pp
  （A 预测 1.158 vs 实测 2.178）。根因：**峰值份额是极值统计量，损伤份额是
  m 阶矩 × 循环率统计量**；本算例 whipping 的损伤份额高达 0.97
  （riding 循环数 ≈ 4.8 × carrier 循环数），峰值份额 0.351 完全无法表达这件事。
* 可用的替代口径：**损伤口径** `D_whip/D_true`（本算例 0.90–0.97，
  A = 1 + D_whip/D_true ≈ 1.9–2.2，跨四种 DEM 工况稳定）。工程含义：
  **把 whipping 增量再加一遍会把冰致疲劳损伤放大近一倍**，这是比"份额 35 %"重要得多的结论。

### 3.6 判据 (d)：雨流可交换性（PASS）

| 检验 | 相对偏差 | 阈值 |
|---|---|---|
| 同序分段喂入（2 / 7 / 31 / 97 段，残差栈跨段保留） | **0.000e+00** | 1e-9 |
| 闭合块（起止同为 0）逐块计数后随机重排（20 次） | **1.62e-16** | 1e-9 |
| **反例**：朴素整段计数施加于重排拼接 | 各次之间散布 2.87e-2 | — |

结论：分段/闭合块分解下损伤可交换（仅浮点求和次序差异）；
但把重排后的块直接整段喂给雨流会得到**依赖次序**的损伤（2.9 % 散布），
这说明"闭合块分解 + 残差栈"不是可选的技巧而是必要条件。

## 4. 注意点（踩过的坑，按代价排序）

1. **雨流"分层"是组合律的全部关键**：叠加两个限带过程后，高频分量被按全幅计一遍，
   又把低频分量的极值撑大同样的幅值——同一幅值计了两次。
   任何"分别计数再相加"的做法在幅值可比时都会低估 20–55 %，**且与频带间隔无关**。
   这一条是本节点最反直觉的结论：文献常说"频带分离则损伤可加"，
   本算例证明**只有在 riding 幅值可忽略（r ≲ 1 %）时**才成立。
2. **起振瞬态污染**（m5528 的老坑，本节点再确认）：一阶模态 ζ=1.5 % 时衰减时间
   1/(ζω₁) ≈ 19 s，恒载阶跃在窗口内长时间振铃，不去掉前 60 s 会把 whipping 份额算成 70–100 %。
3. **频谱 m₄ 与尾巴**：Dirlik 的 ν_p = √(m₄/m₂) 对高频尾巴极敏感；必须让谱方法与时域
   共用**同一条限带 PSD**（本节点用 rFFT 网格），否则 Dirlik 误差里混进了截断误差。
4. **whipping 份额的口径陷阱**：峰值口径 35 % 与损伤口径 97 % 差三倍。
   用峰值份额去论证"whipping 误计入只影响 15 %"会严重低估风险（实测放大 2.18 倍）。
5. **平台内的雨流实现不一致（顺带发现）**：`tensorphysics.fatigue.rainflow` 的
   list 版 `rainflow_counting` 与 stack 版 `rainflow_counting_stack` 在含噪信号上给出
   **不同循环**（同一信号：451 vs 456 个循环，损伤相差 +13.2 %）。
   本节点的 `rainflow_stream` 与 **stack 版逐位一致**（pytest 保证），
   因此 `time_domain_damage_rate(method="reference")` 的使用者应注意该偏差。
   建议平台侧把参考实现统一到 stack 版（本节点不改动既有模块，避免越界）。
6. **时基拉伸 vs 只降速率**：想把"慢变工况"做出准静态极限，必须把**所有**时间尺度
   （含冰卸载时间）一起放大；只降挤压速率会留下 0.15 s 的卸载阶跃，仍激起 0.56 Hz 模态。
7. **波浪 RAO 的复数相位**：实现 `stress_transfer_function` 时最初把复振幅取实部再算 |T|²，
   长波与短波的相位不同，取实部会低估波浪应力约 30 %（本算例 8.87 → 11.30 MPa）；
   PSD 必须用 |T|² 。

## 5. 误差判定（逐项，含"是否 <3 %"的显式回答）

| 量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| 年损伤 / 寿命 / 份额 / Δσ_eq / 循环数（判据 e，15 量） | m5528 已发布结果 | ≤ 8.9e-8 % | **是** |
| 一阶/二阶频率、静弯矩反力平衡 | 解析 βL 根、刚体平衡 | ≤ 1e-12 | **是** |
| 单模态动力放大系数（4 个频率比） | 解析 DAF | ≤ 4.9 %（含瞬态残差；300 s 后稳态 <1 %） | 否（含瞬态口径）；稳态口径 **是** |
| 雨流计数（正弦 25 周期、含噪信号 vs stack 参考实现） | ASTM E1049-85 | 0（逐位一致） | **是** |
| S-N 曲线表值 | DNV-RP-C203 D/F3 @1e7 | ≤ 0.1 % | **是** |
| JONSWAP 谱能量 | Hs²/16 | ≤ 3 % | **是** |
| 机械 (a)：线性叠加 ρ | 雨流真值（同实现） | 见下行注 | — |
| 机械 (a)：**组合律** ρ | 雨流真值 | **最大 8.15 %，平均 2.24 %**（留出点 8.15 %） | 否（8.15 % > 3 %，如实标注） |
| 机械 (b)：Dirlik / TB | 雨流真值 | 12.6 % / 48.2 % | 否（**honest FAIL**） |
| 机械 (c)：峰值口径→A | 实测 A | 16.3 pp | 否（**honest FAIL**） |
| 机械 (d)：分段/重排 | 整段雨流 | 0 / 1.6e-16 | **是** |
| Level B ρ | 雨流真值 | 组合律在留出点 8.15 %；本点属插值区 | 否 |

**显式回答**：凡有独立解析/规范基准的量（频率、静弯矩、DAF、雨流、S-N 表值、
冰载荷统计、m5528 端到端复现）误差均 **< 3 %**（多数 < 1e-6）；
组合律对雨流真值的精度是 **8.15 %（最大）/ 2.24 %（平均）**，**未达 3 %**，
原因是 κ 的幂律形式只捕捉了 riding/carrier 的一阶机理，未含循环率比的高阶修正；
而雨流真值本身是本节点唯一"地面真值"，无实验基准可比。
判据 (b)、(c) 如实记为 FAIL，不粉饰。

## 6. 局限与适用范围

* **单轴、名义/热点应力法**：多轴、厚度方向裂纹、焊缝细节分类未建模。
* **波浪载荷为条带近似**：Froude-Krylov + 深度衰减 + 沿船长相位，无 Smith 修正、
  无绕射/辐射、无砰击。因此**波浪弯矩的绝对值**不作物理声明
  （Level A 用等幅/等损伤归一化；Level B 报告条带绝对值 11.3 MPa rms 并给出隐含增益 1.0）。
  受影响的只是 ρ 的**绝对位置**，组合律的**形式**由 r、N、β 决定，不依赖幅值标定。
* **冰载荷为降阶 DEM**（统计定标），非三维 DEM/实测；冰况只覆盖连续挤压 + 破碎事件列。
* **模态截断 10 阶**（f₁₀ = 27.17 Hz），更高频（如局部板格振动）未含；
  这对 whipping 份额有 ≤ 数 % 影响（m5528 已给 20 阶收敛证据）。
* **组合律的 κ 为三参数半经验式**：标定集为分离频带（β ≤ 0.05，ratio ∈ {10,100}）× 4 个幅值比，
  留出点 ratio ∈ {0.3, 3.0} 的预测误差 ≤ 8.15 %。外推到 r > 3.3、N > 100 或
  ratio < 0.3 未经检验。
* **记录长度限制**：ratio = 100 时载波周期在 1800 s 内仅 ~7.7 个，种子间标准差 0.7–2.3 %
  已如实给出；更长记录的 ρ 会更平滑，但趋势与律的偏差不应改变量级。
* **适用对象**：钢质船体梁（自由-自由弯曲）、冰区航行 + 波浪共存工况的焊缝疲劳筛查；
  不适用于极端砰击、屈曲主导失效或低温脆断评估。
