## 1. 案例介绍

船体梁在波浪中同时承受两类水弹性效应：**springing**（稳态、窄带、由遭遇频率把短波能量搬到
船体梁 2 节点模态上的共振振动）与 **whipping**（砰击脉冲激起的瞬态自由衰减振动）。两者都把
弹性应力叠加到刚体波浪弯矩上，直接影响中拱/中垂极值、疲劳 loop 与剖面模数利用率账本。

| 参数 | KCS（KRISO 集装箱船） | KVLCC2（KRISO 油船） |
|---|---|---|
| L / B / T / D | 230.0 / 32.2 / 10.8 / 19.0 m | 320.0 / 58.0 / 20.8 / 30.0 m |
| Cb | 0.651 | 0.8098 |
| 排水量 | 53 372 t | 320 437 t |
| 水线面系数 Cwp | 0.7673 | 0.8732 |
| 设计航速 / Fn | 24 kn / 0.2599 | 15.5 kn / 0.1423 |
| 中剖面模数 S_M（IACS UR S7 规则最小值） | 14.49 m³ | 96.40 m³ |
| 屈服应力 | 315 MPa | 315 MPa |
| 剖面丰满指数（超椭圆 n） | 4 | 6 |

船体梁理想化（全部假设写在 `hull_hydroelastic/wet.py: ship_beam_properties`）：
`I_mid = S_M·D/2`，纵向 `I(x) = I_mid (b(x)/B)^1.5`（`b(x)` 取平台 `ShipGirder` 水线宽分布）；
有效剪切面积 `A_s(x) = 0.25·I(x)/(D²/4)`；振动质量取满载质量分布（钢结构 + 货物/舾装，均布）；
转动惯量只计钢结构 `ρ_s I`。E = 2.06e11 Pa，G = 7.92e10 Pa，κ = 0.5。

海况：ITTC-1978 双参数谱，Hs = 6.0 m，T1 = 9.0 s（短期待遇），阻尼比基准 ζ = 2 %（见 §5）。

**证据分级**：Timoshenko 干/湿模态、二维附加质量、模态叠加、卷积瞬态、S-N 记账 = REAL；
波浪激励（Smith 修正条带）、砰击压力理想化、窄带 Rayleigh 疲劳 = APPROXIMATE-STRIP；
条带辐射阻尼 = WITHHELD（未实现自由面辐射 Green 函数）；水平/扭转模态、条带转动附加惯量 = NOT MODELLED。

## 2. 怎么做的

1. **非均匀 Timoshenko 自由-自由梁 FE**（`timoshenko.py`）：2 节点单元，独立插值剪切应变
   （φ = 12EI/κGAL² 消除剪切锁死），质量阵 = Euler-Bernoulli 一致质量 + 转动惯量阵；
   `shear_rigid=True` 退化为 EB 单元用于解析闸。广义特征问题用 Cholesky 归约 + `numpy.linalg.eigh`
   （loong64 上广义 `scipy.linalg.eigh` 会段错误，见 §5）。
2. **二维剖面附加质量**（`sections.py`）：常值源面板 + 中点配点，核函数用**解析面板积分**
   （∂ln r/∂n 的 `arctan(u/h)` 闭式、ln r 的闭式），单层位势跳变项 +1/2；浮体截面用镜像源实现
   `φ = 0` 的水线自由面条件（无限频极限），水线不做“盖子”（`open_ends=True`）。浮心附加质量
   `m_jk = −ρ∮φ_k n_j ds`（外法向取流体一侧）。
3. **湿模态**（`wet.py`）：干模态基下 `A_nm = ∫a33 φ_n φ_m dx`，浮力恢复刚度
   `G_nm = ∫ρg b φ_n φ_m dx`（自由浮体必有，占模态刚度 0.9–6.6 %），解 `(K+G) v = ω²(I+A) v`。
4. **springing**（`response.py`）：Smith 修正条带剖面力
   `f3 = ρg e^{−kT}[b(x) + k·a33/ρ]·cos(kx)`（**波相位 cos(kx) 必须保留**），在干模态基下解
   `[K+G−ω_e²(I+A)+2iω_e diag(ζ_nω_n)]q = Q(ω)`，σ = E(D/2)·Σφ_n''(x_mid)q_n，ITTC 谱积分得 RMS；
   `ω_e = ω − kU cos μ`（μ = 180° 迎浪），含雅可比 |dω_e/dω|。
5. **whipping**（`response.py`）：砰击力 = 峰值力 × 非对称半正弦（升时 0.4d）作用在艏部
   0.1L × 0.5B 三角分布，模态脉冲响应卷积（FFT）得应力时程；疲劳用衰减包络的 DNV-RP-C203
   D 曲线（空气中，m = 3，log₁₀a = 12.164），`D_event = (2σ_peak)^m/(2π a m ζ)`。
   模态截断准则是**梁理想化适用性闸**：只保留纵弯波长 2L/n ≥ 4D 的模态（KCS 1–6 阶，KVLCC2 1–5 阶）。
6. **耦合/解耦对比**（`coupling_table`）：解耦 = 同套水动力下**刚体** heave/pitch 波浪弯矩的 3 小时
   极值（3.7σ）；耦合 = 柔性船体应力 RMS（3.7σ）+ 砰击 whipping 峰值；砰击力按 Wagner 相对速度
   平方律 `F(Fn) = F_ref (U/U_ref)²` 随 Fn 增长。
7. **接口闸**：弹性应力经中剖面模数换算成弯矩增量，推进 IACS UR S7 规则极限强度账本
   `utilisation = M/(M_u/γ_m)`（`hullgirder.ultimate`），检查利用率变化与弯矩变化成比例，并给出
   PASS/FAIL 是否翻转的二值结论。

工具链：Python 3.11 + numpy/scipy/matplotlib；重计算（全量算例，两个船型 16.5 s）外协方 所
loong64 双节点集群（n330）执行，本地仅做绘图与文档。

### 3.4 springing：应力响应谱与 RMS

设计航速（KCS 24 kn = 12.3 m/s、KVLCC2 15.5 kn = 8.0 m/s），Hs = 6 m / T1 = 9 s，ζ = 2 %：

| 船型 | 刚体波浪应力 RMS | 柔性船体应力 RMS | 弹性放大比 | 主导模态 | 热点位置 |
|---|---|---|---|---|---|
| KCS | 31.1 MPa | **77.8 MPa** | 2.50 | 1 阶 | 中剖面甲板（x = 0） |
| KVLCC2 | 16.9 MPa | **45.8 MPa** | 2.71 | 1 阶 | 中剖面甲板 |

阻尼敏感性（KCS，设计航速）：ζ = 0.5 / 2 / 5 % → 94.1 / 77.8 / 76.9 MPa。
对 ζ 几乎不敏感 ⇒ 响应由**准静态柔性分量**（而非共振尖峰）主导：迎浪遭遇频率把
ω_n = 2.31 rad/s 的共振搬到波频 ω ≈ 1.87 rad/s（λ ≈ 17.6 m ≪ L），该处 `e^{−kT} = 0.022`
把共振激励压到很低，因此共振份额小、RMS 由波谱主能区（λ ~ 100–300 m）的柔性响应决定。
这是本节点最重要的物理结论，同时也是 §5 中「绝对量级偏大」的直接原因。

### 3.5 whipping：瞬态响应与疲劳贡献

砰击峰值力 5 MN（等效匀布压力 14 kPa，作用 23 m × 16.1 m），升时 0.24d，d = 0.25 s，
单事件冲量 0.80 MN·s，模态保留 λ ≥ 4D：

| 船型 | 峰值应力 | 2 节点分量 | 保留模态 | 峰值时刻 |
|---|---|---|---|---|
| KCS | **23.7 MPa** | 6.2 MPa | 1–6 | 1.62 s |
| KVLCC2 | **4.1 MPa** | 1.1 MPa | 1–5 | 1.4 s |

严重度敏感性（KCS，d = 0.25 s）：2.5 / 5 / 10 MN → 11.9 / 23.7 / 47.5 MPa（近线性）；
d = 0.12 s 时同力下降约一半。若去掉 λ ≥ 4D 截断（保留 10 阶），峰值升到 283 MPa —— 由 9–10 阶
贡献，属梁理想化失效区，取为上限参考，不用于后续判据。

疲劳（DNV D 曲线，空气中）：单事件损伤 D_event(KCS) = 7.3e-3；按 60 次/小时砰击，
whipping 对上浪+springing 总损伤的贡献率 = **0.17 %（KCS）/ 0.0045 %（KVLCC2）**。
即在给定砰击率下，此海况的疲劳 loop 由波浪/springing 主导，whipping 贡献 < 1 %。

## 5. 注意点、局限与 honest-FAIL

**踩过的坑（已修正，写进代码注释）**

1. 二维源面板的**跳变项符号**与核函数必须一致：跳变项 +1/2 与 `arctan(u/h)` 闭式组合才使均匀源
   行和 = ±1（否则解出 σ = −2·v_n，附加质量符号翻转）。圆柱 ρπa² 闸是唯一能抓住它的证据。
2. **浮体截面不能加水线“盖子”**：`panelize` 默认闭合多边形，会把自由面当成湿表面施加速度边界，
   使 sway 附加质量错到 −67 %；引入 `open_ends` 后恢复。
3. **激励的量纲**：条带公式 `ρg e^{−kT}[b + k·a33]` 中 a33 必须是**无量纲**（a33/ρ），否则激励被
   放大 ρ = 1025 倍（首次跑出 32 GPa 应力）。
4. **波相位 cos(kx) 不能省**：省略后在遭遇频率共振处把短波激励沿全船同相叠加，springing 被高估两个量级。
5. **附加质量不能进刚度**：用 ω_wet² 做传递函数分母（等价于把附加质量当刚度）会把准静态柔性响应
   放大 (1+A_nn) ≈ 2.5 倍；必须保持 `[K−ω²(I+A)]`。
6. **自由面漂浮体**的载荷必须做刚体自平衡投影：双积分把残余合力放大 L²/8，`balanced_load` 显式扣除。
7. loong64 节点上广义 `scipy.linalg.eigh` 在 pytest 内**段错误**：改为 `np.linalg.cholesky` + 
   `np.linalg.eigh`，并在跑测试时置 `OMP_NUM_THREADS=1`（否则 BLAS 线程化下仍崩）。

**未完成 / honest-FAIL**

- **判据③ 部分 FAIL（如实报告）**：模态截断 5 → 10 → 20 的应力 RMS 变化为 **3.07 % / 0.687 %**，
  湿频率变化 0.067 % / 0.000 %。5 模态的 3.07 % **超过 1 % 判据**（准静态柔性分量需要更多模态），
  10 → 20 的 0.687 % 满足判据。生产默认 n_modes = 10 位于收敛区；`results.json →
  cases.<hull>.convergence.pass = false` 如实保留，不做粉饰。
- **耦合弯矩的绝对量级不可信（honest FAIL）**：柔性/刚体应力比 2.5–2.7，远大于文献报道的
  1.1–1.3。原因未查清：模态机器本身已用梁静力学独立校验（λ/L = 2 与 1 时柔性静解 vs 直接梁静力
  差 0.2 % / 2.3 %），残余偏差出现在 Smith 修正（`e^{−kT}`）在「柔性外载荷」与「刚体恢复项」之间
  的不一致处理上；长波极限下两套公式仍差 2.3 倍。因此 **Δ% 的数值是上限，判据⑤只保证趋势**。
- **条带辐射阻尼 WITHHELD**：无自由面辐射 Green 函数，modal ζ 仅取结构阻尼（基准 2 %，
  区间 0.5–5 %）。共振份额小使其对结果影响 < 20 %，但若换到共振主导的船型/海况，ζ 将成为主控参数。
- **2D 条带 vs 3D**：未与 TensorBEM 的 STF/3D 水动力耦合。差异来源：无三维绕射、无航速修正的
  相位、无艏艉端面效应；短波（λ ≪ L）时 2D 条带的广义力误差最大，正是 springing 主能区。
- 未建模：水平/扭转船体梁模态、条带转动附加惯量、green water 与艏外飘砰击细节、
  springing–whipping 相互作用、货载分布不均（质量均布）。
