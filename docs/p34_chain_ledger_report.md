## 2. 怎么做的

### 方法概述

三段链的每个交接面被表述为**独立数值路径必须满足的恒等式**，残差度量交接误差而非物理模型：

**Face A（压力→刚体合力）**：
- 路径1：分片常数边界节点保持（模拟 LBM 边界动量交换求和）
- 路径2：分片 Gauss 求积（order 2）
- 参考：精细网格（n_edge=64）+ 高阶求积（order 6）
- 判据：|F_h - F_ref| / |F_ref| < 2%，观测收敛阶 ≥ 1

**Face B（刚体运动→浸没边界）**：
- 闭合面零通量恒等式 ∮u·n dA = 0（刚体运动）
- 浸没体积变化率 dV/dt = -∫_{S_w} u·n dA
- 功率互易性：解析速度功率 vs 交付速度功率
- 负控：旋转位置但不旋转法向 → 恒等式被打破

**Face C（砰击压力→模态广义力）**：
- 路径1：全场 2D 虚功 Q_n = ∫∫p·φ_n dξ dx
- 路径2：条带线载荷 f(x) = ∫p dξ 投影到梁网格
- 路径3：Duhamel 卷积 vs RK4 直接积分
- 判据：广义力误差 < 3%，Duhamel 误差 < 3%

**Face E（能量账本）**：
- W_in = 交付广义力对物理界面速度做的功
- dKE+dPE = 一个波周期内动能+势能变化
- W_diss = 阻尼耗散
- 残差 = |W_in - (dKE+dPE+W_diss)| / |W_in| < 3%

**Face T（时间同步账本）**：
- 零偏移残差 < 3%
- Δt/2 偏移必须被检出（残差 > 10%）
- 0 阶插值力误差 > 10%

**Face N（负控）**：
- 无稳定化（naive Gauss-Seidel）→ 100% 发散检出
- Aitken/IQN-ILS → 100% 收敛
- 谱半径 ρ(G) > 1（轻质量体不稳定）

## 5. 注意点

### 局限与适用范围

1. **二维条带假设**：截面附加质量为 2D Dirichlet BVP 解，三维端部效应未建模。
2. **线性波理论**：Stokes 二阶波，波陡 ka=0.044，非线性效应可忽略。
3. **Wagner 砰击模型**：理想化入水模型，不考虑气流垫、弹性响应耦合。
4. **箱形浮体**：实际船体截面为曲面，此处用超椭圆截面近似（指数 8）。
5. **模态截断**：保留 8 阶湿模态，截断误差 < 1%（审计通过）。
6. **轻质量体 regime**：m/A33 = 0.24，结构质量低于附加质量——这是最严苛的 FSI 稳定性测试。

### 踩过的坑

1. **能量账本的周期净变**：稳态响应下 dE = 0（一个完整周期），但数值积分必须用梯形法则而非矩形法则，否则 O(dt) 残差会淹没待检量。
2. **参考力矩归一化**：砰击载荷的俯仰力矩接近零，直接相对误差无意义，改用 |F|·L 归一化。
3. **法向旋转一致性**：Face B 负控的关键——旋转位置但忘记旋转法向是移动边界代码的真实缺陷类。
