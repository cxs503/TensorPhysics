## 1. 案例介绍（物理背景 / 几何 / 参数表）

纵向加筋板架在总纵弯曲受压侧，极限强度由三类能力竞争：板格屈曲后的有效宽度丧失、筋材柱屈曲-屈服交互、以及筋材**侧倾（tripping）**。基准板格取典型内底板：

| 参数 | 符号 | 值 |
|---|---|---|
| 横向框架间距（柱长） | a | 2.400 m |
| 筋距 | b | 0.700 m |
| 板厚 | t | 12.0 mm |
| 腹板高 / 厚 | h_s / t_w | 200 / 10 mm |
| 翼板宽 / 厚 | b_f / t_f | 100 / 15 mm |
| 材料 | E, ν, σ_y0, H | 206 GPa, 0.30, 313 MPa, 1.0 GPa |
| 板格柔度 | β = (b/t)√(σ_y0/E) | **2.274** |
| 柱柔度 | λ = (a/πr)√(σ_y0/E)（r 含附着板） | **0.378** |

模型常数（声明值，未对标定）：残余应力因子 r = 0.15、峰后软化斜率 0.02E、初始挠度 a/1000、侧向约束 lambda_trip = 1.0。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **剖面（新增 `panel_section.py`）**：把板条 + 腹板 + 翼板分解成轴对齐矩形，逐矩形**解析**积分得到面积、一阶矩、二阶矩（自身惯性 + 平行轴）、等面积轴 y_p（二分至 1e-16）、塑性剖面模数 Z_p = ∫|z−y_p|dA、圣维南常数 J、T 型翘曲常数 C_w、极惯性矩 I_p，以及板 / 腹板 / 翼板 / 柱 / 侧倾五个弹性临界应力。**独立复核**：`numeric_properties()` 用 800 条水平条带做完全另路的数值积分。
2. **极限强度（新增 `panel_ultimate.py`）**：等缩短量并联装配。板元件用可选曲线（Faulkner 试验标定 = 设计值；von Kármán 理想板 = 上界）；筋材用**四个上限竞争**（含附着板的 Johnson-Ostenfeld 柱曲线、弹性侧倾、腹板局部屈曲、翼板悬伸屈曲），最小者绑定；元件过峰后按各自软化斜率下降，故面板曲线有真实**极限点**。
3. **物理门**：结果必须落在弹性下界 (1−r)·min(σ_cr) 与刚性塑性上界 σ_y 之间（`check_ultimate_bounds`），越界判为缺陷而非结果。
4. **四法交叉**：本模块 Faulkner / 本模块 von Kármán / `axial_collapse_ep` 的 Perry-Robertson 装配 / 同模块刚性塑性求和 / `progressive_collapse` 纤维求解器（曲率由 M = N·δ 定）。
5. **N-M 塑性面（新增）**：扫描塑性中和轴解析求和得到**精确**刚性塑性 N-M 面；端点 N=0 ⇒ M=M_p、M=0 ⇒ N=±N_p 为机器精度锚点。
6. **板架（重写 `grillage_error_bound.py`）**：删除伪系数 k = 1 + 0.05(n_y−1)/n_y、1 + 0.02(n_x−1)/n_x（无出处，且使 3×3→5×5 判据恒等于 0.67% 而必然通过），改为等缩短量并联装配 + 确定性分位数抽样的初始挠度分布（Beta(2,2)，无随机数）；收敛研究拆成两把刀：舱格数（物理上严格不变）与载荷步数（真正的分辨率旋钮）。

## 3. 计算结果（数字表，程序化注入）

完整 9 张表见 `artifacts/p167w2_n04/tables.md`。关键量：

- 剖面：A = 0.0119 m²，z_bar = 0.0447269 m，I = 7.38351e-05 m⁴，y_p = 0.0025 m，**Z_p = 0.000553075 m³**，形状系数 = 1.3204，M_p = 173.112 kN·m，N_p = 3724.7 kN。
- 板架极限强度（设计值，Faulkner 曲线）：**σ_u = 215.804 MPa = 0.6895 σ_y**，极限点应变 0.00150，峰后比 0.6468，控制模式 **plate_buckling**。
- 强度带：Faulkner 0.6895 σ_y ↔ von Kármán 0.8733 σ_y，半带宽/均值 = **11.76 %**。
- 四法交叉离散（max/min − 1）= **31.12 %**；同族方法 |偏差| ≤ 3.40 %，离散几乎全部来自板元件曲线选择。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **旧板架系数的性质**：k = 1 + 0.05(n_y−1)/n_y 无论板架如何都给出 0.67% 的 3×3→5×5 差，旧 `converged` 判据必然通过——测试绿但问题没解决。新判据同时含**严格不变性**（6.7e-16）与**步长收敛性**（200→400 步 6.7e-04；旧默认 40 步偏 2.57%）。
2. **板元件曲线主导 27%**：von Kármán √(σ_cr σ_y) 是理想板（无残余应力、无初始挠度）的峰后平均值；Faulkner 是试验标定值。二者之差即本文声明的强度带。无试验锚点时**不应**把上界当设计值。
3. **筋材初始挠度符号问题（诚实报告，未修）**：现有纤维求解器 σ_u 随 w0 单调**增加**（w0 = 0 → 4 mm 时 0.8422 → 0.8704 σ_y），与所有设计曲线（η ∝ δ0）方向相反。因此本轮**没有**用初始挠度统计去构造尺寸效应，而是降级为不确定度上界；缺陷登记待修。
4. **未做**：侧向压力 / 双轴压缩耦合（不引入无锚点经验式）；焊接残余应力的空间分布（仅单一折减 0.15）；桶形 / 箱形筋。
5. 适用范围：b/t ≤ 60（β ≤ 4.6）、h_s/t_w ≤ 60、a/b ∈ [1, 6]，单一 T 型或平板筋。

## 6. 误差判定（逐项列出并显式回答是否 < 3%）

| 关键量 | 基准 | 误差 | 是否 < 3% |
|---|---|---|---|
| A, z_bar, I（剖面） | 800 条带独立数值积分 | 6.3e-08（最大） | **是** |
| Z_p（塑性模数） | 同上 | 6.3e-08 | **是** |
| M(N=0)（塑性面锚点） | σ_y·Z_p 解析 | 1.8e-15 | **是** |
| σ_cr（板屈曲） | Timoshenko 闭式（测试内独立重算） | < 1e-12 | **是** |
| σ_T（侧倾，平板筋） | GJ/I_p 闭式（测试内独立重算） | < 1e-12 | **是** |
| σ_u（同族方法间） | Faulkner vs Perry-Robertson vs 刚性塑性求和 | 3.40%（最大） | **是** |
| σ_u（跨族：元件曲线） | Faulkner vs von Kármán vs 纤维求解器 | 31.12%（max/min−1） | **否** |
| σ_u vs 试验 | —— | 无离线试验基准 | **无基准**（如实声明） |
| 板架尺寸不变性 | 同舱格解析恒等 | 6.7e-16 | **是** |
| δ_iso | 并联装配（无自由参数） | 2.2e-05 相对，界 ±3.4e-05 | **是**（且否定旧 +5%） |

**结论**：所有带解析/独立数值基准的量均 < 3%（多数 < 1e-6）；**σ_u 的跨族离散 31% > 15%，不满足精度标准**，根源唯一地定位到板元件本构曲线（von Kármán vs Faulkner），已标为待试验判定的开放缺口，未用任何经验系数粉饰。

## 7. 本轮顺带发现并处理的既有缺陷

1. `grillage_error_bound` 的两个伪约束系数（已删除，改力学装配）。
2. `SmithCollapseSolver` 文档声明支持 `tripping` 但该模式**不可达**（纤维求解器只认 板/柱）：已修——侧倾临界应力低于板/柱时返回 `tripping`（平板筋 t_w = 6 mm 复算得 `tripping`；基准 T 型筋为 `interactive`）。
3. `StiffenedPlateGeometry.section_properties()` 的 `Z_bot` 量到板**中面**而非板底纤维，对基准板格高估 13.41%（新模块用板底纤维，回归测试锁定二者关系）。
