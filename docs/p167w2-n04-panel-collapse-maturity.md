## 1. 案例介绍（物理背景 / 几何 / 参数）

纵向加筋板架在总纵弯曲下面临四种互相竞争的极限状态：板格局部屈曲（有效宽度丧失）、
筋-带板组合的柱屈曲、梁柱一阶屈服、以及筋材绕板接线的**扭转/侧扭屈曲（tripping）**。
船体梁极限强度计算（Smith 渐进塌陷法）要求把这四种模式的**最小者**逐单元装载、沿应变
路径积分得到板架平均应力-应变曲线的峰值 σ_u。

基准算例（典型油船/散货船内底板）：

| 参数 | 符号 | 值 |
|---|---|---|
| 横向框架间距（柱计算长度） | a | 2.400 m |
| 筋距 | b | 0.700 m |
| 板厚 | t | 12.0 mm |
| 筋腹高 / 厚 | h_s / t_w | 200 / 10 mm |
| 翼板宽 / 厚 | b_f / t_f | 100 / 15 mm |
| 材料 | E, ν, σ_y, H | 206 GPa, 0.3, 313 MPa, 1.0 GPa |
| 板格柔度 | β = (b/t)√(σ_y/E) | **2.274**（ Faulkner Φ = 2/β − 1/β² = 0.686 ） |

**基线（P70-N01 交付，commit 170acaa）的实测缺陷**——本节点的出发点：

| 缺陷 | 实测证据 | 性质 |
|---|---|---|
| σ_u 超过屈服 | 同一算例 σ_u = **374.23 MPa = 1.1956 σ_y** | 物理上不可能（受压构件平均应力不得超屈服） |
| 板架"边界约束"是硬编码凑数 | `σ_u^grillage = σ_u^iso·(1+0.05(n_y−1)/n_y)·(1+0.02(n_x−1)/n_x)`；3×3 = 391.87 MPa，5×5 = 395.43 MPa，相对差 **0.910%** | 收敛由构造保证，判据失效 |
| δ_iso 无机制 | +5.66%，来源即上一个乘子 | 不可审计 |
| tripping 未进塌陷路径 | `SmithCollapseSolver` 无 tripping 分支 | 模式缺失 |
| tripping 截面常数错误 | 翼板平移项取 h_s/2（应为 h_s+t_f/2）；带板以弯曲惯矩 t b³/12 混入**极**惯矩；扭/弯以 1/σ 串联 | 手抄常数，不可验证 |

## 2. 怎么做的（方法 / 工具链 / 关键设置）

### 2.1 薄壁开口截面（`panel_section.py`）

中面（thin-wall）模型：带板 `y=0`、腹板 `x=0, y∈[0,h_s]`、翼板 `y=h_s+t_f/2`。

* `A, ȳ, I_x, I_y`：矩形精确公式；
* `J`：薄壁 `ΣLt³/3`（j_thin）**与** 精确矩形级数（j_rect）双输出；
* `C_w`：Vlasov 扇形坐标一般算法（BFS 沿壁树积分 + 归一化 `∫ω dA = 0`）；
* 剪切中心：本文族（腹板 + 可选对称翼板）取闭式解 `y_sc = h_s + t_f/2`（T 型）/ `h_s/2`（扁钢）；
* `I_p,SC = I_x + I_y + A(y_sc − ȳ)²`（绕剪切中心的极惯矩，供扭转屈曲用），
  `I_p,att`（绕板接线）作为对照输出。

**与 TensorFEM 独立实现交叉对标**：`tensorfem.open_section_torsion.stiffener_properties(0.200, 0.010, 0.100, 0.015)`
给出 `J_thin = 1.7916666666666664e-7`，本模块对筋材单独取值的相对偏差 **< 1e-6**；
两者同时给出 T 型 `C_w ≈ 0`（中面模型退化，`1e-33` 量级），一致。

### 2.2 tripping 模式（`tripping_mode.py`）

弹性扭转屈曲应力（Vlasov / Timoshenko，绕剪切中心）：

```
σ_ET = [ G·J_s + π²·E·C_w,s / L_t² ] / I_p,SC / λ_trip
```

`λ_trip ≥ 1` 为侧向/扭转约束惩罚因子（板提供的转动约束按保守方向折算，λ_trip = 1 即
"筋材单独、无板约束"上界）。弹塑性折减用 **DNV-RP-C201 柱曲线**（`μ0 = 0.34`，curve b，
λ_T = √(σ_y/σ_ET)），因此模式连续切换：
`λ_T ≤ 0.2 → yielding`，`0.2 < λ_T < 1.5 → tripping`，`λ_T ≥ 1.5 → elastic_tripping`。

**闭式对标（marine_stiffener_failure）**：`ltb_critical_moment` 复现经典均匀弯矩 LTB 闭式解
`Mcr = (π/L)√(E I_y G J)·√(1 + π²E C_w/(L²GJ))`，并由 `ltb_numerical`（中心差分 Dirichlet
Laplacian 特征值，与 TensorFEM 同法但独立实现）验证。

### 2.3 成熟化 Smith 板架求解器（`panel_ultimate.py`）

等应变（iso-strain）并联装配，单元能力取四模式最小者（均为**名义/毛截面应力**）：

```
σ_P  = Φ·σ_y                                   Faulkner 板极限（板格局部屈曲）
σ_E  = π²E·I_eff/(s²·A_eff)·A_eff/A_gross       Euler 柱屈曲（柱长 s = 横框架间距）
σ_BC = 梁柱一阶屈服：σ_y,eff = P/A_eff + M·c/I_eff，M = P·w0/(1 − P/P_E)
σ_T  = 弹塑性 tripping 应力
```

* 有效宽度取 Faulkner 极限值（`b_e = Φb`），保有面积比 `A_eff/A_gross` 折减；
* 残余应力因子：`σ_y,eff = σ_y(1 − 0.15·residual_stress)`；
* 缺陷场 `w0(x,y) = w0p|sin(πx/s)sin(πy/b)| + w0c|sin(πx/s)|`，在 `n_x × n_y` 单元网格
  形心取样（`w0p = 5e-4 b`，`w0c = 1e-3 a`）；**局部贝坐标**定义，故 n_bays 个刚性框架舱
  与单舱严格等价（负控 ii 用此验证）；
* 柱模式**仅在筋材面积占比 ≥ 1% 时有效**：无筋时带板在面内受相邻筋线边支承，只会局部
  屈曲而不会作为"板柱"侧向失稳（否则退化算例会给出 4 kPa 的非物理 Euler 值）；
* σ-ε 曲线：弹性段（斜率 E）→ 平台段（长 `PLATEAU_STRAIN = 0.002`，理想塑性）→
  峰后卸载段（`SHEDDING_SLOPE = −0.02E`）。后两段**只影响峰后分支**，不改变 σ_u。

### 2.4 收敛判据的实现方式（为什么现在它是真判据）

σ_u 是单元能力对缺陷场的**面积平均**；`n_x × n_y` 网格用形心（中点）求积，因此 3×3→5×5
是求积误差的 O(h^p) 收敛，而非人为乘子。`grillage_error_bound.py` 的
`grillage_convergence_study` 同时给出 Richardson 外推与 1..17 序列，`isolated_element_deviation`
给出 δ_iso 的双参考（网格平均缺陷 / 名义设计缺陷）。

## 3. 计算结果（全部由 `results.json` 程序化给出）

### 3.1 板架极限强度与模式判决（5×5，基准算例）

| 竞争极限 | 值 [MPa] | 与 σ_y 比 |
|---|---|---|
| Faulkner 板极限 Φσ_y | 214.77 | 0.686 |
| Euler 柱（s = 2.4 m） | 1872.65 | 5.98 |
| 梁柱一阶屈服（w0 = w0p） | **205.31** | 0.656 |
| tripping（λ_trip = 1） | 221.35 | 0.707 |
| 有效屈服 σ_y,eff（残余应力） | 266.05 | 0.85 |
| **σ_u（面积平均峰值）** | **198.74** | **0.6349** |

判决模式 = `beam_column_yield`（25/25 单元），σ_u = 198.74 MPa = **0.635 σ_y**。
注意 σ_u 是**缺陷场上的面积平均**，故略低于单控极限（beam-column 205.31 MPa，−3.2%）——
这个差距正是 δ_iso,nominal ≈ +2.5% 所指的"用单单元代替板架平均"的偏差。σ_u 落在两个物理
下/上界之间（板极限 Φσ_y = 214.77 与梁柱极限 205.31 之下、被 tripping 221.35 放宽），
不超屈服，量级自洽。

### 3.2 误差界（判据 C2）

| 网格 | σ_u [MPa] | 与 5×5 之差 |
|---|---|---|
| 3×3 | 198.453 | — |
| 5×5 | 198.740 | — |
| 9×9 | 198.848 | +0.054% |
| 17×17 | 198.882 | +0.072% |
| Richardson 外推 | 198.901 | +0.081% |

**|σ_u^{5×5} − σ_u^{3×3}|/σ_u^{3×3} = 0.1445% < 2%** ✅
3→5→9→17 单调逼近；观测收敛阶 p = 1.66（介于中点法 2 与含缺陷离散 1 之间，如实记录）。
对照：1×1→3×3 的相对差 **2.39%**（是 3×3→5×5 的 16.5 倍，且已越过 2% 判据），
9×9→17×17 为 0.017%。三条量级说明判据确实有分辨力，不是"构造性收敛"。

**δ_iso（孤立单元偏差）**：定义 `δ_iso = (σ_u^panel − σ_u^iso)/σ_u^iso`，
σ_u^iso 为同一 intercolumn 单元在**板架平均单元缺陷**下的能力：

| 缺陷场 | σ_u^iso [MPa] | δ_iso | 符号 |
|---|---|---|---|
| 正弦场 | 198.668 | **+3.60e-4** | 正（凸性：孤立单元偏保守） |
| 随机场（CoV 0.35，均值保持对数正态） | 198.635 | **+5.30e-4** | 正 |

量级 1e-4，即孤立单元近似在此缺陷场下误差 **< 0.06%**；符号为正说明能力-缺陷关系在均值
邻域为凸（`w0` 超过一定值后才转为凹）。若以**名义设计缺陷**（w0p+w0c = 2.75 mm）为参考，
则 δ_iso,nominal = **+2.54%**（设计者用单单元算偏保守 2.5%）。

| s/a | s [m] | 柱计算长度 | σ_u [MPa] | σ_u/σ_y |
|---|---|---|---|---|
| 3.0 | 7.2 | 7.2 | 171.96 | 0.549 |

**严格单调不减** ✅（3a → 1a 提升 15.57%），且柱计算长度逐点等于 s（刚性横框架语义正确）。

### 3.4 tripping 与闭式对标（判据 C1 + C5）

| h_s [mm] | t_w [mm] | σ_ET [MPa] | λ_T | σ_trip [MPa] | 模式 | Mcr [kN·m] | Mcr/(I_p/c) [MPa] |
|---|---|---|---|---|---|---|---|
| 300 | 6 | 126.7 | 1.572 | 99.3 | elastic_tripping | 1.806 | 20.1 |
| 300 | 8 | 225.2 | 1.179 | 153.3 | tripping | 4.281 | 35.7 |
| 300 | 14 | 688.7 | 0.674 | 249.8 | tripping | 22.94 | 109.0 |
| 300 | 20 | 1402.3 | 0.472 | 280.5 | tripping | 66.89 | 222.0 |
| 200 | 10（+翼板 100×15） | 456.8 | 0.828 | 221.3 | tripping | 79.67 | 129.6 |

**Mcr 闭式解的独立数值复现**（中心差分 Dirichlet Laplacian，与 `tensorfem.marine_stiffener_failure`
同法、独立实现）：4/8/16/32/64 段的相对误差 = 1.637% / 0.507% / 0.142% / 0.038% / 0.010%，
**单调收敛，16 段 < 0.2%** ✅（判据 < 3%）。

**σ_ET 与 Mcr/(I_p/c) 的关系（必须讲清的一点）**：两者**不是同一个物理量**——
σ_ET 是纯扭转（Wagner）屈曲应力 `(GJ + π²EC_w/L²)/I_p,SC`，Mcr/(I_p/c) 是**弯扭**（LTB）
屈曲应力的等效值。当 `C_w → 0` 时其比值有闭式解
`σ_ET/(Mcr/(I_p/c)) = (GJ + π²EC_w/L²)/(Mcr·c)`，
数值上 T 型为 3.52、扁钢 300×8 为 6.32（`results.json:tests` 中以 1e-10 精度验证该闭式比值）。
因此本节点**不宣称**二者误差 < 3%；交付的是：闭式解本身被独立数值路径复现到 0.01%，
且二者的比值被解析闭式锁定（不可互换的物理说明见 §5）。

| 刀 | 物理设定 | 判据 | 实测 | 结论 |

## 5. 注意点（坑 / 局限 / 适用范围）

0. **没有任何实验/文献实测值可对标本算例的 σ_u**：本节点交付的是*内部一致性 + 极限退化 +
   闭式解复现 + 负控*四类证据，**不是**与试验或非线性 FE 的精度标定。因此 σ_u 的"精度"
   只能说"可复现、可审计、受四模式上界约束"，不能说"与实测误差 < 3%"。若需精度声明，
   下一步必须在同一几何上与壳单元弹塑性塌陷（或 Paik 等的试验数据库）做对标，这不在本节点范围。

1. **σ_u > σ_y 的基线缺陷**：`SmithCollapseSolver` 的板/柱应力混合式未受屈服上限约束，
   给出 1.1956σ_y。本分支加了一行屈服钳位（`|σ| ≤ σ_y,current`），并把成熟算力移入
   `panel_ultimate`；legacy 类保留仅为向后兼容（回归测试锁定 σ_u ≤ σ_y）。
2. **极惯矩的参考轴决定 tripping 应力**：绕剪切中心得 T 型 456.8 MPa，
   若把带板一起并入绕板接线的极惯矩则降到 ~30 MPa（数量级错误），会把所有板架误判为
   tripping 控制。本文取"筋材单独 + 绕剪切中心"，板约束只以 λ_trip 惩罚进入（保守）。
3. **中面模型下 T 型/扁钢 C_w ≡ 0**：这是薄壁理想化的退化（所有壁过剪切中心），
   TensorFEM 独立实现给出同样的 ~1e-41。真实 C_w 由壁厚偏置产生，量级 `(t_f/h_s)²` 更小；
   若将来要处理不对称/闭口剖面，需引入 Bredt 相容常数。
4. **无筋时柱模式必须关闭**：否则带板作为"板柱"的 Euler 应力（4.2 kPa/舱宽）会把 σ_u 拉到
   2.55 MPa（本节点开发中真实踩到，靠 `COLUMN_MODE_MIN_SHARE = 1%` 修正并写成负控 i）。
5. **缺陷场定义在局部舱坐标**：否则 1 舱与 n 舱不可比（负控 ii 曾因此差 0.99%）。
6. **σ_u 的定义**：等应变并联、面积平均曲线的峰值，属"最大应力"型 Smith 理想化；
   未含峰后卸载重分配（真实板架会向相邻单元卸荷），故 σ_u 略偏保守。
7. **λ_trip 是工程约束因子而非第一性原理量**：真实板提供的转动约束受板自身屈曲限制
   （k_θ 一旦按弹性板条算，`k_θL²/π² ≫ GJ`，会得到永不 tripping 的非物理结论）。
   本文把它显式参数化并在 §3.4 给出敏感度表，供标定而非隐藏。
8. **未覆盖**：焊缝/热影响区、双向受压、面内剪力、疲劳与裂纹、闭口剖面（Bredt）、
   筋材不对称（单侧翼板）的弯扭耦合、以及 3D 壳单元的塑性塌陷对标。

| 负控 (iv) 三段曲线 | 斜率 E / 平台 σ_y / 单调降 | 误差 0.0 / 0.0 / 严格 | — | ✅ |

**显式回答**：凡"同一物理量"的对标（J、I_y、Mcr 闭式解、Faulkner 退化、刚性框架退化、
tripping 关闭退化）误差均 **< 3%**（多数为浮点级 1e-16 ~ 1e-3）。唯一不满足 3% 的是
σ_ET 与 Mcr/(I_p/c) 这一对，**原因不是数值误差而是量纲一致性之外的物理差异**：前者是纯扭转
屈曲 `(GJ+π²EC_w/L²)/I_p,SC`，后者是均匀弯矩下弯扭屈曲的轴向应力等效；二者比值
`(GJ+π²EC_w/L²)/(Mcr·c)` 已由闭式锁定（tests 中 1e-10 精度），因此**不宣称 3%**，
也不把它当成 tripping 判据的替代。
