## ① 案例介绍（物理背景 / 几何 / 参数）

**物理背景**：本节点要为 TensorPhysics 的结构域提供**自主实现的 3D 等参固体单元内核**，
它是后续一切船体局部结构、冰载荷接触、塑性塌陷、极限承载分析的数值底座。
此前仓内只有薄壁扭转/板条/冰带板格等**降维**或**梁壳**模型（`structural_mechanics/`、`hull_icebelt_fem/`、`ice_plasticity/`），
没有可做三维体单元的通用内核——本节点从零补齐，并把「单元是否可信」这件事用五个可机器裁决的基准钉死。

**基准问题与几何**

| 基准 | 几何 | 目的 |
|---|---|---|
| 分片试验 (patch test) | 边长 1 的立方体 2×2×2 网格（Hex8，1 个内点）/ 3×3×3 网格（Hex20，44 个内点）；另做 0.25·h 随机畸变版 | 常应变/常应力精确再现 |
| 体积锁死 (locking) | 厚壁筒 a=1 m, b=2 m，1/4 环（θ∈[0,π/2]），平面应变，内压 p=50 MPa，4×8 网格 | ν→0.5 时体积应变精度 |
| 沙漏控制 (hourglass) | 同上厚壁筒，Hex8 1 点减缩积分；另有悬臂梁 L=10, h=b=1, P=1e5 N | 零能模式与稳定化能量占比 |
| J2 塑性 | 单位立方体单轴拉伸（位移控制）；厚壁筒塑性塌陷 | 径向返回映射 + 一致切线 |
| Lamé 锚 | 厚壁筒 a=1, b=2, p=50 MPa，平面应变，Hex20 4×8 | 弹性解析解锚 |

**材料与载荷参数表**

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 内核结构（`src/tensorphysics/solid_fem/`，纯 numpy + scipy.sparse，无外部 FE 依赖）

| 模块 | 内容 |
|---|---|
| `shape.py` | Hex8 三线性 + Hex20 二次 serendipity 形函数及**解析**自然导数；1pt / 2×2×2 / 3×3×3 Gauss 规则（权重和 = 8，机器精度） |
| `element.py` | Jacobian、B 矩阵（Voigt 工程剪应变）、`full` / `bbar`（Hughes 平均膨胀）/ `bbar_stab`（平均膨胀 + 膨胀脉动稳定化）/ `sri` 四种体积格式化；Flanagan–Belytschko 正交沙漏控制 |
| `material.py` | 各向同性弹性；J2 径向返回映射（线性等向硬化，dλ 上限截断保护）+ **解析一致切线**；单轴解析曲线 |
| `mesh.py` | 结构化盒网格 / 环扇网格；Hex8→Hex20 提升（共享棱中点并吸附到圆弧上）；协调压力载荷（面 Gauss 积分，法向由单元形心判定，与面局部位序无关） |
| `solver.py` | 稀疏装配、Dirichlet 求解、增量 Newton–Raphson（塑性状态存储于 Gauss 点，每步从**上一收敛状态**积分）、反力输出 |
| `verification.py` | 五类基准的驱动与度量（分片、锁死、沙漏、单轴、Lamé/极限内压） |

**关键离散/算法设置**

1. **形函数与积分**：Hex8 全积分 2×2×2（8 点），Hex20 全积分 3×3×3（27 点）；减缩积分 1 点仅配合沙漏控制使用。
2. **体积格式化**：
   * `bbar`（Hex8）：将应变算子膨胀行替换为单元体积平均 `B̄_v = (1/V)∫B_v dV`，偏量部分不动；常应变场下 `B̄ ≡ B`，故分片试验不受影响（实测到 1e-16）。
   * `bbar_stab`（Hex20）：平均膨胀 + 膨胀脉动惩罚
     `K += ε·K_bulk ∫(B_v − B̄_v)(B_v − B̄_v)ᵀ dV`，ε=1e-3。**这是本节点发现并修复的真实缺陷**：
     纯平均膨胀（`bbar`）对 20 节点 serendipity 单元有 **3 个伪零能模式**（9 个零特征值而非 6 个），
     在弯曲问题中放大出 62 倍位移；脉动项只惩罚非均匀膨胀，对均匀膨胀零贡献，故不损锁死性能（ν=0.4999 时 ε_v 相对误差 2.5e-5）。
   * `sri`（选择性减缩）：偏量全积分 + 膨胀用减缩规则（Hex8 1 点，Hex20 2×2×2）。
3. **沙漏控制**（Hex8 1 点）：4 个 Flanagan–Belytschko 基向量正交化到线性场（`γ = h − (h·x_i)B_i`，故 `γ·1 = 0`、`γ·x_i = 0`），
   稳定化刚度 `κ = α_hg·G·V^{1/3}`（量纲＝力/长度，物理尺度即"单元体积立方体的剪切刚度"，因此 α_hg=O(1) 无需魔法调参）。
4. **J2 塑性**：总应变式径向返回
   `q_tr=√(3/2 s_tr:s_tr)`，`Δλ=(q_tr−σ_y(α))/(3G+H)`，`σ = K tr(ε)1 + (1−3GΔλ/q_tr)s_tr`；
   一致切线 `C_ep = K 1⊗1 + 2Gθ P_dev − 9G²(1/(3G+H) − Δλ/q_tr) M⊗M`（`M=s_tr/q_tr`，`θ=1−3GΔλ/q_tr`）。
   塑性应变以**工程剪应变**存储（剪分量需 ×2），这个换算在开发中是第一号 bug（见 ⑤）。
5. **加载与边界**：Lamé/塑性筒用**协调面压力载荷**（面 Gauss 积分；1/4 环靠对称面约束 + `u_z=0` 实现平面应变）；
   单轴拉伸用位移控制（`u_x = 0.003` 于加载面，侧向自由），反力求和得到 σ_xx。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **工程剪应变 vs 张量剪应变（最贵的一坑）**：塑性应变初版按张量剪应变存储（`Δε_p = Δλ(3/2)s/q`），
   而 Voigt 向量存的是**工程**剪应变，剪分量需 ×2。该错使返回映射在纯剪下偏差 ~2 %，
   并让一致切线自检在纯剪工况给出 **24.5 %** 的不自洽（多轴工况 6 %）。
   修正后三个塑性工况的一致切线误差降到 1e-10 量级——**"自洽切线 vs 中心差分"这个自检本身是抓 bug 的关键工具**。
2. **弹性矩阵剪分量系数**：`C = 2μ·dev_eng + K·1⊗1` 中 `dev_eng` 的剪对角必须取 1/2（使 `C[3,3]=G`）。
   错写成 2μ 会让纯剪刚度翻倍，而"应力=矩阵×应变"的自洽检验察觉不到（必须与解析 τ=Gγ 对照）。
3. **Hex20 + 纯平均膨胀（B-bar）不稳定**：9 个零特征值（含 3 个伪模式），L=10 悬臂一次放大 62 倍位移。
   修复方案 `bbar_stab`（膨胀脉动惩罚，ε=1e-3）把秩恢复到 6，且 ν=0.4999 下 ε_v 误差仍为 2.5e-5。
   **但它在"壁厚方向只有 1 层单元"的弯曲问题上仍偏差过大（62 倍）**——这是已识别、未彻底解决的局限（见下条）。
4. **Hex8 的剪切锁死（已知局限，本节点未实现不协调模式）**：细长弯曲（L/h=10）下，即使 4 层单元，
   8 节点实体仍系统性偏刚 ~38 %（全积分 39.98 %、B-bar 38.13 %），而 Hex20 收敛到 1.7 %。
   1 点 + 沙漏控制可以改善弯曲（α_hg=0.1 时 59.6 % 偏软，α_hg=1.0 时 95 % 偏刚），但对 α_hg 敏感。
   **结论：弯曲主导问题请用 Hex20（全积分）或按壁厚细化 + QM6 类不协调模式（后续节点）**；本内核的强项是体积/压力主导与塑性塌陷问题。
5. **SRI 的应变输出不自洽**：减缩积分的膨胀由 1 点（Hex8）/2×2×2（Hex20）控制，而应变恢复用全积分 B，
   因此 SRI 的"逐点 ε_v/应力"误差数字（表中 2.96e1 / 9.03）是**报告不一致**而非物理失真（其位移误差 7.4e-3 正常）。
   判据 (b) 只用 B-bar 系列；SRI 仅作位移层面的对照。
6. **压力载荷方向判定**：面法向由"面形心相对单元形心"定向，与局部位序无关；环扇内壁的形心半径是弦中点半径
   （r·cos(Δθ/2)），用形心半径做"是否内壁"的判据会漏选面——改为判 `max(角点半径) ≤ a`。
7. **位移控制的重启动语义**：从已收敛状态继续加载时，`load_vector` 必须是**总载荷**而非增量
   （否则残差恒为 0，求解器"立即收敛"、位移不再增长——曾导致塌陷曲线完全平坦）。
8. **适用范围**：小应变、几何线性、各向同性、单一材料；无接触、无大转动、无动力学。hex20 的体积格式化需 ≥2 层壁厚单元。
