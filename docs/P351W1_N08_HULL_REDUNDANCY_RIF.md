## ① 案例介绍（物理背景 / 几何 / 参数）

**物理问题**：冰区船在碰撞、搁浅、局部冰压破损后，规范要求"剩余强度"仍能承受设计弯矩。
本节点回答一个比"剩余强度够不够"更细的问题：**哪些构件的单独失效仍能把船体梁极限弯矩保持在完好状态的 80% 以上（冗余构件集），哪些构件是单点失效即击穿 0.8 门槛的关键构件**，并给出**构件级失效谱**（RIF 矩阵）与**失效位置敏感性**。

**目标截面**（两个）：
1. **主截面** `p350w1_n03_combined`：P350W1-N03 的板-梁组合（底部/甲板加筋板格）由双壳舷侧闭合成的理想化中横剖面箱型截面，B = 24.0 m、D = 20.0 m、肋距 a = 2.4 m、纵骨间距 0.8 m；材料 MS 钢 E = 206 GPa、ν = 0.3、σ_y = 235 MPa、H = 1 GPa。**12 个板条构件 + 6 个筋组构件 = 18 个构件**（满足"板条 ≤12 × 筋 ≤8"）。
2. **副截面** `double_hull_side`：双壳舷侧组件独立成梁（外板/内板各 3 条 + 上下闭合板 2 条 = 8 板条，6 筋组），用于检验冗余排序是否为截面无关。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**内核复用**：元素本构直接复用已验证内核 `elastoplastic_collapse`（板 load-end shortening 曲线 + J2 单轴曲线），本节点在其上建**截面级增量 Smith 求解器**，不重写已验证部分。

**截面级增量 Smith 法**（`hull_redundancy.smith.SmithSectionSolver`）：

1. 破损截面离散为纤维：每个板条 1 根纤维（质心），每个筋组 `n_web` 根纤维（沿腹板高度）；
2. 逐级施加曲率 κ（从 κ_max/n 到 κ_max = 6e-4 1/m，共 80 级；sagging κ>0 / hogging κ<0）；
3. 每级 κ 下用**二分法**解轴力平衡 `N(ε0) = Σσ_i A_i = 0`（N 对 ε0 单调），得瞬时中和轴 `z_NA = -ε0/κ`；
4. `M(κ) = Σ σ_i A_i (z_i − z_NA)`；`M_u = max_κ M(κ)`（峰值在扫描区间内部，非边界截断——有测试保证）。

**三种构件失效模式**（`hull_redundancy.damage`）：

| 模式 | 力学含义 | 实现 |
|---|---|---|
| `remove`（板带撕裂 / 构件彻底移除） | 面积归零；若为筋，则其支持的板格失去该支持线 | 面积 → 0，关联板条屈曲宽度 ×2 |
| `trip`（筋 tripping） | 筋侧向-扭转失稳，**保留剪切连接**（仍焊在板上），刚度耗尽 | 压应力上限 = σ_cr,trip，且超过后为零切线平台（理想塑性平台）；板格支持保留 |
| `debond`（组合作用丧失） | 焊缝不再传递横向作用：筋退化为裸压杆，其支持的板格跨到相邻仍有连接的纵骨 | 压应力上限 = 裸压杆 Euler（Johnson-Ostenfeld）；关联板条屈曲宽度 ×2 |

**三个关键本构决策**（都有测试与文献锚）：

- **板格有效屈曲应力**（`effective_plate_buckling_stress`）：直接取弹性 σ_cr（k=4）时，0.8 m×16 mm 板格的 σ_cr = 298 MPa > σ_y，板永不软化，M(κ) 无峰值（实测 M 在 κ=2e-3 仍单调上升）。用 Faulkner 强度 `φ(β)σ_y` 反标定 `σ_cr,eff = min(σ_cr,elastic, (φσ_y)²/σ_y)`，使 von Karman 分支 `√(σ_cr,eff σ_y) = φσ_y` 精确复现 Faulkner 强度，峰值因此成为真实极限点。
- **tripping 应力**：绕焊趾转动，`σ_cr,trip = G J / I_p`，`J = h t_w³/3`，`I_p = t_w h³/3 + b_e t³/12`，`b_e = min(0.4a, b/2)`，加 Johnson-Ostenfeld 修正 → 甲板 300×11 FB：**106.3 MPa (0.45σ_y)**；底部 350×12 FB：**93.0 MPa (0.40σ_y)**（细长平钢球扁钢早tripping，符合工程常识）。
- **裸压杆应力**：`r = h/√12`、`σ_E = π²E/(a/r)²` + J-O → 350×12 于 a=2.4 m：**231 MPa ≈ σ_y**。即 2.4 m 肋距下裸压杆仍是屈服控制，**组合作用丧失的惩罚主要落在板格支持丧失上**（屈曲宽度 0.8→1.6 m，φ 由 0.833→0.504），这是本截面下的真实力学结论。

**失效模式严重度排序（构造上）**：`remove > debond > trip > none`（`SEVERITY_RANK`），并逐项数值验证。

**工具链**：numpy + 自实现 Spearman（含并列秩平均，不依赖 scipy）；`scripts/run_p351w1_n08_rif.py` 一键产生全部 JSON + 5 张图；`pytest tests/test_hull_redundancy.py` 34 项。

**结论**：主截面（双壳箱型）在 **sagging/hogging 两个方向**上，**任意单构件任一失效模式**下 RIF ≥ 0.8348（sagging 甲板板带撕裂最不利），即"任意单构件失效后 RIF ≥ 0.8"的构件集合 = **全部 18 个构件**。
**副截面（双壳舷侧独立成梁）**则给出反例：PO1（sagging）/ PO3（hogging）单构件移除 RIF = **0.7963 < 0.80** → 关键构件 1 个。说明该指标**有分辨力**，不是恒真的"全冗余"。构件越粗（分组越少）损伤越大，因此主截面的"全冗余"结论是**保守侧**结论（细分构件只会让 RIF 更接近 1）。

| 方向/构件 | remove | debond（组合作用丧失） | trip（tripping） | remove<debond | debond<trip | 最小间隙 |

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **坑 1：板格无峰值**。板格 σ_cr 弹性值（298 MPa）高于 σ_y 时，`plate_load_shortening_stress` 退化为纯单轴硬化曲线，板永不软化，`M(κ)` 到 κ = 2e-3 仍单调上升（实测 M_u 从 2991 → 3099 MN·m），"极限弯矩"实为扫描边界值。修正为 Faulkner 反标定 σ_cr,eff 后峰值出现在 κ = 2.55e-4（内部点）。**这是本节点最重要的数值陷阱**，已加测试 `test_moment_curvature_has_interior_peak`。
2. **坑 2：弹性中和轴不是负控基准**。sagging 下 PD2 附近的"中和轴"取弹性值 9.526 m 时，舷侧中段 PO2 距其仅 0.47 m，但移除它 RIF = 0.9525（若按弹性中和轴做负控判据会误判为不通过）。真因：极限状态甲板卸载，塑性中和轴降到 5.691 m，PO2 距塑性轴 4.31 m，力臂不可忽略。判据 (b) 因此按**极限中和轴**选取最近构件（PI1 0.9930、PO1 0.9907 ≥ 0.98 ✓），并把弹性轴读数（0.9525/0.9661）作为**发现**如实报告，不掩饰。
3. **坑 3：`benchmark_vs_smith` 必须传损坏态的 Smith 值**。首版误把完好 M_u 传给损坏算例，得到 12.5% 虚高误差；修正后完好 0.37%。
4. **局限 1（基准类型）**：判据 (d) 的基准是**已发表闭式方法**（Faulkner 1975 板强度 + Paik & Thayamballi 2003 第 5 章"简化法"刚塑性求和），**不是试验数据**——仓内没有受损船体梁试验数据集，也无外网。故为**方法级基准**，已在 criteria.json 的 `limitation` 字段声明。试验数据级对标 = WITHHELD，不粉饰。
5. **局限 2（理想化）**：未建模腹板/翼缘局部屈曲、残余应力、断裂/撕裂后承载力（拉侧只到屈服）；板条为分组超单元，构件粒度=1/3 板格；tripping 上限按理想塑性平台（无 post-tripping 陡降）。截面为代表性尺度而非施工图。
6. **局限 3（副截面单调性）**：副截面 ρ = −0.730 未达 −0.8，原因已量化（面积差 5.6 倍混杂秩）；剔除闭合板后 −0.873。判据在主截面（战役目标截面）两个方向均满足。
7. **适用范围**：单构件失效、静态单调弯曲、无腐蚀折减、无温度效应；不适用于多构件同时失效（组合损伤）或疲劳-极限交互。
