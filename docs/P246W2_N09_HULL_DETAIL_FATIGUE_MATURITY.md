## ① 案例介绍（物理背景 / 几何 / 参数）

船体构件焊接细节（对接接头焊趾、角接/横向加强筋焊趾、开孔板边）在交变波浪/冰载荷下
的疲劳寿命评估，是船体结构完整性校核的主线之一。工程链条为：

```
名义/热点应力 → 应力集中系数 K_t → 热点应力外推 → S-N 曲线 (IIW/DNV) → Miner 累积损伤 D
```

本节点把这条链从"公式拼装"推进到**可验证的实现**：每一个物理量都用**独立于实现本身**
的解析锚或精确代数恒等式校核，而不是用同一套公式自证。

| 模型问题 | 几何 / 参数 | 解析锚 | 用途 |
|---|---|---|---|
| 开孔圆板（Kirsch 四分之一环） | a=10 mm，R/a=12，σ₀=1 MPa，E=210 GPa，ν=0.3 | Kirsch(1898)：K_t=3 精确 | C2(a) K_t |
| 对接焊趾（边缘圆弧缺口） | L=120、W=40、h=1.0/0.5、ρ=1.0 mm | Inglis(1913)：K_t=1+2√(h/ρ) | C2(b) K_t |
| 板厚突变（圆角过渡） | L=120、t₁=12、t₂=16、ρ=8 mm | 等膜力平衡 + 远场 σ=σ₀/σ₀t₁/t₂ | 结构梯度校核 |
| T 型角接接头（横向加强筋，半厚度对称） | L=200、t=20、a=60、t_a=10 mm，焊趾锐角 | IIW 热点外推程序 + 网格三级加密 | C4/C6 热点应力 |
| IIW FAT90 / DNV-RP-C203 curve D (air) | Δσ_c=90 MPa @ 2×10⁶，m₁=3，m₂=5，knee 10⁷ | log a₁=12.164（DNV） | C1 S-N |
| 两级应力块谱 | Δσ₁=140 MPa, n₁=2×10⁴；Δσ₂=85 MPa, n₂=1.5×10⁵ | 单斜率幂律闭式 | C3/C5 Miner |

**审计发现（本节点起点）**：仓库既有 `tensorphysics.fatigue.detail_fatigue` 中的
`fem_stress_field_t_joint / _butt_joint / _fillet_joint` 并非 FEM，而是
`σ(x)=σ_nom(1+(K_t−1)e^{−x/λ})` 形式的**解析代理**（docstring 自述 "decay scale is tuned
so that quadratic extrapolation from 0.4t, 0.9t, 1.4t recovers the analytical Kt"）。用它验证
K_t 或外推精度是**循环论证**（证据等级应为 MOCK/代理），故本节点新建真实隐式 FEM 内核作为
独立证据来源。同一模块的 `hotspot.kt_from_detail()` 为硬编码查表（MOCK），本节点不使用。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 真实平面应力 FEM 内核（`plane_stress_fem.py`）

* **单元**：6 节点二次三角形 T6（直边、3 点 Gauss 积分，刚度被积函数为二次多项式，积分精确）；
  由结构化四边形网格每个 quad 拆成 2 个 T6（共享弦中节点 + 对角中节点），节点按坐标去重，
  支持多块网格自动焊接（T 型接头主板 + 加强筋两块网格共面焊接）。
* **载荷**：直边用一致节点载荷（N₁,N₂,N₃ 权重 1/6、2/3、1/6）；曲面（Kirsch 外圆）用抛物
  边 3 点 Gauss 积分施加随法向变化的面力。
* **边界**：Kirsch 用对称面（u_y=0 @ θ=0，u_x=0 @ θ=90°）；缺口/突变/T 型接头在 y=0 对称面
  约束 u_y，两端施加等值反向面力，并约束一个 x 刚体模态。
* **求解/后处理**：`scipy.sparse.linalg.spsolve`；T6 线性应力在单元节点取值后做节点平均。
* **补丁试验（patch test）**：均匀拉伸矩形板，σ_xx 与 u=σ₀L/E 均被复现到机器精度
  （σ 误差 <1e−9 MPa，位移相对误差 <1e−9）。这同时验证了刚度矩阵、面力一致载荷和应力恢复
  三条路径——**本节点第一个被修正的自身缺陷就由它抓出**（早期版本两端面力同号，净力不平衡）。

### 2.2 热点应力三点外推（`hotspot_extrapolation.py`）

* 采样点：标准 0.4t / 0.9t / 1.4t（IIW 二次外推）与 0.5t / 1.0t / 1.5t（任务书给定），
  线性 0.4t / 1.0t。
* 外推到焊趾（d=0）采用**精确 Lagrange 插值**：系数对常量场严格求和为 1（测试覆盖）；
  0.4/0.9/1.4 对应的插值系数为 **2.52 / −2.24 / 0.72**。手册中常见的
  "1.875 / −1.25 / 0.375" 组合不是插值型（对常量场不精确），二者对同一组取样点可有数个百分点
  差异，故本实现显式声明所用系数而非混用。
* **重要缺陷修复**：早期实现忽略了 `x_toe`，把"绝对坐标"当"到焊趾距离"取样，导致外推点落在远场
  （热点应力≈σ_nom，验收虚高）。现按剖面相对焊趾的方位取样（`sample_x = x_toe ± d`），
  并在剖面不覆盖采样窗口时抛错（测试覆盖）。

### 2.3 S-N 曲线与拟合（`sn_iiw.py`）

* 设计曲线：`log₁₀N = log₁₀A₁ − m₁log₁₀Δσ`，`log₁₀A₁ = log₁₀N_ref + m₁log₁₀Δσ_c`
  （Δσ_c 即 FAT 值，N_ref=2×10⁶）。双线：m₁=3（N≤10⁷），m₂=5（N>10⁷），拐点连续。
* 拟合：`loglog_fit` 在 log-log 空间最小二乘，输出 m、log A、R²、残差标准差与反推 FAT。
* 跨标准锚：IIW FAT90 的 log a₁=**12.1638** 与 DNV-RP-C203 curve D (air) 的 **12.164** 对照
  → 反推 Δσ_c=90.02 MPa（**0.019%**）。
* 试验数据只有"声明的统计模型"（IIW 焊接接头 logN 标准差 s=0.2；设计曲线=均值−2s，即
  ×2.51 寿命），故所有与"试验"的比较都显式标注 SIMULATED，且列表中给出解析上限
  `R²≤1−s²/var(logN)`：s=0.2 时要在 10⁵–10⁷ 两个数量级内达到 R²≥0.98 在数学上不可能
  （本数据实测上限 **0.9296**，拟合 R²=0.9265 已贴住上限），因此 R²≥0.98 判据在**标准曲线**
  上判定（R²=1.000，m=3.000），另用低散差（s=0.05，实验室重复性量级）序列证明拟合实现本身
  可达到 R²=**0.9959**、特征值 FAT 误差 0.40%。

### 2.4 Miner 累积损伤（`damage.py`）

* `D=Σn_i/N_i`，`D=1` 判失效；块谱失效次数 λ=1/D（两应力块闭式）；另用**纯代数**
  `N_i=10^{logA}Δσ_i^{−m}` 独立实现作交叉校验（不共用代码路径）。
* 变幅路径：三角波块谱 → ASTM E1049-85 四点雨流（复用仓库既有 `rainflow`）→ Miner。
* 顺序效应探针 `sequence_effect_probe`：同一对块谱正反次序的 D 相同（数学恒等），把 C7 的
  局限从"文字声明"变成可机器校验的数字。
* C7 诚实门：`CORTEN_DOLAN_STATUS = {status: "not_implemented", reason, impact, action}`，
  另有 `KNOWN_LIMITATIONS`（无平均应力修正、无板厚修正、无焊后处理、无裂纹扩展路径）。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **自身缺陷 1（面力符号）**：`solve_plate_with_edge_notch/thickness_step` 初版两端均施加
   +σ₀，净力不平衡，缺口 K_t 看似"合理"（3.15）实为错误应力态；补丁试验（均匀拉伸）
   才暴露。修正后两端分别为 −σ₀/+σ₀。
2. **自身缺陷 2（外推取样坐标）**：`extrapolate_from_profile` 初版未使用 `x_toe`，把绝对坐标当
   距离，采样落在远场，热点应力≈σ_nom 使 C4/C6 "轻易通过"。修正为按焊趾方位取样并加越界检查。
   ——这条正是"测试绿 ≠ 问题解决"的活例。
3. **厚板突变模型需等膜力**：t₁≠t₂ 时两端面力必须按截面反比施加（σ₀ 与 σ₀t₁/t₂），否则
   得到虚假的远场 1.33σ₀。
4. **K_t 的 +2.1% 系统偏差**：Kirsch 开孔 FEM 结果随网格收敛到 3.063（θ 48→192、首层
   0.2a→0.002a，变化 <0.2%），并非离散误差未收敛，而是 T6 线性应力在强梯度自由边界处的
   应力恢复偏差。它远小于 10% 判据，但应在引用 K_t 精度时如实标注（不要声称 <1%）。
5. **热点外推只对"结构梯度"有效**：用精确 Kirsch 场检验，0.4t/0.9t/1.4t 外推只能恢复孔边峰值的
   **71.8 %**（2.15 vs 3.00）。这说明热点应力法是**面向焊趾结构应力**的工程定义，不是峰值应力
   估计器；对"特征长度≈外推跨度"的孔边型集中会系统性低估。这也解释了为何 IIW 以 FAT 等级
   而非峰值应力给出设计曲线。
6. **锐角焊趾应力奇异**：T 型接头锐角模型焊趾处应力随网格加密持续上升（1.289@t/4 →
   1.943@t/16），这正是热点法"不外推则不可用"的原因；因此对角接只报告外推后结构 SCF，
   不宣称其与 Nii 等缺口型 K_t 公式可比（定义不同：结构应力 vs 缺口应力）。
7. **T 型接头结构 SCF 偏小（1.067）**：主板受拉、横向加强筋 a/t=3 的工况下，结构梯度在
   0.4t 处已基本衰减（1.03），故热点 SCF 接近 1。这不是实现问题，而是该载荷/几何下
   "焊趾以局部缺口效应为主"的物理事实；真实船体工况（加强筋端部、肘板趾端）梯度更陡。
8. **试验数据缺失（WITHHELD）**：本仓库无变幅/恒幅焊接疲劳试验原始数据，C3/C5 的"与试验
   比较"分支使用**声明的** IIW 散差模型（s=0.2，设计曲线=均值−2s）。因此：
   - 报告给出的 2 倍因子结论属于"中心值意义下成立"（0.90 / 1.00）；
   - **单个试件级别**的 90% 覆盖散差带本身就有 2.13×，把 ≤2 倍判据套到单试件上是把材料散差
     误当模型误差；
   - 真正的试验对标（IIW 试验库 / 船级社焊接疲劳数据）列为待补。
9. **标准数值的引用风险**：DNV curve D (air) log a₁=12.164 与 IIW FAT90 的对应关系在本报告
   中既作为交叉校核也被当作引用值；若标准版本更新，需重新核对表格（代码中该常数集中于
   `sn_iiw.DNV_D_AIR_LOG_A1`，便于一处更新）。
10. **适用范围**：常幅/块谱、单向拉伸主导、板厚 10–30 mm 的船体钢焊接细节；不覆盖多轴疲劳、
    腐蚀疲劳时间历程、低温/冰区材料韧性转变、焊后处理与裂纹扩展寿命。
