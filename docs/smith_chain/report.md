## 1. 案例介绍

### 1.1 物理背景

Smith 方法（逐截面递增曲率法，Smith 1977）是船体梁极限强度分析的主流方法：把剖面离散为中国纵向单元（板条 + 纵骨组），每个单元给一条平均应力-应变律（板件 von Karman 屈曲后曲线 + Faulkner 强度；纵骨柱屈曲/侧扭屈曲 Johnson-Ostenfeld 强度），逐级施加曲率 κ，由轴力平衡 N(ε₀)=0 求瞬时中和轴，积分 M(κ)=ΣσᵢAᵢ(zᵢ−z_NA)，峰值即极限弯矩 M_u。其物理正确性依赖三件事：**单元律正确**、**截面集成与中和轴迁移正确**、**离散化收敛**。本节点按尺度自下而上建三级链，逐项检验这三点：加筋板（只考单元律）→ 箱梁（考截面集成，且有解析塑性极限）→ 双底船体梁（考跨尺度放大、网格收敛与失效模式）。

## 2. 怎么做的（方法/流程/关键设置）

### 2.1 单元律（压缩正号）

**板件**：σ_cr,eff = min(σ_cr,el, (φσ_y)²/σ_y)，使 von Karman 支 √(σ_cr,eff·Eε) 恰在 ε_y 处取到 φ(β)σ_y 峰值（β=(b/t)√(σ_y/E)，φ=2/β−1/β²，β≤1 时 φ=1）。

```
σ(ε) = Eε                        ε ≤ ε_cr
     = √(σ_cr,eff · Eε)          ε_cr < ε ≤ ε_y   （屈曲后有效宽度支）
     = φσ_y − 0.02E(ε−ε_y)       ε > ε_y          （软化支，下限 0.2φσ_y）
受拉：J2 单轴（H=0 时理想塑性）
```

**纵骨纤维**：J2 单轴 + 压缩封顶（零切线）σ_cap = min(σ_y, σ_col, σ_trip)，其中
```
σ_col : 纵骨 + 有效宽度附着板（b_e = φ·b）的 Euler 应力，Johnson-Ostenfeld 修正
σ_trip: 绕焊线的侧扭应力 σ = GJ/I_p（J = h t_w³/3），Johnson-Ostenfeld 修正
```
板与筋共用同一套已验证内核，避免同一物理两套公式。

### 2.2 截面集成：两种加载模式、一个求解器

| 模式 | 适用 | 平衡 | 结果量 |
|---|---|---|---|
| `bending` | 箱梁/双底/船体梁 | 逐 κ 向量化二分求 N(ε₀)=0，M=ΣσᵢAᵢ(zᵢ−z_NA) | M_u=max|M(κ)| |
| `axial` | 加筋板/裸板 | iso-strain 均匀缩短，σ_avg(ε)=ΣAᵢσᵢ(ε)/ΣAᵢ | σ_u=max σ_avg |

峰值用**黄金分割**在粗扫最优 κ 邻域细化，使 M_u 不依赖曲率采样密度。截面类型由几何自动判定（板级数/蒙皮数/深宽比，`idealisation.classify_section`），判定结果只驱动**报告与参考量选择**，力学内核完全一致 —— 这就是 C6 的「统一接口支持多截面类型」。

### 2.3 网格收敛协议（预声明）

* 主细化参数：**n_sub**（每单元沿厚度纤维数），级别 [2, 4, 8]，细化比 r=2.0；腹板条带数冻结 8（一次只变一个离散参数）。
* 曲率峰值细化 60 次：开细化后四条序列严格单调；关细化时薄壁箱梁/双底曾出现 O(1e-5) 相对量反转（采样抖动，见 §5.3）。
* 次研究（敏感性，非主判据）：腹板条带 2/4/8 阶梯，单调性 {'sagging': False, 'hogging': True}。
* Richardson：p = ln|f₂−f₁|/ln r，f_ext = f₃+(f₃−f₂)/(r^p−1)，残差 = |f₃−f_ext|/f_ext。

### 2.4 失效模式自动识别（预声明规则）

极限状态按**压缩侧承载力损失**归因：L_e = A_e(σ_y−σ_u,e)|z_e−z_NA|（σ_u,e 取板 φσ_y 或筋 min(σ_y,σ_col,σ_trip)）；份额最大为主导机制，次者份额 ≥0.6 判为交互。三档剖面的模式预期在运行前由柔度判据给出：β>1→板屈曲；β<1→屈服；筋承载力低于板强度→筋控制。

## 5. 注意点（踩过的坑、局限、适用范围）

1. **硬化模量会让 M_u 超过解析塑性极限**。首轮沿用既有材料默认 H=1.0 GPa，紧凑箱梁给出 M_u/M_p=1.036（>1，非物理），原因是 J2 单轴律在大应变下把纤维应力抬到 σ_y 之上。基准材料改 H=0 后 M_u/M_p=0.9989。**教训：用塑性极限载荷做锚定前必须先关硬化。**
2. **有效宽度闭合解首版符号写错**（法向力用幅值相加而非带符号求和），使薄壁箱梁 M_EW=5.53 > 塑性极限 4.35（不可能）。修正后 M_EW=3.33 MN·m。**教训：任何「独立参考」也必须过物理边界自检（M_y ≤ M_u ≤ M_p）。**
3. **网格收敛的抖动来自曲率采样而非元素细分**。峰值改用黄金分割细化后四条序列严格单调；否则薄壁箱梁与双底出现 1e-5 相对量级反转。腹板条带阶梯（次研究）在 4→8 仍有 O(5e-4) 非单调，已登记。
4. **iso-strain 面板法在 β=3 时高于 CSR 设计式 16.6%**（β=1.5 时 10.8%）。原因：面板平均强度 = ΣAᵢσᵢ/ΣA，板仅占约 58% 面积时纵骨仍按其自身承载力贡献，必然高于「最弱模态」设计值。这不是求解器误差（与面积加权闭合解一致到 <0.01%），而是 **iso-strain 假设不含筋触发式坍缩（snap-back）** 的固有上界性质；C3 取 β=2.0（板控制、两者几乎重合）正是避免把方法差异当数值误差。
5. **Paik & Thayamballi (2003) 经验式与 iso-strain Smith 相差约 1.5 倍**（β=2.0：0.512 vs 0.758）。系数凭记忆转写、离线不可复核，故**只作参考展示、不进入任何判据**；两者差异本身列入后续查证项。
6. **文献/试验锚 WITHHELD（本节点最大局限）**：ISSC 2009 双底原始几何与 M_U、Dow (1991) 箱梁试验极限弯矩无法在本工作树内核实，因此本节点建立的是「**方法内部一致性 + 解析极限正确性 + 离散自收敛**」，**并未建立与试验的绝对精度**。C4 以精确塑性极限（紧凑箱梁，误差 0.11%）与有效宽度闭合解（薄壁箱梁，差 5.30%）替代试验锚，属方法自主选择，在此显式声明。下一步：取得 ISSC2009 原始坐标/结果表与 Dow 1991 试验数据后补一轮绝对精度对标。
7. **纵骨侧扭采用扁钢绕焊线公式**（既有已验证内核），对 T 型材会低估约束、偏保守；本文三档均为扁钢故不受影响，但用于真实船体剖面时需扩展 T 型侧扭公式。
8. **双底 sagging 的 M_u/M_y,comp < 1**（0.739）不是错误：受压翼缘（内底板 β=2.08）在达到 σ_y 前就屈曲，剖面从未「首屈服」，故极限弯矩低于弹性首屈服弯矩。
