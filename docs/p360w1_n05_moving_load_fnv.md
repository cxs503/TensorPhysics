## 1 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理问题

船在碎冰航道中以航速 `V` 前进。在船体坐标系里，海冰不再"静止"：一块浮冰在艏部接触船体后，
接触斑随船体相对运动**以 `V` 沿船长向后扫掠**，在扫过该浮冰自身的接触长度 `s` 后分离；
下一块浮冰随即在艏部接触。于是船体梁受到的是

1. **时间调制**：接触力以重复频率 `f_ice = V / s` 脉冲式加载（碎冰的脆性-延性破碎锯齿，
   每次破碎有突降）；
2. **空间调制**：载荷作用点沿船长移动，逐个扫过各阶模态的振型。

当 `f_ice` 命中船体梁某阶固有频率 `f_n` 时，即 `V = V_cr = s·f_n`，进入**移动载荷共振**。
本节点要给出的工程结论是：在哪些航速下船体梁响应不可接受，以及国际冰级规范关心的
居住性指标

    FNV = a_max / (g · f_dom)

（`a_max` 峰值加速度、`f_dom` 主导频率、`g = 9.80665 m/s²`）落在 habitable / tolerable /
unacceptable 哪一档。

**注意两种"临界速度"的区别**（本节点最容易被混淆的一点）：

| 类型 | 公式 | 本算例数值 | 可实现性 |
|---|---|---|---|
| 经典单力移动载荷临界速度（简支梁） | `V_cr = ω_n L / (nπ)` | 158.80 m/s（`n=1`） | 不是船舶航速，仅作力学校核（A2 用） |
| 碎冰接触重复临界速度（本节点物理主用） | `V_cr = s · f_1` | 4.956 m/s | **≈ 5 m/s，正是任务给定航速** |

任务书给出的 `V = 5 m/s`、`V/V_cr = 0.5/0.8/1.0/1.2` 只有按第二种定义才有物理意义：
本算例把平均浮冰长度取为 `s = 4.13 m`，使 `V_cr = 4.956 m/s` 恰落在给定航速附近。

其"窄带 vs 原始峰值"口径差异在 §5 显式声明。

## 2 怎么做的（方法 / 流程 / 工具链）

### 2.1 船体梁（`beam.py`）

均匀 Euler-Bernoulli 梁 `EI w'''' + ρA ẅ = p(x,t)`，两种支承条件严格分离：

- **自由-自由**（浮船体梁的物理配置）：`ω_n = (β_nL)² √(EI/ρA)/L²`，`cosh(βL)cos(βL)=1` 的根
  （`n ≥ 5` 用渐近式 `(2n+1)π/2`）；振型直接用仓库既有已核验助手
  `tensorphysics.ice_vibration.modal.free_free_beam_mode_shape`（不重复造轮子）。
  刚体模态剔除，只保留弹性模态。
- **简支**（移动载荷文献的标准配置）：`φ_n = sin(nπx/L)`，`ω_n = (nπ/L)²√(EI/ρA)`，
  `m_n = ρA L/2`。A1/A2 的解析参考只在此配置下成立。

模态基 `ModalBasis` 统一给出 `ω_n`、`m_n`、`k_n = m_nω_n²`、振型/曲率求值器与
`c_n = 2ζ_nω_nm_n`，下游（移动载荷、FNV）与支承条件无关。

**独立校核**：`beam_fem_frequencies` 用 Hermite 三次梁单元（2 节点 4 自由度）+ 一致质量矩阵
装配 60 单元，Cholesky 白化后解标准特征值问题。该路径与解析式无共享代码，纯作核验。

### 2.2 碎冰移动载荷（`ice_field.py`）

- 浮冰长度 `s_k ~ LogNormal(s, cv)`，强度因子 `β_k ~ LogNormal(1, 0.2)`；
- 第 `k` 块浮冰在 `t_k` 于艏部接触（`x = L`），接触期内作用点
  `x_k(t) = L − V(t − t_k)`，扫过自身长度 `s_k` 后分离；接触时间间隔 `T_k = s_k/V`；
- 接触力为脆性-延性锯齿：`F_k(t) = β_k F_max [ r + (1−r)·phase ]`，`phase` 在每次破碎后归零
  （`r = 0.4` 为残余水平）；
- 输出 `ContactForceHistory`（`t, F(t), x_p(t)`）+ 谱主导频率估计
  `dominant_frequency_hz`（Hann 窗 FFT + 对数幅值抛物线插值）。

### 2.3 运动方程与积分（`moving_load.py`）

模态叠加：`m_n q̈_n + c_n q̇_n + k_n q_n = F(t)·φ_n(x_p(t))`。两条独立求解路径：

1. **Newmark 平均加速度**（`β=1/4, γ=1/2`，模态解耦向量化）——生产路径，带阻尼、任意力时程、
   载荷沿船长移动。每个时间步同步记账四本能量：输入功 `W=∫ΣQ_nq̇_ndt`、应变能、
   动能、阻尼耗散（梯形积分）。
2. **闭式级数解**（常数力在简支梁上以 `V` 通过，零初值、无阻尼）
   `q_n(t) = (P/m_n)/(ω_n²−Ω_n²)·[sin(Ω_nt) − (Ω_n/ω_n)sin(ω_nt)]`，`Ω_n = nπV/L`；
   在 `Ω_n = ω_n` 处用 L'Hôpital 共振极限 `q_n = (P/m_n)[sin(ωt)/ω − t cos(ωt)]/(2ω)`。
   该路径是 A2 的参考解（300 阶截断，截断误差 ~1e-6）。

此外提供**频域第三路径** `steady_state_fundamental_amplitude`：把激励在目标频率上做复数
Fourier 投影，乘模态 FRF `1/(m_n(ω_n²−Ω²+2iζ_nω_nΩ))`，与时域积分无共享代码，用于核验
稳态窄带幅值（pytest 内 <15 % 一致）。

### 2.4 FNV（`fnv.py`）

- `f_dom`：对稳态窗（`t ∈ [15, 45] s`）的加速度做 Hann 窗 FFT 取最大峰 + 抛物线插值；
- `a_band`：在 `f_dom` 上做带 Hann 权的 `A cos + B sin + C` 最小二乘拟合，
  `a_band = √(A²+B²)`（**窄带幅值**，FNV 的物理一致口径）；
- `a_raw = max|a(t)|` 同时输出，给 `FNV_raw` 作透明对照；
- 判据分档：`FNV < 0.5` habitable，`0.5 ≤ FNV < 1.0` tolerable，`FNV ≥ 1.0` unacceptable。

- `V/V_cr = 0.8` 与 `1.2` 的主导峰落在 2 阶/高阶模（3.33 / 1.42 Hz）：远离一阶共振后，

- `V/V_cr = 0.5` 的 FNV（0.416）比 0.8 的（0.025）大，是因为低航速下脉冲间隔 1.67 s 仍远短于

  但整周期数少且每次冲击的相位在一阶带宽外，叠加反而不如一阶振铃的窄带能量集中。

### 表 6 辅助研究（非判据，但解释机理）

**(a) 浮冰间距规整度 → 共振质量**（`V = V_cr`）

| 浮冰长度 `cv` | FNV | `a_band` [m/s²] | 力谱主导频率 [Hz] |
|---|---|---|---|
| 5 % | 1.172 | 13.73 | 1.194 |
| 15 % | 0.769 | 8.98 | 1.187 |
| 35 % | 0.236 | 2.73 | 0.237 |

结论：共振建立需要脉冲序列在 `1/(ζω₁) = 26.5 s` 内保持相位相干（≈ 30 次接触）；
浮冰长度 `cv = 35 %` 时到达时刻抖动 0.29 s ≫ 共振半带宽对应的时间尺度，共振散相干，
FNV 掉到原来的 1/5。**这也说明真实碎冰场的"锁频"必然依赖冰-结构反馈的自组织**
（本模块是单向耦合，不含该反馈，见 §5）。

**(b) 移动 vs 定点接触**（`V = 4.956 m/s`）

| 工况 | FNV | `a_band` [m/s²] | 中点峰值 [m] |
|---|---|---|---|
| 接触斑沿船长扫掠（本节点主模型） | 1.172 | 13.73 | 0.2927 |
| 接触钉在艏部（关掉扫掠） | 1.491 | 17.48 | 0.3697 |

扫掠振型调制使共振幅值下降 21 %（1.172 / 1.491）——这就是移动载荷效应本身的量级。
另有：以同一航速通过的单力（简支参考梁闭式解）`V/V_cr^classic = 0.0312`，DAF = **1.030**，
即**纯平移在 5 m/s 是准静力的**，共振必须由接触重复（`f_ice = V/s`）提供。三件事合起来
构成完整的因果链：准静态平移 + 高重复率冲击 + 模态扫掠调制。

可对标的是①梁力学（解析解，误差 1e-4 量级）、②模态参数（独立 FE，1e-7 量级）、
③移动载荷动力学（闭式解，1e-7 量级）、④能量守恒（3e-6）。FNV 的量级依赖于设计中
峰值接触力 `F_max`（线性关系）、`ζ`（反比于幅值）、以及与浮冰规整度强相关的相干性，
这三者是**设计输入**而非本仓可验证的输出，见 §5。

## 5 注意点（踩坑 / 局限 / 适用边界）

1. **FNV 的"峰值加速度"口径**：任务书写 `a_max = max(|ü(t)|)`，而 FNV 除以单一主导频率。
   碎冰冲击是宽带激励，`max|ü|` 由多个模态的高频振铃叠加，与 `f_dom` 不同源；直接用会把
   高频抖动算进居住性指标（本例 `FNV_raw` 比窄带口径高 15–65 %，且 `V/V_cr = 1.2` 时
   高 6.7 倍）。因此本节点**主判据用窄带幅值 `a_band`**（同频同源），`FNV_raw` 一并输出、
   不隐藏。这是对任务口径的**偏差声明**（自主权·方法自主），属可复算选择而非放水。
2. **单向耦合**：冰力是给定统计时程，结构速度不回馈破碎过程 ⇒ 本模型**不能**复现速度弱化
   引起的自激锁频；因此浮冰长度离散 `cv ≥ 15 %` 时共振消失（表 6a）是模型的诚实结论，
   真机的锁频依赖反馈自组织。自激路径在 `tensorphysics.ice_vibration.lockin` 里，未在本节点合并。
3. **Euler-Bernoulli 假设**：无剪切变形/转动惯量/变剖面；一阶波长/梁深 = 30，尚在适用区，
   但高阶模态（`f > 10 Hz`）此假设偏刚。
4. **附连水**：`ρA` 取干船体（`added_mass_factor = 1.0`）。实际垂向振动附连水使 `f_n` 降
   `1/√(1.2–1.4)`≈ 10 %，共振航速随之左移——模块留了 `added_mass_factor` 参数并有测试
   （`test_added_mass_factor_shifts_frequencies`），本算例保守地不引入。
5. **`V=0` 静力判据用简支配置**：`P L³/(48EI)` 只在简支下成立；自由-自由梁的"中点挠度"
   是模态投影量（本算例 0.0321 m，约等于 `PL³/(48EI)` 的一半），不能拿来当静力基准。
   A1 因此固定在简支配置，A3 的 DAF 分母用自由-自由的静态模态投影量并在报告中标明。
6. **单力通过的阶跃起始**：`run_moving_point_load` 在 `t=0` 把满值载荷瞬间放上梁，会产生
   阶跃振铃（ζ=0.5 % 时衰减 26 s），量级可达静态的 1.5 倍，**不是**移动载荷共振。
   因此 §3 表 6b 的"单力"对比改用闭式解（`V/V_cr^classic = 0.03` 的准静力结论），
   不用带阶跃瞬态的数值解充当证据。
7. **算例依赖性**：FNV 与 `F_max` 成正比、与 `ζ` 成反比，`V_cr = s f₁` 又把浮冰尺度与一阶
   频率绑在一起。换船（`L`、`EI`、`Δ`）必须重算，不能搬数字。
8. **`Cb` 先行校验**：几何审计在任何动力学之前跑，`Cb` 由排水量反算不一致即判 FAIL，
   避免"几何错的漂亮结果"。
