# V&V machine gate — maturity record (mission IN48-N03)

Status: **engineering-usable**, with two honest FAILs left open and named.

This document supersedes the numbers of `docs/VV_GCI_ASME_GATE.md` for the parts
it re-runs, and adds the leg that was missing there: a **real
manufactured-solution study of a solver repository that recovers the design

(TensorLBM's shipped Poiseuille verification).

Everything below is regenerated by the commands in §8; the machine-readable
audit chain is `artifacts/vv_gate/summary.json`, which carries
`acceptance.<criterion>.{value,target,met,evidence}` for the eleven criteria
this repository tracks. Nine are met; the two open ones are
`c_cross_repo_lbm` (the solver-side case really does not converge at second

node and was not re-executed here — no local checkout in this worktree).

## 1. What the gate is

Input: one observable `f` evaluated on >= 3 grids (or timesteps) with grid
lengths `h`, plus the design order and, for validation, a reference value
`f_exp` with input uncertainty `U_input`.

Output, in one JSON record (`schema: tensorphysics.vv.gate/1`):

| field | definition |
|---|---|
| `order_p` | observed order of accuracy. Uniform `r`: `p = ln[(f_1-f_2)/(f_2-f_3)]/ln r`; non-uniform: least-squares fit of `f = f_exact + C h^p` (`order_source = "least-squares"`) |
| `f_extrapolated` | Richardson value `f_fine + (f_fine - f_medium)/(r^p - 1)` |
| `gci_fine` | Roache GCI `Fs |(f_fine - f_coarse)/f_fine| / (r^p - 1)`, `Fs = 1.25` for three levels, `3.0` for two |
| `convergence_type` / `convergence_ratio` | monotone (`0<R<1`) / oscillatory / stagnant / diverging |
| `gci_monotone` | GCI must not grow when the grid is refined (`>= 3` GCI pairs) |
| `noise_certified` | true only if per-level `sigma` is declared or `>= 4` grids are supplied |
| `validation` | ASME V&V 20: `U_val = sqrt(U_num^2 + U_input^2)`, `E = f_sim - f_exp`, `|E| <= U_val -> PASS` |
| `status` | `PASS / WARN / FAIL`, and the exit code of the CLI (`0/1/2`, `64` for a usage error) |

Physics of the decision rule: a study is accepted only inside the asymptotic
range — monotone contraction, `0 < p <= p_max`, GCI non-increasing under
refinement, and (with `>= 4` levels) a consistent order across triplets and a
small power-law residual. Anything else is a FAIL, never an unqualified PASS.

## 2. Positive control (criterion a)

`f(h) = 3 + 0.5 h^2`, `h = 1, 0.5, 0.25` (`r = 2`), declared design order 2
(`artifacts/vv_gate/controls/positive_control.json`):

| quantity | measured | target | met |
|---|---|---|---|
| `order_p` | `2.000000` | `2.000 +/- 0.01` | yes (`|dp| = 0`) |
| `|f_exact - 3|` | `0.0` | `< 1e-6` | yes |
| `GCI_fine` (`Fs = 1.25`) | `0.012886597938144331` | `1.25 * |df|/|f|/(r^p-1)` | identical |
| GCI vs `r = 2, 3, 4` (coarse grid fixed) | `0.05 > 0.0227 > 0.0129` | decreasing | yes |
| five levels (`r = 2`): `p` / power-law residual | `2.0000000000000027` / `5.6e-17` | asymptotic | PASS |

Note on "GCI decreases with r": for a *fixed fine grid* the relative GCI is
invariant in `r` (difference and denominator scale with `r^p - 1`), so the
informative sweep fixes the coarse grid — that is the variant tabulated and
plotted (`figures/fig_gci_vs_r.png`).

## 3. Negative controls (criterion b)

| control | measurement | verdict | evidence |
|---|---|---|---|
| oscillatory | `R = -0.5` | FAIL | `controls/negative_controls.json` |
| diverging | `R = 2.0` | FAIL | idem |

The last row is the honest boundary of the method and is new in this node: three
levels fit three numbers (`f_exact`, `C`, `p`) exactly, so an undeclared noise

information (14/25 seeds are caught) but more than 40 % of 1 %-noise studies
still look consistent. Callers who need noise protection must declare a
per-level `sigma` (`--strict` downgrades an uncertified three-grid result to
WARN) or supply `>= 4` grids; both paths are implemented and tested.

## 4. Cross-repository run A — TensorFVM manufactured solution (criterion c)

Case (unchanged, imported read-only): `tensorfvm.verification.native_order3d.
manufactured_solution_study(n)` solves `div(tau(u)) = source` on an `n^3`
hexahedral box (`h = 1/n`) for the native viscous operator used by the
collocated/RANS solvers, with the analytic divergence of the stress of

```
u* = [ sin(pi x) cos(pi y/2) e^z ,  cos(pi x/2) sin(pi y) e^-z ,  sin(pi x) sin(pi y) z ]
```

imposed as the cell source, so the exact discrete solution is `u*` and the
error norm is a genuine discretisation error. Dirichlet data `u*` on all six
faces. Three grids, executed on the 外协方 cluster (job `s1794067711_233`,
nodes n315/n330, `stage_dir` = TensorFVM source snapshot; the `n = 8` result was
reproduced locally to all printed digits).

| observable | `n = 4` (`h = 1/4`) | `n = 8` | `n = 16` | `p` (gate) | `|p - 2|` | verdict |
|---|---|---|---|---|---|---|
| `l2_interior` (wall layer excluded) | 3.532567e-02 | 8.466880e-03 | 2.338022e-03 | **2.1317** | **0.132** | **PASS** |
| `l2_global` (all cells) | 3.703622e-02 | 1.062831e-02 | 2.793860e-03 | 1.7531 | 0.247 | FAIL |
| `linf_global` | 7.377949e-02 | 2.646043e-02 | 8.376820e-03 | 1.3877 | 0.612 | FAIL |

Reading: the volume operator that the solvers assemble is second order to within
the declared tolerance once the wall-adjacent layer is excluded; the wall
closure (Dirichlet traction on one-sided faces) is *not* second order and drags
the global and max norms below 2. The gate therefore reports the interior norm
as the verification claim and keeps the two contaminated norms as FAIL, instead
of averaging them into a comfortable number. Residual of every linear solve
`< 1e-14`.

Supplementary non-uniform probe (adds `n = 24`, `h = 1/24`, ratio 1.5 — the
general least-squares path, `artifacts/vv_gate/gate_tensorfvm_mms_4level_*`):

| observable | 4-level `p` (least-squares) | triplet spread | power-law residual | verdict |
|---|---|---|---|---|
| `l2_interior` | 2.0970 | 0.347 | 3.9e-03 | FAIL |
| `l2_global` | 1.7693 | 0.145 | 2.0e-03 | FAIL |
| `linf_global` | 1.4125 | 0.176 | 3.2e-03 | FAIL |

The point estimate improves (`|p-2| = 0.097`), yet the gate refuses to certify:
the triplet-to-triplet order spread and the power-law residual exceed the
asymptotic thresholds. That is the intended conservatism — a mixed-ratio
sequence buys a nicer number, not a certificate.

## 5. Cross-repository run B — TensorLBM Poiseuille, honest FAIL + diagnosis

TensorLBM's shipped verification case (`tests/test_verification.py`, BGK +
half-way bounce-back + its Guo-style body force, transcribed call-for-call in
`tools/vv_crossrepo_tensorlbm.py`; nothing in TensorLBM touched), `ny = 16, 32,
64`, `n_steps = 4 ny^2`, `nu = 1/6`, `fx = 1e-4`:

| observable | ny=16 | ny=32 | ny=64 | `p` | verdict |
|---|---|---|---|---|---|
| rel-L2 velocity error | 2.394666e-02 | 1.383948e-02 | 7.834480e-03 | 0.7511 | FAIL |
| flow-rate error | 2.902468e-02 | 1.586510e-02 | 8.741398e-03 | 0.8854 | FAIL |
| peak-velocity error | 1.833719e-02 | 1.057647e-02 | 6.154258e-03 | 0.8114 | FAIL |

The repository's own test only requires a refinement ratio `> 1.5`, i.e. `p >
0.58`; the gate shows that this is not second order, and the new profile fit
(`tools/vv_lbm_profile_fit.py`, `artifacts/vv_gate/lbm_poiseuille_profile_fit.json`)
locates the cause:

| grid | fitted walls `(y_low, y_high)` in cells | wall vs half-way position | amplitude ratio | parabola residual / `u_max` |
|---|---|---|---|---|
| 16 | `(+0.0669, +14.9331)` | `0.567` cells | 0.98175 | `1.7e-05` |
| 32 | `(+0.0752, +30.9248)` | `0.575` cells | 0.98945 | `3.6e-05` |
| 64 | `(+0.0787, +62.9213)` | `0.579` cells | 0.99387 | `5.2e-05` |

The profile is parabolic to `1e-5` of `u_max` on every grid — the bulk stencil is
fine — but (i) the effective wall sits at `y ~ +0.07` cells instead of the
`y = -0.5` of half-way bounce-back and (ii) the wall displacement is constant in
*cell* units, which is an `O(h)` error in physical units. The amplitude error
decays as `h^0.787`, exactly the measured `p ~ 0.8`. Fixing this is a
solver-side/reference-definition change (consistent forcing/wall position),
reported here and deliberately **not** patched: the gate exists to expose it.

## 10. Limitations and scope

1. **Three grids cannot certify a noise floor** (§3). Declare `sigma` or use
   `>= 4` grids; `--strict` exists so a caller can refuse uncertified
   certificates.
2. **Error norms as observables.** `GCI` is reported relative to `f_fine`; for an
   error norm that means the number is large by construction (`GCI ~ 1` here).
   Use the absolute GCI (`Fs |df| / (r^p - 1)`) for norms; this is a reporting
   convention, not a decision rule.
3. **Wall-adjacent closures are a separate approximation.** The TensorFVM
   interior norm is second order, the wall-inclusive norms are not; a single
   global norm hides that.
4. **The gate cannot repair a bad reference.** The TensorLBM case fails because
   the discrete wall location and the analytic reference disagree by a constant
   fraction of a cell; no gate setting can turn that into second order.
5. **Order band.** `p` outside `(0.05, 6]` is refused; results with strong
   superconvergence (e.g. `p = 8` due to an error cancellation) therefore FAIL
   rather than mislead.
6. **Not re-executed here:** TensorFEM's `benchmarks/h_convergence_gci.py`
   (no local checkout in this worktree; `c_cross_repo_fem_mms` stays open) and
   the TensorFVM `n = 32` level (`l2_interior`-style refinement, launched on the
   cluster but not finished when this record was written; the `n = 24`
   supplementary level carries the non-uniform path instead).
