## ① 案例介绍

冰区操纵是极地/寒区船总体性能的短板：满足开水面操纵标准（IMO MSC.137(76)）的船，在冰浓度
升到 50 % 时可能已无法沿航道回转——因为在破冰阻力之外，冰盖还施加一个**阻碍转首的艏摇力矩**。
平台能力 `ice.maneuver.turning_radius` 此前为 WITHHELD 的直接原因就是：仓内没有任何模型解析
这个力矩。本节点建立该模型、给出稳态转弯半径，并把能力升级为 REAL。

**参考船（申报输入，非实测）** KV Svalbard：

| 量 | 值 | 来源 |
|---|---|---|
| L_pp / B / T | 89.0 / 18.6 / 6.5 m | 申报（冰载荷文献常用船型） |
| Δ / ∇ | 6375 t / 6220 m³ | 申报 |
| C_b = ∇/(LBT) | **0.57802**（几何闸门相对误差 0.0） | 几何闸门自校验 |
| 舵面积 A_R / 舵高 h_R | 11.57 m² / 5.0 m（A_R/(LT)=0.020） | 冰级船典型值 |
| 舵展弦比 λ=h_R²/A_R → f_α | 2.161 → **3.003 /rad**（Fujii） | 公式计算 |
| 螺旋桨 D_p / n | 5.0 m / 1.44 r/s（设计航速平衡 6.73 m/s） | 申报 |
| I_z = m(0.25L)² | 3.156×10⁹ kg·m² | 派生 |

**设计冰况**：h = 0.6 m，C_ice = 0.5（碎裂冰道）；验收点 δ = 20°。

## ② 怎么做的

### 2.1 运动模型（MMG 结构，三自由度）

```
(m+m_x) u̇ − (m+m_y) v r = X_H + X_R + X_P + X_I
(m+m_y) v̇ + (m+m_x) u r = Y_H + Y_R      + Y_I
(I_z+J_z) ṙ               = N_H + N_R      + N_I
```

**船体力 H**：沿水线的非线性横流阻力 `−0.5ρC_D d(x)|w|w`（w=v+rx，Inoue 型条带积分，C_D=1.0）
＋线性横向升力 `Y_lift=−C_Yβ·0.5ρLTU·v`，作用点在舯后 `x_lift=−0.15L`（这就是船的航向稳定
来源）＋细长体 **Munk 力矩** `N_Munk=−(m_y−m_x)u v`（失稳项）。横向面积分布**艏部尖瘦、艉部丰满**
（艏 30 % 抛物线收缩、艉 −0.7L/2 起收缩）——前后对称分布会给出恒等于零的稳定力矩，这是本模块
最早踩到的坑。

**舵 R**：`F_N=0.5ρA_R f_α U_R² sinα_R`，`u_R=(1−w_R)u√(1+κ(√(1+8K_T/πJ²)−1))`，
`v_R=−γ_R(v+l_R r)`，`α_R=δ−atan(v_R/u_R)`；`X_R=−(1−t_R)F_N sinδ`，`Y_R=−(1+a_H)F_N cosδ`，
`N_R=−(x_R+a_H x_H)F_N cosδ`（**注意该式的负号**：漏掉会让 δ>0 的船朝左转，是本节点第二次踩坑）。

**桨 P**：线性化敞水图 `K_T=K_T0(1−J/J₀)`（K_T0=0.45, J₀=0.85），伴流 w_P=0.35、推力减额 t_P=0.20。

**冰 I（本节点的核心）**：两族载荷，都由仓内已有 Lindqvist(1989) 法给量级：

| 分量 | 表达式 | 物理 |
|---|---|---|
| 破碎冰阻力（纵向） | `X_I = −η_channel·C_ice·R_Lind(u)` | 沿航迹破冰的阻力，η_channel=0.55（航道重复利用率，带 0.40–0.80） |
| 转首力矩（横向） | `F_lat = −κ_lat·C_ice·R_break(h)·tanh((v+r x_cp)/v_s)`，`N_I = x_cp·F_lat` | 艏部横向扫掠必须把航道「掰宽」，即对艏肩冰做弯曲破坏；x_cp=0.42L=37.4 m |

`tanh` 使接触力在横向扫掠速度上光滑、奇对称（不用符号函数切换）；v_s=0.30 m/s 为接触建立速度。
**关键物理**：艏在回转时向外扫掠（r>0 ⇒ 艏点横向速度 >0），故横向冰力反向 ⇒ `N_I` 与 r 反号 ⇒
冰**阻碍**回转，稳态半径随冰浓度单调增大。这就是节点要求的「破碎冰阻力/转首力矩」。

### 2.2 数值与稳态提取

RK4，dt=0.5 s（生产）/1.0 s（测试，与 0.5 s 差 < 0.1 %），t_end=2400 s；入流速度取**同冰况直航
平衡速**（避免人工加速段）。稳态判据：末 120 s 均值 r̄₂ 与前 120 s 均值 r̄₁ 的相对差
`|r̄₂−r̄₁|/|r̄₂|`，窗口 1 min ⇒ 单位 %/min；`R_steady = √(u²+v²)/|r̄|`。**未收敛必须如实返回
converged=False**（否则「慢船只跑半圈」会把半径测小）。

### 2.3 两个标定量与三个外部锚（这是本报告的诚实核心）

模型**不是**从 PMM 导数组抄来的（离线无法核对原始表），因此把「可验证的部分」与「标定的部分」
分开记录：

| 参数 | 值 | 层级 | 锚 |
|---|---|---|---|
| C_Yβ（船体横向力斜率） | **1.20 /rad** | CALIBRATED（带 0.8–1.6） | 开水面 δ=35° 回转直径落入 IMO/trial 带 `D_T/L∈[3,5]`（实测 **3.231**） |
| κ_lat（横向破冰效率） | **0.486** | CALIBRATED（带 0.05–1.00） | 冰/开水面回转半径比 = **1.529**（生态内独立冰区 MMG 实现 mission 9801 的基准值，落在文献带 1.3–2.0 内）；校准曲线：κ=0.05→0.925、κ=1.00→1.643，二分得 0.486 |

其余系数（C_D、m_x/m、m_y/m、J_z/I_z、k=0.25L、w_R、κ_R、γ_R、l_R、t_R、a_H、x_H、w_P、t_P、
K_T0、J₀、η_channel、x_cp）逐条写入 `PARAMETER_PROVENANCE`（含单位、依据、层级），并全部进
report.json。

### 2.4 对标路线（三条互不相同的路线）

1. **时域仿真**（本模型，RK4 积分，非线性横流 + 饱和冰力）；
2. **准稳态经验平衡式**（`steady_radius_balance`）：把稳态平衡写成 (v,r) 的二元代数方程组
   Newton 求解，丢掉附加质量科氏项与全部瞬态——判据 (a) 的对标公式；
3. **线性理论**（`steady_radius_linear_theory`）：在文档化参考工况 (β_ref=8°, r′_ref=0.30) 一次性
   线性化，解 2×2 线性稳态方程——用于量化**非线性误差**。

## ⑤ 注意点 / 局限（必读）

1. **判据 (a) 是模型一致性，不是独立验证**。经验公式（准稳态平衡）与仿真共用船体力与 Lindqvist
   冰力律，因此 2 % 的吻合证明的是「稳态降阶与瞬态积分自洽、稳态确实收敛」，**不证明冰力律本身
   正确**。独立证据只有三条外部锚：IMO/trial 回转带（开水面）、文献冰/开水面比带 1.3–2.0
   （生态内 mission 9801 独立实现给出 1.529）、Lindqvist 分量公式（`benchmarks/ice_nav_refs`
   sha256 语料）。**绝对精度 vs 实船冰区试验 = WITHHELD**（无试验时历可对）。
2. **两个标定量**：C_Yβ=1.20 与 κ_lat=0.486。前者的锚是 IMO/trial 带（区间式，不是点值）；
   后者对着 1.529 单点校准。敏感度：C_Yβ ±20 % ⇒ R **±25～27 %**（强敏感，参数不确定性是
   本能力最大误差源）；κ_lat ±20 % ⇒ R **−7.3 / +6.5 %**（较弱，因冰力矩已接近饱和）。
3. **导数量级偏离公开 MMG 带**：本模型 Y′_v=−1.205，而 KVLCC2 一类公开表值在 −0.15…−0.45；
   N′_v=−0.0132 又偏弱（公开带 −0.05…−0.25）。**未隐藏**：`derivatives.reference_band` 逐项
   记录 True/False，report.json 可查。原因是横向力斜率按 IMO 回转带标定而非按 PMM 表拟合；
   方向稳定性指数 C=+0.2997 > 0（航向稳定），但点值精度不据此声明。
4. **横向面积分布是建模选择**：艏瘦艉丰的抛物线分布决定了稳定力矩；换成前后对称分布，N_v 会
   退化为 0 且航向失稳（测试与早期试算都复现了这一点）。
5. **适用域**（`MANEUVER_LIMITS`）：深水、单桨单舵、无横倾/纵倾耦合、C_ice∈[0,1]（ρ=1.5 m 上限）、
   h∈[0.05,1.5] m、δ∈[0,35°]、Fr_L ≤ 0.25；**冰脊场、浅水、倒车、Z 形操纵不在本模块**。
6. **冰况模型是「浓度缩放的平整冰」**：用 C_ice 缩放 Lindqvist 平整冰阻力描述碎裂冰道；真实的
   碎冰尺寸分布、冰脊、压实（besetting）未建模。
7. 前一轮（第 1 次尝试）教训已吸收：yaw 惯量须按 ½ρL²d 无量纲化（若无量纲化错，艏摇响应慢
   300+ 倍且轨迹不收敛）；未收敛一律 converged=False；舵力矩符号必须核对（错号会让 δ>0 左转）。

## ⑥ 误差判定（逐项 vs 基准，显式回答「是否 < 3 %」）

| 关键量 | 计算 | 基准 | 误差 | < 3 %? |
|---|---|---|---|---|
| R_steady（δ=20°, C=0.5） | 308.96 m（R/L 3.472） | 准稳态经验平衡 315.54 m（R/L 3.545） | **−2.08 %** | **是** |
| 能力图 12 点最大误差 | — | 同上 | −3.52 %（δ=10° 点） | 否（该点 −3.52 %，其余均 <3 %） |
| 冰/开水面半径比 | 1.529 | 外部锚 1.529（带 1.3–2.0） | **0.0 %**（校准值） | 是（但为标定量，见 §⑤.2） |
| D_T/L（开水面 δ=35°） | 3.231 | IMO 上限 5.0；trial 带 3–4.5 | **−35.4 %** 于上限 / 带内 | 不适用（区间基准） |
| 艏摇率收敛率 | 0.000 %/min | 判据 < 1 %/min | 满足 | 是 |
| 稳态三自由度残差（力矩） | 0.000 MN·m | 0 | 机器精度 | 是 |
| Y′_v | −1.205 | −0.15…−0.45 | 2.7–8 倍 | **否（已声明为标定量）** |
| N′_v | −0.0132 | −0.05…−0.25 | 3.8–19 倍偏弱 | **否（已声明）** |
| 线性理论 R（同工况） | 771.2 m（R/L 8.66） | 仿真 308.96 m | 相对仿真 **+149.6 %**（即仿真相对线性 −59.9 %） | 否（**诊断项**） |

线性路线偏差的机理：在冻结导数下冰力矩（4.52 MN·m）已**超过**舵力矩（3.93 MN·m，占比 1.15），
固定点被推到很小的艏摇率 ⇒ 半径被高估一倍半。非线性（横流阻力二次、舵来流漂角修正、冰力 tanh
饱和）在此不可忽略——这正是判据 (a) 采用**保留非线性**的准稳态平衡式、而不采用线性理论的原因。

**结论**：主判据 (a) 用准稳态经验平衡式对标，−2.08 % < 3 %；能力图整体最大偏差 3.52 %；
能力 `ice.maneuver.turning_radius` 升级 **REAL**，范围为「模型内稳态转弯半径 + 能力图趋势」，
绝对精度 vs 实船试验保持 **WITHHELD**。
