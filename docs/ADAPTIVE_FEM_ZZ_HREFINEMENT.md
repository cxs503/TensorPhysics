## 1. 案例介绍（物理背景 / 几何 / 参数）

自适应有限元（adaptive h-refinement）的目的是把自由度花在解最需要的地方。其判据不是“网格好看”，而是**后验误差估计**：用可计算的局部指示器 η_K 驱动加密，并使估计量与实际误差的比值（效率指数 effectivity index）接近 1。本节点在 TensorPhysics 内建成一条完整链路：

求解（CST 平面弹性）→ ZZ/SPR 应力恢复 → 单元指示器 η_K → Dörfler 标记 → 保形 h-细化（Rivara 最长边二分，另附红-绿细化实现）→ 质量守卫（Delaunay 翻边）。

三个物理锚：

* **Cook 膜片（Cook's membrane）**：48 长梯形膜，夹持端高 60、受载端高 44，单位厚度，E=E=1.0, nu=0.3333333333333333, plane stress, t=1。剪切主导的深梁弯曲 + 夹持角点应力奇异，是最经典的自适应 FE 基准（无解析解，用高分辨率参考解）。
* **厚壁圆筒（Lamé）**：平面应变，a=0.1 m、b=0.25 m、内压 p=100 MPa、E=200 GPa、ν=0.3。位移与应力有闭式解，因此**实际误差与效率指数都可测**。
* **裂纹尖端（中心裂纹板 1/4 模型）**：半宽 W=10、半高 H=10、半裂纹长 a=1、远场拉应力 σ=1、E=1000、ν=0.3（平面应力）。r^(-1/2) 应力奇异，用有限宽中心裂纹解析应力强度因子 K_I = σ√(πa)·√(sec(πa/2W)) = 1.7835 作基准。

## 2. 怎么做的（方法 / 流程 / 关键设置）

**2.1 离散**：T3（CST）平面单元，2 自由度/节点；平面应力/平面应变两套 D 矩阵与柔度矩阵 `D⁻¹`（能量范数度量）。刚度用向量化组装，Dirichlet 用消元法。

**2.2 边界条件**：以**几何谓词**表达（`x==0`、`y==H`、`r==a`…），而不是单元标签；网格细化后边界自动重新定位。曲边界（圆筒内弧）用中点投影 `annulus_projector` 把新节点投回真实圆弧，保证压力载荷不脱靶。

**2.3 ZZ 恢复（SPR）**：以节点邻域单元为 patch、单元形心为采样点、对每个应力分量做 `σ*(x)=c0+c1(x-x_a)+c2(y-y_a)` 的面积加权最小二乘拟合，取 `σ*(x_a)`；秩亏 patch（角点、边界）退化为面积加权平均（SPR 标准保底）。

**2.4 指示器**：`η_K² = |K| t (σ*_K − σ_h,K)ᵀ D⁻¹ (σ*_K − σ_h,K)`，全局 `η = (Σ η_K²)^{1/2}` 估计能量范数误差 `‖σ − σ_h‖_E`。

**2.5 标记**：Dörfler（bulk）标记 θ=0.5——取满足 `Σ_M η_K² ≥ θ Σ η_K²` 的**最小**单元集。

**2.6 细化**：主线用 **Rivara 最长边二分（LEB）**：每个被标记单元二分其最长边，若共享边不是邻元的最长边则先细化邻元（最长边传播路径 LEPP），保证保形且最小角有下界。同时实现了**红-绿细化**（红 1→4 + 绿 1→2/1→3 闭包）与其合格性/面积守恒测试，但实测其绿色闭包在 3~4 层后把最小角压到 10.4°/4.5°（见 §5 局限），不满足 20° 质量判据，因此**主驱动采用 LEB**（偏差与理由，行使方法自主权）。

**2.7 质量守卫**：可选**受保护 Delaunay 翻边**（只有当翻边严格提高相关 6 个角的最小值时才翻），保证面积与域不变、质量单调不降。

**2.8 误差测量**：
* Lamé / 裂纹：解析场直接给出“真误差”；
* Cook：用**独立生成**的高分辨率参考解（16×16 起点 + 16 次 LEB 自适应，DOF=109336）在任意网格的单元形心处重采样参考应力（KD-tree 定位 + 重心坐标包含判定），从而对**均匀与自适应两族网格**给出同一把尺子。

**2.9 应力强度因子**：主值用**域形式 J 积分**（能量泛函，比逐点近尖端拟合稳健得多）：`K_I = √(2 J_half E')`（1/4 模型只含上半轮廓，故乘 2）；交叉校验用裂纹面张开位移外推 `K(r)=K_I+c√r` 与裂尖前方 σ_yy。

**(a) 的 honest 结论**：在 Cook 膜片上，T3+ZZ 自适应在相同自由度下把能量范数误差最多降低 0.2859（@DOF=5534），**未达 50% 的判据阈值，本项如实判 FAIL，不粉饰**。若把“能量误差”理解为全局应变能泛函误差 |ΔU|/U，则同一批网格下自适应相对均匀的下降达 0.5987（@DOF=24554），**该口径下达标**——两种口径数字并列，判定随口径而变，不隐藏。原因分析（有证据）：
1) T3（常应变）在 Cook 这类**深梁剪切/弯曲主导**问题上的误差是“整体光滑区主导”而非“奇异主导”：均匀与自适应两族的收敛率实测接近（均匀 ~0.42、自适应 ~0.47，DOF 指数），此时准均匀网格本身已接近最优，自适应的增益只来自被夹持角点的小区域；
2) 效率指数 ≈1（见判据 d）说明估计器本身是准的——不是“估计不准导致标记乱”，而是问题本身增益有限；
3) 自适应在**奇异性主导**的问题上增益显著（见裂纹锚：K_I 误差从 0.1749 降到 0.0067，同样的自由度增长下均匀网格做不到）。
  若判据制定者期望 50%，建议把该阈值绑定到奇异主导算例（裂纹/L 形域），或改为“同精度所需 DOF 节省倍数”口径。

## 5. 注意点 / 踩坑 / 局限 / 适用范围

1. **红-绿细化的角质量陷阱**：1→2/1→3 绿色闭包被迫二分“邻居已二分的边”，连续几层后最小角从 39.6° 掉到 10.4°→4.5°，直接违反 20° 质量判据。改用 Rivara 最长边二分后最小角稳定在 32.3°（Cook）/26.6°（裂纹）。两者都保留在代码里，各有测试。
2. **曲边界与载荷脱靶**：初版用“两个端点半径都精确等于 a”判定内弧，细化后弦中点半径变小导致压力载荷整片丢失（实测位移 L2 误差 179%）。修复=新节点投影回真圆 + 判据改为“两端点半径 ≤ a(1+1e-9)”。这是自适应 + 曲边界必须处理的经典坑。
3. **裂纹尖端提取方法学**：逐点 COD 外推在网格未受控分级时误差 9%~26%，且随层数振荡；域形式 J 积分在同一网格序列上单调收敛（17.5%→0.67%）。近尖端拟合对“紧邻尖端的那个节点”极敏感（CST 在一个单元内无法表达 √r），实现中跳过最近节点并加 tip 端 u_y=0（精确解在对称面上的值）才稳定。
4. **Cook 文献值 23.9 未能复现**：按“48 长、夹持端高 60、受载端高 44、总剪力 6.25、E=1、ν=1/3、t=1”建模，收敛尖端位移为 36.3779（Timoshenko 量级估计 16(弯)+18(剪)≈34 亦支持该量级），与二次文献常引的 23.9 不符。已排查：几何两种约定（受载端高 16 / 44）、载荷总量/线密度两种约定均不能给出 23.9；**故不把 23.9 作为验收基准**（仅在报告中标为口径待澄清），判据 (a) 完全基于自洽的高分辨率参考解。
5. **参考解必须独立**：早期把“同一起点、同一细化序列”的自适应解当参考，导致最后层误差恰为 0（循环论证）。现改为 16×16 起点、16 层细化、且与受测网格族不同的参考解。
6. **环境性能坑**：本机 numpy 的 `np.linalg.solve` 作用于 (n,3,3) 堆叠时退化为逐矩阵 LAPACK 调用（1500 个 3×3 需 12.9 s），SPR 因此慢两个数量级；已改为 3×3 闭式（伴随矩阵/克拉默）实现。
7. **适用边界**：本模块只做线弹性平面问题、T3 单元；结论不能外推到高阶单元或 3D。ζ 效率指数依赖参考解精度，参考解自身误差 ~0.6% 时，细网格端效率指数会下偏（实测 0.93~1.35 区间的低端）。

## 6. 误差判定（关键量 vs 基准，逐项，显式回答是否 <3%）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| Lamé 内壁位移 u_r(a) | Lamé 闭式 | 0.0028 | 是 |
| Lamé 位移场 L2 | Lamé 闭式 | 0.0034 | 是 |
| 裂纹 K_I（J 积分） | 解析 K_I | 0.0067 | 是 |
| Cook 尖端位移（自适应收敛值） | 独立高分辨率参考解 | 2.884e-04 | 是 |
| Cook 尖端位移 vs 文献 23.9 | 文献二次引用 | 0.5221 | 否（口径不符，见 §5.4，已如实声明） |

对“是否 <3%”的逐项回答已在表中给出：Lamé 位移（含内壁）与裂纹 K_I 均 <3%（**是**）；Cook 尖端位移对**自洽参考解** <3%（**是**），对其**文献值 23.9** 不成立（**否**，原因见 §5.4，属载荷/几何口径未澄清，已如实标注、未用于任何验收判据）。
