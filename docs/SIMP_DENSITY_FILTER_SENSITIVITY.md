# SIMP 拓扑优化：密度滤波与伴随灵敏度一致性验证面

> 节点 p247w1-N08 · TensorPhysics · `tensorphysics.topology_optimization.simp`
> 本文件由 `scripts/gen_simp_doc.py` 从 `artifacts/simp_m9136/verification.json` 程序化生成（数字零手抄，时间戳与全部原始数值见该 JSON）。

**能力面**：`fem.simp.density_filter`（密度滤波对棋盘格的抑制）、`fem.simp.sensitivity_consistency`（伴随灵敏度 ↔ 有限差分一致性）。

**一句话结论**：灵敏度一致性面全部达标（最大绝对误差 2.177e-05，均值 3.352e-06，相对误差量级 1e-5），棋盘格抑制达标（抑制比 20.4×）；但战役判据 C1 的「无滤波/有滤波柔度比 ≥ 5」**被证伪**（实测 0.9771，物理上 ≤1），如实记 FAIL。

## 1. 案例介绍

SIMP（Solid Isotropic Material with Penalisation）把单元杨氏模量写成密度的幂次插值 `E(rho) = Emin + rho^p (E0 - Emin)`，在给定体积分数下最小化柔度 `C = F^T u`。该离散问题在没有正则化时是**不适定**的：双线性 Q4 平面应力网格允许逐单元交替密度（棋盘格）与单节点铰接（one-node hinge），它们是纯离散伪影，不对应任何可制造结构。Sigmund 线性密度滤波（半径 r）恢复最小长度尺度，从而恢复适定性；滤波后必须把灵敏度按链式法则投影回设计变量，否则优化器会走在错误的梯度上。

两个标准算例（平面应力 Q4，单位厚度，E0 = 1，Emin = 1e-9，ν = 0.3，p = 3）：

| 算例 | 网格 nelx×nely | 体积分数 | 边界条件 | 载荷 |
|---|---|---|---|---|
| MBB 半梁 | 100×50 | 0.5 | 左端 u_x = 0（对称），右下角 u_y = 0 | 左上角节点 F_y = −1 |
| 悬臂梁 | 50×25 | 0.4 | 左端全固支 | 右端半高处节点 F_y = −1 |

滤波半径 r = 1.5 个单元长度；OC 更新（move limit 0.2），体积约束施加在**物理（滤波后）密度**上。

## 2. 方法

### 2.1 平面应力 Q4 内核（`simp/fem2d.py`）

从零实现（numpy + scipy.sparse）：双方程刚度阵 2×2 Gauss 积分（对常 Jacobian 单元精确），矩形单元 Jacobian 解析求逆；结构化网格装配；齐次 Dirichlet 消元 + 稀疏直接解。**残差校验**：解出后检查 `||K u - F|| / ||F|| <= 1e-6`，否则判为奇异/不连通设计并返回 `None`（不把垃圾解当成物理结果）。

### 2.2 线性密度滤波（`simp/density_filter.py`）

Sigmund/Bourdin 形式：`H_ij = max(0, r - |x_i - x_j|)`，`rho_tilde_i = Σ_j H_ij rho_j / Σ_j H_ij`，即 `rho_tilde = P rho`，P 行和为 1、权重非负（故滤波后场是邻域凸组合，不会越界）。r = 0 时 P = I。

### 2.3 伴随灵敏度与滤波链式法则（`simp/sensitivity.py`）

对 `C = F^T u`、`K(rho) u = F`，自伴随问题的解析导数：

```
dC/drho_e = -(p * rho_e^(p-1) * (E0 - Emin)) * u_e^T k0 u_e
```

（即单元应变能乘以插值斜率取负）。滤波在场内是线性的，故 
`dC/drho = P^T dC/drho_tilde`。注意 `u_e^T k0 u_e` 用的是**滤波后**密度的位移场。

### 2.4 有限差分与复步差分

- 前向差分 `(C(rho+Δ) - C(rho))/Δ`：截断 O(Δ)，但相消误差 ~ eps_eff·C/Δ；
- 中心差分 `(C(rho+Δ) - C(rho-Δ))/(2Δ)`：截断 O(Δ²)，相消误差同样存在；
- 复步差分 `Im C(rho + iΔ)/Δ`：无相消，可把解析导数探到机器精度量级。

每次差分都**重解** FE 方程（单变量扰动），因此与伴随法的一致性是真正的交叉验证，而非同一公式的自证。元级并行（进程池）求解，每个单元的差分互相独立。

### 2.5 棋盘格指数

对每个内部 2×2 单元块计算混合二阶差分 `rho_ij - rho_i,j+1 - rho_i+1,j + rho_i+1,j+1`，取绝对值平均再除以 2（0/1 场的最大可能幅度）：纯棋盘格 = 1，常数/线性场 = 0。

### 2.6 优化与验收集成

OC（optimality criteria）更新，二分 Lagrange 乘子，move limit 0.2；终止条件 `max|Δrho| < 0.01`。验收判定由 `simp/verification.py` 端到端执行并落 JSON，图由 `simp/figures.py` 从同一 JSON/npz 生成。

## 5. 注意点与局限

1. **C1 判据被证伪（诚实 FAIL）**：滤波把可达密度场限制为无滤波问题的子集，按变分原理必有 `C_filter >= C_no_filter`，实测比值 0.9771（≤1）。任何诚实的实现都不可能得到 ≥5 的柔度比；战役判据里想表达的「≥5 倍」在实测中体现为**棋盘格指数的抑制比** 20.4×（已作为 C2 的伴随量给出），而非柔度比。本节点不修改判据文字，只如实标注 FAIL 并给出可复算的反证。
2. **DOF 交错陷阱**：装配时若用 `np.column_stack([2n, 2n+1])` 会得到 `[2n1,2n2,...,2n4, 2n1+1,...]` 的错误交错，伴随法与差分法会**同时**错，一致性检验照常通过。刚体位移零能量测试（`test_rigid_body_translation_has_zero_energy`）是唯一抓住它的检查——本节点开发中确实由该测试发现并修正。
3. **差分相消极限**：float64 直接解下，差分误差 ≈ eps_eff·C/Δρ，实测在 Δρ ≤ 1e-6 处主导；因此「Δρ→0 单调收敛到 1e-8」对经典实差分不可达。节点用无相消的复步差分完成 C5，并把实差分曲线作为机器精度极限的证据。
4. **滤波器 + OC 收敛慢**：密度滤波（对物理密度施加体积约束）在 100×50 上需要 100+ 次迭代，且终止时仍保留约 15% 灰度单元；这是线性滤波（非 Heaviside 投影）的已知特性，不影响本节点的滤波/灵敏度结论，但影响绝对柔度数值的可比性。
5. **棋盘格指数依赖初始化**：均匀初值在细网格上会收敛到只有局部交替的局部最优（细网格两种子实测 0.3702, 0.3866），棋格失稳需要 ±5% 对称破缺才能充分暴露；两个种子的值都如实列出。
6. **网格依赖性不是本配置的判别量**：4 倍加密下无滤波最优柔度变化 0.0292、有滤波 0.037，二者相当；即在该算例里「滤波恢复网格无关性」的说法不成立，滤波真正可测的收益是最小长度尺度/棋盘格抑制（C2），本节点不越过证据去宣称更多。
7. **相对误差的定义域**：约 22.64% 的单元位于空洞区，其 SIMP 斜率为零（灵敏度数值上为 0），逐点相对误差无意义；故给出尺度无关的 l2 相对误差与「灵敏度 ≥ 峰值 1%」子集上的相对误差，战役判据本身用绝对阈值（C3/C4）。
8. **无外部基准**：MBB/悬臂的绝对柔度没有可比的公开基准值（网格规模、载荷归一化、E0 归一化各异），因此本节点只做**内部交叉验证**（伴随↔差分↔复步、常应变分片、刚体模态），不对绝对柔度作精度声明。
9. **Emin=1e-9 的病态性与未做的扫描**：生产设置保留 Sigmund 的 Emin=1e-9，使刚度阵条件数很大、差分的相消底更高；本审计在单一 Emin 下完成，未做 Emin 敏感性扫描（明确记为局限）。

## 6. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 相对误差 | 是否 <3% |
|---|---|---|---|
| 伴随灵敏度 dC/dρ（滤波分支） | 中心差分 Δρ=1e-6 | l2 1.154e-05；活跃子集（712 单元）mean 2.190e-05、max 2.722e-04 | **是** |
| 伴随灵敏度 dC/dρ（无滤波分支） | 中心差分 Δρ=1e-6 | l2 7.209e-06；活跃子集 mean 9.115e-06、max 1.839e-04 | **是** |
| 伴随灵敏度 | 复步差分（Δρ=1e-8） | l2 1.922e-12；max_abs 7.369e-12 | **是** |
| 常应变分片（Q4 内核） | 解析应变能 | 机器精度（<1e-12） | **是** |
| 刚体平移（Q4 内核） | 零应变能 | <1e-10（绝对） | **是** |
| 最优柔度绝对值 | 无外部基准 | — | 无基准，声明原因：网格/载荷/E0 归一化无统一口径 |

结论：**所有有基准的关键量相对误差均远小于 3%**（灵敏度一致性 ~1e-5 量级）；柔度绝对值无外部基准，仅提供内部一致性与网格依赖性数据，不作精度声明。
