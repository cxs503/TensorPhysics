\section{Conclusion}\label{sec:conclusion}

We described a platform and protocol under which heterogeneous LLM
agents co-develop coupled multiphysics solvers as a role-specialized
fleet: model-pinned mission routing, claim-token dispatch under a
server-enforced envelope, machine-checkable stage gates, and an
append-only research audit substrate. The wedge-icebreaking ladder
S0--S4 provides the demonstration campaign; the seven-model bake-off
and fleet telemetry provide the measurements. \pending{final outcome
summary after the campaign completes.} Code and campaign artifacts will
