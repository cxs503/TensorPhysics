## 1. Case Introduction

### Physical Background
Ocean wave spectra in real sea states often exhibit bimodal characteristics: a low-frequency swell component (generated by distant storms) superimposed on a higher-frequency wind-sea component (generated by local winds). The Torsethaugen two-peak model provides a parameterized representation of such spectra.

Directional spreading of wave energy is commonly modeled using the cos^s(θ/2) family, where the spreading parameter s ranges from 0 (isotropic) to 36+ (narrow beam). ISO 15016 prescribes simplified directional assumptions (long-crested and short-crested) for speed/power performance assessment, which may introduce significant bias when applied to bimodal sea states.

## 2. Methodology

### 2.1 Bimodal Spectrum Construction
The Torsethaugen single-peak spectrum is normalized so that m₀ = Hs²/16:

```
S(ω) = N · α · g² · ω⁻⁵ · exp(-1.25·ωₚ⁴·ω⁻⁴) · γ^exp(-0.5·((ω-ωₚ)/(σ·ωₚ))²)
```

where N is a normalization factor computed by numerical integration to ensure m₀ = Hs²/16.

The bimodal spectrum is the linear superposition:
```
S_bimodal(ω) = S_swell(ω) + S_wind(ω)
```

### 2.2 Directional Spreading
The cos^s(θ/2) spreading function is normalized as:
```
D(θ; s) = Γ((s+2)/2) / (2√π · Γ((s+1)/2)) · |cos(θ/2)|^s
```

The spreading parameter s is recovered from the first Fourier coefficient a₁:
```
s = 2·a₁ / (1 - a₁),  where a₁ = ∫D(θ)·cos(θ)dθ
```

### 2.3 ISO 15016 Bias Quantification
Three response computations are performed:
1. **Long-crested**: All energy at θ₀, S_resp(ω) = |RAO(ω,θ₀)|² · S(ω)
2. **Short-crested**: cos^s(θ/2) spreading with effective s
3. **True bimodal**: Separate directional distributions for swell and wind sea

Bias is quantified as relative difference in m₀ between assumptions.

## 5. Notes and Limitations

### 5.1 Implementation Notes
- The Torsethaugen spectrum uses numerical normalization to ensure m₀ = Hs²/16, avoiding the ~10% error from fixed alpha.
- The spreading normalization constant uses the correct formula: C(s) = Γ((s+2)/2) / (2√π · Γ((s+1)/2)).
- The long-crested response correctly finds the RAO column at θ₀ using nearest-neighbor search.

### 5.2 Limitations
- The generic RAO model is simplified (Lorentzian frequency response, cos^s heading response). Real RAOs require hydrodynamic computation.
- The bimodal model assumes linear superposition; nonlinear wave-wave interactions are not captured.
- The ISO 15016 bias analysis uses a single effective spreading parameter; real bimodal seas have different spreading for each component.

### 5.3 Scope
- This module provides the spectral input layer for seakeeping analysis.
- Response computation requires coupling with a hydrodynamic solver (BEM/FEM) for real RAOs.
- The directional spreading model is validated for s ∈ [0, 36]; extrapolation beyond this range is not recommended.
