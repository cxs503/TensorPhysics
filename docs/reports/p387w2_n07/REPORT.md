## 1. 案例介绍（物理背景 / 几何 / 参数表）

**物理背景。** 平整冰层在船首挤压或冰盖受荷下发生弯曲破坏，其响应由**板弯曲刚度 D** 与**地基反力模型**共同决定。既有冰载荷链把海冰板放在 **Winkler 单参数地基**（p = k·w，等价独立弹簧阵列）上——这对浮力（水）是正确的一阶近似，但**完全不传递水平剪切**：载荷正下方的冰与邻近冰面之间没有剪切耦合，集中载荷附近的弯矩与裂纹位置因此完全由局部决定。物理上更完整的层级是：

```
层1 Winkler      : D∇⁴w + k w = q                              (k = ρ_w g，浮力)
层2 Pasternak    : D∇⁴w − G_p∇²w + k w = q                     (双参数，传剪切)
层3 弹性半空间   : [D α⁴ + C α] W = Q,  C = E_s/[2(1−ν_s²)]     (Boussinesq 连续体)
```

层3 的核是 **C·α**（分数次幂 α¹），层2 的核是 **k + G_p·α²**（α 的偶次多项式）——这正是本节点要量化的“跨越”：双参数地基在何种程度上、以何种方式代表弹性半空间。Vlasov 的层状识别给出 k = E_s/[(1−ν_s²)H]、G_p = E_s H/[6(1+ν_s)]，H 是唯一自由参数；H→∞ 即“弹性半空间极限”（k→0、G_p→∞）。

**几何与载荷。** 无限大冰板（Kirchhoff），集中载荷 P 与半径 a 的均布圆接触斑（船首接触斑）。地基三层用同一块冰板、同一载荷对比，避免几何差异污染结论。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**2.1 层2 的精确 Green 函数（新实现）。** 对 D∇⁴w − G_p∇²w + k w = q 作 Hankel 变换，算子化为关于 α² 的二次式 D m² + G_p m + k = 0，部分分式 + ∫αJ₀(αr)/(α²+b²)dα = K₀(br) 给出**闭式**：

```
w(r) = P / [2πD(m₁−m₂)] · [K₀(μ₁r) − K₀(μ₂r)],  μ_i = √(−m_i), Re μ_i > 0
w(0) = P ln(μ₂/μ₁) / [2πD(m₁−m₂)]                  (中心挠度有限)
```

G_p = 0 时 μ = e^{±iπ/4}/l 且 w 恒等于 Hetényi 的 −P·kei(r/l)/(2πkl²)（本节点机器验证误差 ~1e−16）。同一算子还给出弯矩与双调和残差的解析式，便于逐项自检。

**2.2 层3 的精确谱解（新实现）。** 半空间的 Boussinesq 核在 Hankel 域是代数因子 2(1−ν_s²)/(E_s α)，与板方程耦合后得 **[Dα⁴ + Cα]W = Q**，逐 α 可解 → w(r) = ∫Q J₀(αr)/(Dα³ + C)dα；斑载荷取 Q = P J₁(αa)/(παa)，弯矩由 M_r = D∫Aα²[J₀ − (1−ν)J₁/(αr)]dα 得到（解析，不靠差分）。该层的极限由 Boussinesq 闭式钉住：柔性圆斑 w(0) = 2pa(1−ν_s²)/E_s、w(a) = 4pa(1−ν_s²)/(πE_s)、远场 P(1−ν_s²)/(πE_s r)、刚压头 w = P(1−ν_s²)/(2E_s a)。

**2.3 振荡积分的求积策略（关键设置）。** 上述 Hankel 积分同时含 Bessel 振荡（周期 2π/max(a,r)）与核函数的代数尺度。实现分两段：**几何分级面板**（比 1.1）覆盖 1e−8·α_max 到振荡分辨极限，**等宽面板**（周期/12）覆盖到 α_max，每面板 12 点 Gauss–Legendre，尾部交自适应求积并记录尾量量级。与 mpmath 任意精度求积对照：挠度 1e−8~1e−11、弯矩 1e−7~1e−11 相对误差（mpmath 版本已写入回归测试）。

**2.4 独立数值面。** (i) 轴对称 Kirchhoff 环单元 FEM，本次给 `solve_axisym_plate_fem` 增加 Pasternak 弱形式项 2πG_p∫w′v′r dr（G_p = 0 时与既有 Winkler 实现逐位兼容）；(ii) 定义性 Hankel 积分（不用任何 Bessel 恒等式）。三者互校构成“解析—谱解—有限元”三角验证。

**2.5 裂纹间距与承载能力。** 环裂出现在径向弯矩的极值处：在稠密网格上取 |M_r| 的局部极大并用抛物线顶点细化，相邻极值间距即环裂间距 s；Winkler 下矩场自相似（只依赖 r/l，l = (D/k)^(1/4)），故 **s = C_s·l**、α = dln s/dln k = −1/4。首裂载荷 P_c = M_f / max_r|M_r(P=1)|。Pasternak 下间距不再纯幂律：理论值为解析周期律 s ∝ 2π/Im μ(k) 的对数导数，与数值矩场提取的指数对照。

**2.6 工具链。** `src/tensorphysics/elastic_foundation/{pasternak_plate,halfspace,hankel,crack_spacing}.py` + 既有 `plates.py`（扩展 G_p）+ `scripts/p387w2_n07_verify.py`（判据计算）+ `scripts/p387w2_n07_figures.py`（图）+ `tests/test_p387w2_n07_ice_foundation_tiers.py`（32 例回归）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **Boussinesq 闭式的椭圆积分模数**：`scipy.special.ellipe` 取的是**参数** m = k²，柔性圆斑闭式必须写 E_ell(m = (r/a)²)；第一版误写为 E_ell(r/a)，在斑内 0.25a–0.75a 造成 5–9% 的系统偏差，被谱解与 mpmath 双重独立路径抓出（现版本与 mpmath 相对误差 1e−8）。
2. **不能用有限差分从挠度场求弯矩**：谱解的挠度含 ~1e−4 量级的求积噪声，二次差分放大 1/h² 后与弯矩同量级（实测 P_c 偏差 Winkler 1.365 %、半空间 0.474 %，局部点偏差可达 40%）。本节点桁定：弯矩一律走解析/谱式，差分仅作粗校验。
3. **Pasternak 谱根符号**：算子 Dα⁴+G_pα²+k 的二次式是 D m² + G_p m + k = 0（m = α²），第一版写成 D m² − G_p m + k 导致剪切层把挠度算反（符号翻转、量级差 16 倍）。现已用三条独立路径锁定：双调和残差 ~1e−11、G_p→0 与 kei 逐位一致、斑载荷谱矩与解析挠度自洽。
4. **求积面板频率的选择**：面板宽度必须同时分辨 Bessel 振荡（周期 2π/max(a,r)）与核的代数尺度；把 1/l_hs 误当振荡频率会使板刚度→0 的工况需要数百万面板（本节点实测触发面板上限）。现方案 = 几何分级（覆盖全代数尺度）+ 等宽面板（仅按 Bessel 频率），并对尾部量级留痕。
5. **退化剪切模量** G_p = 2√(Dk) 时两谱根重合，闭式发散——模型显式拒绝并要求扰动 G_p（已入回归测试）。
6. **适用范围**：Kirchhoff（薄板）假设，h/l ≪ 1；冰板 h=1 m、l=2–15 m 满足。半空间层用 Boussinesq 静力核，不考虑层状/孔隙水效应；海水浮力与弹性半空间是**互斥**的物理地基（本节点把它们作为同一验证面的两个层级，不是同一物理场景的两种近似），因此层3 的算例取“冰盖/河冰坐落在弹性地基（E_s = 100 MPa 冻结粉土）”物理解释。
7. **裂纹间距的“理论值”**：Winkler 下的 −1/4 是由自相似矩场（只依赖 r/l）决定的精确律，因此闭式路径的指数复核属于实现一致性检验（误差 ~1e−14）；**FEM 路径与 Pasternak 路径才是非平凡检验**（FEM 误差 2.7e−8，Pasternak 相对解析周期律 2.157 %）。间距常数 C_s ≈ 4.944 是“矩极值间距”这一定义下的常数，不宜当作普适材料常数引用。
