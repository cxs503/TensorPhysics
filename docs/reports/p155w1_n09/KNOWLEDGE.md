# 可复用知识：适用域包络的「单轴探测」为什么会漏判，以及最小可行补法

**标题 / 规则（一条）**：当能力失效集在参数空间中**非轴对齐**（两个参数同时变坏才失效）时，
「逐轴扫描、其余轴取标称」的适用域探测在数学上不健全——它可能把**已验证标称点附近**的
越界区域整体判为域内；补法不是加密单轴扫描，而是**联合格点 + 见证点 + 保守胞**：
凡「一维区间都说在域内、评估算子却失败」的采样点即见证，见证所在格胞整格判 OUT，
由格胞平铺保证无缝隙，代价是边界一格厚的过度拒绝。

- **上下文与适用范围（applicability boundary）**
  - 适用：任何「能力 = 参数轴集合 + 评估算子 + 判据」的适用域包络机制；离线消费端按包络判级
    （不重跑评估算子）的流水线；判定必须是 fail-closed（宁拒不错）的场合。
  - 不适用：单轴能力（无联合方向，联合探测不产生区域，可完全跳过，零成本）；
    失效集与参数轴语义已知且可解析表达的场合（这时应直接用解析不等式，不必扫描）；
    **需要连续意义的证明**的场合——联合探测的结论是「采样分辨率下」的，见「反例与局限」。

- **机制（mechanism，为什么必须这样）**
  1. 单轴扫描把其余轴钉在标称点；标称点几乎总在「正常工作」一侧，于是联合失效集与每一条
     扫描线都不相交，一维区间被填满，**所有单轴数字都自洽**——这就是这个缺陷难被发现的原因：
     报告里的每个数都对，错的是「域 = 各轴区间之积」这个隐含假设。
  2. 离线门（`artifact.gate`）按设计不重跑评估算子，只能用落盘的区间判级，因此**不能靠
     `verify=True` 兜底**；必须把联合失效区域**落进工件**。
  3. 「见证 + 保守胞」是能同时满足「无缝隙」（格胞平铺）与「胞内必含真实失效点」（见证在胞内）
     的最小结构；两者缺一不可：只放见证点会留缝（本节点实测：半径取半格距时仍有 0.7% 误认证），
     只加密扫描而不改判定结构则完全无效。
- **推荐流程（procedure）**
  1. 能力注册时判定轴数 ≥ 2 → 自动启用联合探测（配置 `interaction: {enabled, samples, max_pairs, max_rays}`）。
  2. 联合格点用与单轴相同的采样律（Chebyshev-Lobatto，端部加密），再加入格胞中点（分辨率减半）。
  3. 标记见证：两轴一维区间都含该点 且 `evaluate_point` 失败；记 `failure_type`（criterion/pathology/law）。
  4. 见证所在格胞 → 保守胞（裁剪到一维区间内；区间外的点本就 OUT，裁剪不损失 fail-closed 性）。
  5. 每个保守胞沿「最近通过点 → 见证点」二分到射线参数的 `1e-3`，报边界与置信（按 `max_rays` 截断并写明）。
  6. `classify` 在单轴全 IN 之后追加联合检查；命中保守胞即 `OUT` → 判级强制 `OUT_OF_DOMAIN`，拒写 `REAL`。
  7. 联合区随工件落盘、参与 `suite_digest`，消费端重放同一判定。
- **反例与局限（counterexamples / limitations，诚实申报）**
  - **残留别名**：保守胞只保证「胞内含已采样的失效点」。失效区若薄于一个格胞，仍可能漏检；
    本节点在 61×61 闭式真值格点上实测误认证为 0，但这是离散验证，不是连续证明。
    关闭途径：加密 `samples`（代价表见报告 ③）或对关键点 `classify(..., verify=True)` 重算。
  - **过度拒绝是有意代价**：默认格点下为搜索面的 6.3%–8.6%，加密到 25 降至 3.3%–5.6%；
    任何声称「零代价」的说法都与本节点实测矛盾。
  - **失败的尝试**（记录条件与原因）：
    - 以「见证点 ± 半格距」建正方形保守胞：相邻见证之间会留缝 → 单格点上报误认证 0.66%–75%；弃。
    - 把重叠保守胞贪心合并以「让报告更短」：合并产生阶梯状大框，过度拒绝从 7.6% 膨胀到 68%；弃。
    - 仅靠 `classify(..., verify=True)`（重跑评估算子）兜底：离线门按设计不使用它，
      对消费端流水线无效，且把成本推给每次判级；弃。
  - **轴对上限**：`max_pairs` 默认 3，高维能力需分组；顺序按声明顺序以保证可复现。
