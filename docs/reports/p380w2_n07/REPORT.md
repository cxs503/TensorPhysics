## 1. 案例介绍

### 1.1 物理背景

船舶上层建筑（桅杆、吊机吊臂、管系、上层舱壁、甲板货物）在冬季航行中遭遇过冷水滴撞击：水滴惯性不足以随气流绕过结构而撞击表面，撞击水按 Messinger 控制体热平衡部分冻结，余水沿表面回流向船尾方向并在下游复冻。后果有二：(i) 电加热防冰功率需求巨大且受发电机容量约束；(ii) 上层结冰抬高重心 KG、降低初稳性高 GM、延长横摇周期 T_roll，是小型渔船/近海船倾覆的直接诱因（IMO/FAO 渔船安全议题的经典失效模式）。

本节点的验证面是有向链：**过冷水滴撞击 → 热平衡冻结（含回流）→ 电加热功率约束优化 → 稳性影响**，五个环节均为真实数值内核（解析势流 + 拉格朗日颗粒追踪 + Messinger 热平衡 + 约束优化 + 质量矩稳性），没有任何硬编码结论。

## 2. 怎么做的（方法/流程/关键设置）

### 2.1 过冷水滴撞击：Langmuir–Blodgett 轨迹法 + 指数积分器

空气流场取**解析势流**：圆柱 `w = U(z + R²/z)`；椭圆（吊臂/钝前缘/甲板箱面）用 Joukowski 映射 `z = ζ + c²/ζ`（ζ 域为半径 μ 的圆，反演取模长较大的根）。水滴动量方程：

    dv/dt = (f_D/τ_p)(u − v) + g,   τ_p = ρ_w d²/(18 μ_a),   f_D = 1 + 0.15 Re_p^0.687,   Re_p = |u−v| d/ν_a

拖曳项用**指数积分器**精确积分（常值 u 下 v 与位移有闭式解），对小水滴（τ_p ≪ L/U）无条件稳定、自然退化为随流极限。接触判据用归一化壁面间隙 `gap ≤ 2e-4`（不是“进入物体内部”，否则滞止区渐近逼近壁面的水滴会被静默丢弃）。当地收集率 β(s) = dy₀/ds，总收集率 E = y₀,max/h（h 为截面半高），故弹道极限 E→1、无惯性极限 E→0 均解析可验。

### 2.2 冰生长：Messinger 控制体热平衡 + 一维回流

    n·ṁ_im·L_f + ṁ_im·U²/2 + ṁ_im·c_w(T_a − T_s) + ṁ_in·c_w(T_rb − T_s) + q_h
        = h_c(T_s − T_a) + ṁ_ev·L_v + εσ(T_s⁴ − T_a⁴)

干生长（rime）取 n=1、阻尼 Newton 解 T_s；若 T_s 会超过熔点则转湿生长（glaze），置 T_s=0 反解 n，余水沿弧长**精确行进**（无迭代）输送到下游单元，蒸发量受膜水限制以保持水量闭合。h_c 用 Churchill–Bernstein（圆柱）/层流平板关联式；蒸发/升华由 Chilton–Colburn 传质类比 + Buck 饱和蒸气压 + Clausius–Clapeyron 斜率给出。常温恒定的工况下 n 与时间无关，故备有代数等价的准稳态求解器 `ice_growth_steady` 作为优化器内循环（与瞬态解偏差 <1e-12，有测试保证）。

### 2.3 防冰优化：约束功率最小化 + SIMP 0/1 布局

蒙皮沿表面导热会重新分配加热功率：对单位注入热流解一维翅片方程 −k_s t_s T'' + h_c T = q，得到**能量守恒的扩散矩阵 W**（列和=1：注入的每一瓦最终都从某个单元对流散出），有效热流 q_eff = W q 进入 Messinger 平衡。优化问题：

    min Σ A_i q_i    s.t.  h_i(t_end) ≤ h_allow,  0 ≤ q_i ≤ q_cap

用 SLSQP（归一化变量 x_i=q_i/q_cap ∈ [0,1]，显式有限差分步长 2e-3，并加 2 % 设计裕度 + 可行性回收），另给 SIMP 型 0/1 布局优化（q_i = q_cap ρ_i³，p=3 惩罚，再投影为开关式布局并复验）。**均匀加热基线**= 每个分区都按最不利分区配置同一功率密度（非优化安装的实际做法）。

### 2.4 稳性影响

KG' = (Δ·KG + Σ m_i z_i)/(Δ + Σ m_i)，GM' = GM − (KG' − KG)，T_roll = 2π√((1+k_add)I_xx/((Δ+Σm_i) g GM'))，I_xx 含冰质量偏心项 Σ m_i (z_i − KG')²，k_add = 0.20，k_x = 0.35B。冰厚来源有二：(i) 本项目耦合链算得的冰厚；(ii) 声明式设计冰载荷（ISO 12494 冰级，稳性评估的标准做法）。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **粒子雷诺数用错直径**：把机体直径当水滴直径代入 Schiller–Naumann 修正，会让所有水滴退化成随流示踪粒子（E≡0，且低惯性工况静默通过）。这是单位错误，靠“弹道极限 E→1”测试才暴露。
2. **接触判据**：用“进入物体内部”判命中会丢掉滞止区撞击——惯性不足的水滴渐近逼近壁面（ξ ~ e^{−t/T}）永不进入体内部。改用归一化壁面间隙判据后才得到正确的 β(0)。
3. **Joukowski 反演分支**：以“第一个 |ζ|>μ 的根”选分支在壁面上因舍入误差失效，壁面速度出现 39 m/s 伪值；改取模长较大的根后壁面不可穿透残差降到 6e-4（相对速度归一）。
4. **回流水的显热**：回流离开上游单元时温度已是 0 °C，若下游仍按环境温度重新加热会重复计入显热，使下游永远“保护不住”（初版加热功率因此虚高一个量级）。修正后回流水的温度取 T_rb = 0 °C。
5. **优化器尺度**：SLSQP 默认有限差分步长（~1.5e-8 相对）低于结冰求解器分辨率，梯度变噪声、停在初值；必须归一化设计变量并显式给 eps=2e-3，否则“优化”结果与均匀加热相同（会被误读为“无优化空间”）。
6. **功率上限是物理量**：若把 q 的上界设成“均匀加热的功率密度”，集中加热方案被裁掉，优化只剩 ~10%；上界必须取加热器额定（本项目 12 kW/m²）。
7. **模型边界**：势流无边界层/无分离，撞击极限与 β 幅值对 MVD、截面尺度敏感（E 在本工况 0.27，属低惯性区间，β≤0.5）；忽略结冰后形状反馈（Myers modified Messinger 的冰层导热），故为撞击限制而非导热限制（同工况 Stefan 上限 11.9 mm ≫ Messinger 3.82 mm，说明当前不处于导热控制区）；水平甲板的收集率用等效截面 + catch_fraction 折减近似。
8. **适用范围**：MVD 10–500 μm、U 5–50 m/s、T_a −40–0 °C、圆柱/椭圆截面 D 0.05–1 m；超出范围（如 SLD 大水滴破碎、强分离几何）需改用 Eulerian 两相或含湍流扩散的模型。
9. **稳性**：参考船为参数化合成船，不是真实船舶；未计自由液面、未计波浪中横摇阻尼变化，仅给静水初稳性与线性横摇周期。
