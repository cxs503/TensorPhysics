## ① 案例介绍

### 物理背景

冰脊由破碎冰块堆积而成：水线以上为冰帆（sail），以下为龙骨（keel）。龙骨是**多孔碎石体**——总孔隙体积的 30–50 % 为充满海水的孔隙。冬季孔隙水自冷面（脊顶大气侧）向内再冻结，碎石被"冻结键"胶结成**固结层**；固结层才是破冰船真正要压溃/弯曲的介质，其下的疏松碎石只需被排开/推动。因此"固结到什么程度"直接决定冰脊阻力——这正是本节点要闭合的链条：

```
(a) 龙骨大孔隙结构  →  (b) 再冻结 (修正 Stefan)  →  (c) 固结层强度  →  (d) 固结度-阻力耦合
```

## ② 怎么做的（方法 / 工具链）

### (a) 龙骨大孔隙结构 → 有效物性

冰骨架 + 孔隙卤水的两相复合体：

```
k_eff = k_ice^(1-φ) · k_brine^φ          （几何平均，任务指定形式）
k_Voigt = (1-φ)k_ice + φk_brine          （并联上界）
k_Reuss = 1/[(1-φ)/k_ice + φ/k_brine]    （串联下界）
ρ_eff = (1-φ)ρ_i + φρ_b,  C_vol = (1-φ)ρ_i c_i + φρ_b c_b
κ_eff = k_eff / C_vol
L_vol = φ ρ_i L_f                        （只有孔隙水冻结！）
```

φ=0.40 时：k_eff=1.229、k_Voigt=1.480、k_Reuss=0.987、k_Maxwell=1.373 W m⁻¹ K⁻¹，ρ_eff=950 kg/m³，C_vol=2.762e6 J m⁻³ K⁻¹，κ_eff=4.448e-7 m²/s，L_vol=1.202e8 J/m³。

### (b) 再冻结：修正 Stefan 定律（精确相似解，非准稳态）

把固结复合体当作导热固相、孔隙水恒在液相线 T_f，则单相 Stefan 问题给出**精确**相似解：

```
h_c(t) = 2λ(Ste) √(κ_eff t),   λ e^{λ²} erf(λ) = Ste/√π,
Ste = C_vol (T_f − T_s) / (φ ρ_i L_f)
```

即任务要求的"修正 Stefan 律 h_c = k_c√(κ t)"，其中无量纲固结常数 **k_c = 2λ(Ste)**。与准稳态 k_c=√(2Ste) 的差别来自增长层自身储热：Ste=0.19/0.53/0.88（对应 −10/−25/−40 °C）时准稳态偏高 3.2 %/8.0 %/12.4 %，**故模型一律用精确 2λ**，准稳态只作渐近校核（判据 B）。

**双前向生长**（任务要求 (1)）：上边界（气温，可串积雪热阻）与下边界（龙骨底面）各一个前沿，各自带自己的 ΔT 与 k_c；两前沿相遇即封顶为 h_keel 并置 `CONSOLIDATION_CLOSED`。积雪按串联热阻处理，准稳态平衡 `kΔT/(h+kR) = L_vol dh/dt` 精确积分为 `h = −kR + √((kR)² + 2kΔT t/L_vol)`，再乘以相似修正因子 2λ/√(2Ste) 使无雪极限与精确解严格一致。

### (c) 固结层强度演化

```
σ_c(t) = σ_ice(T_mean) · (1 − φ_keel) · f(C),  f(C) = C^q,  C = h_c/h_keel ∈ [0,1]
```

* σ_ice(T_mean)：复用 `ice_mechanics/constitutive.compressive_strength`（Schulson 1999），自变量取**冰本体卤水体积分数** v_b(S_ice,T)（T=−13.4 °C 时 σ_ice=9.00 MPa）；
* (1−φ_keel)：毛截面中**固体承压面积**占比（未冻结孔洞不承拉/剪）；
* T_mean=(T_surface+T_f)/2：固结层准稳态线性剖面均值；
* 端点精确：f(0)=0（无强度）、f(1)=σ_ice(1−φ)。

### (d) 固结度-阻力耦合

```
R_ridge = R_sail + R_keel
R_keel  = R_plate(h_c, σ_c)                          # Lindqvist(1989)，h_c 替代 h_ice（ISO 19906 固结层视角）
        + C1(1−φ)ρ_i g B (h_k² − h_c²)               # 未固结碎石浮力排开项（Keinonen 系数，深度区间 [h_c, h_k]）
        + C2(1−φ)ρ_i B V² (h_k − h_c)                # 未固结碎石动量项
R_sail  = (1−C)·C2(1−φ_s)ρ_i B V² h_s + C·0.5σ_f h_s B (sin(φ_b/2)+μcos(φ_b/2))/k_bend
```

深度区间限制 `[h_c, h_k]` 是刻意的：C→0 时 `(h_k²−0)` 使模型**严格退化为既有 Keinonen 冰脊阻力定律**（判据 F 验证到 1e-12，实测相对误差 0.0）。`R_plate` 直接调用 `ice.resistance.level_ice_resistance`（复用已验收的 Lindqvist 三组件），并原样透传其 domain flags。

### 工具链

Python 3.11 + numpy/matplotlib（确定性闭式，无随机采样）；参考解用 `ice_contact.stefan.solve_stefan_1d`（独立焓法）；Newton/二分用 `ice_contact.stefan.neumann_lambda`。全流程 `run_ridge_consolidation.py` 一条命令重跑，`results.json` 内嵌 git revision 与库版本。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **下边界物理反转（方法论偏差声明）**：任务实现路径 (1) 要求"固结层从脊顶和**底面**同时向内生长"。真实海洋中龙骨下边界与孔隙水**同一液相线**（−1.7 °C），下前向无驱动温差，故**实际是自上而下单向生长**。本模块按任务实现通用双前向求解器（判据 D 验证镜像对称 1e-12、封顶、以及 0.02 K 过冷下前向按各自 k_c 生长），但物理基准算例把海洋边界置为 T_f，输出 `LOWER_FRONT_STAGNANT` 标记，并给出量化：0.02 K 过冷只使下前向达 0.033 m（上前的 3 %）。偏差理由与量化均入报告，不掩盖。
2. **时间尺度量级**：任务期望"数天…数周"对应 h_c 0.3–1.0 m（模型给 1.7–46.5 d，吻合）；但**完全固结一个 10–20 m 龙骨需数年至数十年**（t∝C²h_k²）。这与实测"冰脊龙骨长期部分固结"一致，是物理结论；同时意味着本节点不宣称"厚脊数周固结"。
3. **裸面模型是上界**：100 天、φ=0.40 时裸面 h_c = 1.17 / 1.88 / 2.31 m（−10/−25/−40 °C），**超出**实测固结层 0.2–1.0 m 带；加入 0.3 m 积雪后为 0.42 / 0.96 / 1.35 m，回到带内/带宽附近。故：裸面 = 上包络，工程使用需给雪厚/海洋热通量。模型未含海洋热通量（约 1–5 W/m²，会显著延缓厚雪脊）与三维侧向散热，两者均使 h_c 偏小。
4. **阻力基线外推**：8–20 m 龙骨超出 Keinonen 冰脊定律自身适用域（h_k ≤ min(0.15B, 4 m) = 3.6 m）。模块**不截断、只打 flag**（`KEEL_BEYOND_RIDGE_LAW_LIMIT`，判据 F2 验证 flag 必然出现），因此 3.7 节的绝对 kN 值属**系数集外推**，只有相对趋势可信。同理 Lindqvist 板项在 h_c > min(0.03L, 0.10B)=2.4 m 时打 `PLATE_BEYOND_LEVEL_ICE_LIMIT`。
5. **两条 SEMI-EMPIRICAL 闭合**：f(C)=C^q 与 R_keel 分层分解无第一性原理推导，3.8 节给出 ±5–9 % 敏感性；`R_sail` 的水上堆积无浮力支撑项（只有动量项）+ 固结后弯曲项的线性混合，属工程近似，最不确定。
6. **孔隙水渐进冻结未分辨**：真实孔隙卤水在 T_f 以下连续析冰（mushy zone），本模型用单一潜热台阶；低温（−40 °C）下会低估可释放潜热 ⇒ 高估 h_c。这是 3 条已知偏差的同一方向。
7. **σ_ice 的取值**：Schulson 模型在 −13.4 °C 给 9.0 MPa，高于 `ice.resistance.SIGMA_C_REF`=5 MPa（工程有效平均）。差异不改 R 的趋势，但改绝对值（R_plate ∝ σ_c）；报告保留模型原值并在敏感性中体现。
8. **既有测试**：`tests/test_ice_resistance.py::test_vp_curves_artifact` 在本工作树失败，原因是缺 `artifacts/vp_curves.json`（需先跑另一个 benchmark），与本节点改动无关（未触碰 `ice/resistance.py`）。
