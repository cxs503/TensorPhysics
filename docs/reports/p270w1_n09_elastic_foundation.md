## 1. 案例介绍（物理背景 / 几何 / 参数表）

**物理背景。** 平整冰层在船首挤压下的弯曲破坏（level-ice bending failure）与冰盖在浮力支撑上的弯曲响应，
本质是**弹性地基上的板/梁弯曲**问题：竖向挠度 `w` 由抗弯刚度 `D`（或梁的 `EI`）与地基反力共同平衡。船舶
冰载荷链中"首裂载荷—弯曲破坏"的预测精度，取决于地基模型（Winkler 单参数 / Pasternak 双参数）与板梁弯曲
求解器是否被解析解**验证过**。既有冰板链路的地基为 Winkler 弹簧阵列（缺口登记 GAP-FEM-P0：不传剪切），
而验证面此前只覆盖矩形板的 Navier 级数，**缺少**（i）无限梁/板的集中载荷闭式锚、（ii）轴对称 Kirchhoff
板的独立数值面、（iii）有限域边界效应定律、（iv）冰厚—特征长度标度律。本节点把这四项补齐成可复算的
验证面（解析锚 + 独立数值面 + 负控 + 标度律），并**否定**了两条在任务书/手册中常见但错误的闭式写法。

**几何与载荷。** 两类算例：

* 通用梁：无限长 Euler–Bernoulli 梁，`EI = 1e+07 N·m²`，`k = 1e+06 N/m²`，
  集中载荷 `P = 1e+05 N`（FEM 以 `±L` 自由端截断，截断长度按衰减长度取）。
* 冰板：无限大浮冰板（Winkler 地基 `k = ρ_w g`），厚度 `h ∈ {0.5, 1.0, 1.5} m`，
  集中载荷或半径 `a = 0.5 m` 的圆接触斑，`P = 1e+05 N`（首裂载荷另行反算）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 解析锚（闭式解与推导）

**(1) 无限 Winkler 梁（Hetényi 1946）。** `EI w⁗ + k w = P δ(x)`，特征长度 `l_b = (4EI/k)^(1/4)`：

```
w(x) = P/(2 k l_b) · e^(−|x|/l_b) · [cos(|x|/l_b) + sin(|x|/l_b)]
```

**(2) 无限 Pasternak 梁（双参数，Selvadurai 2000）。** `EI w⁗ − G_p w″ + k w = P δ(x)`。
算子分解 `EI (D²−s₁)(D²−s₂)`，`s₁,s₂` 是 `EI s² − G_p s + k = 0` 的根，取 `Re√s > 0` 的分支：

```
w(x) = P / [2 EI (b²−a²)] · [ e^(−a|x|)/a − e^(−b|x|)/b ],  a=√s₁, b=√s₂
```

`G_p = 0` 时 `a=(1+i)/l_b`、`b=conj(a)`，上式**精确退化为 Hetényi 解**（G1: **PASS** 的
同一性检查：最大相对差 `5.235e-16`）。`γ = G_p/√(EI k) < 2` 复根
（阻尼振荡），`γ > 2` 双实根（两个衰减长度）。

**(3) 无限 Winkler 板（Hetényi 1946 / Kelvin 函数）。** `D ∇⁴w + k w = P δ(r)`，`l = (D/k)^(1/4)`。
由 Hankel 变换 `w(r) = P/(2πk l²) ∫₀^∞ u J₀(ur/l)/(1+u⁴) du`，用 Kelvin 函数写成闭式：

```
w(r) = − P · kei(r/l) / (2 π k l²) = (P/(8 k l²)) · (−4/π) · kei(r/l)
w(0) = P/(8 k l²) = P/(8 √(kD))          （kei(0) = −π/4）
```

`ker/kei` 是 `K₀(r e^(iπ/4)/l)` 的实部/虚部（测试中用 `scipy.special.ker/kei` 交叉验证到 1e-9）。

**(4) 有限半径板（边界效应的精确参照）。** 圆板半径 `R`，边缘固支（`w=w′=0`）或简支（`w=0, M_r=0`）。
通解 = 奇异特解（Kelvin）+ 两个**在原点正则**的齐次解（`I₀(q r)` 的实部/虚部，`q = e^(iπ/4)/l`）：

```
W(r) = −P kei(r/l)/(2 π k l²) + c₁ Re I₀(q r) + c₂ Im I₀(q r)
```

`c₁,c₂` 由两条边缘条件构成的 2×2 线性方程给出。因 `|I₀(qR)| ~ exp(R/(√2 l))`，`c₁,c₂ ~ exp(−√2 R/l)`
（两条条件各贡献一个增长因子），故**中心挠度的相对边界误差按 `exp(−√2 R/l)` 衰减**；单条件时对应
`exp(−R/(√2 l))`。这一节给出**不依赖 FEM 离散误差**的边界效应定律。

**(5) 圆斑载荷板（首裂载荷用）。** 均布压力 `q = P/(πa²)` 覆盖半径 `a`：

```
w(r)   = ∫₀^∞ q a J₁(ξa) J₀(ξr) / (D ξ⁴ + k) dξ
M_r(r) = −D ( w″ + ν w′/r ),  w′, w″ 在积分号下求导（J₀′ = −J₁, J₀″ = −J₀ + J₁/(ξr)）
```

### 2.2 独立数值面（不共用解析锚的推导路径）

* **Hermite 梁单元**（每节点 `w, θ=w′`）：`EI` 弯曲刚度 + Winkler 一致矩阵 `k·le/420·[…]` +
  Pasternak 剪切层一致矩阵 `G_p/(30 le)·[…]`（`∫(w′)²dx` 的标准一致矩阵）。
* **轴对称 Kirchhoff 环单元**（每节点 `w, w′`），应变能
  `U = πD ∫[w″² + (w′/r)² + 2ν w″w′/r] r dr + πk ∫w² r dr`，单元刚度
  `2πD∫(r N″N″ᵀ + N′N′ᵀ/r + ν(N″N′ᵀ+N′N″ᵀ))dr`。**关键设置**：`r=0` 节点删除转角自由度
  （轴对称要求 `w′(0)=0`），同时消除 `1/r` 奇异被积函数——保留该自由度会使单元能量对数发散。
* **三条互不依赖的振幅/方程检验**：① Hankel 积分（定义式，与 Kelvin 恒等式无关）；
  ② 平衡恢复 `2πk∫w r dr / P = 1`（载荷必须全部由地基承担）；③ 双调和残差
  `(D∇⁴w + k w)/(k w) = 0`（极坐标 `∇⁴w = w⁗ + 2w‴/r − w″/r² + w′/r³`）。
* **源强度检验（点载荷必要条件）**：`EI [w‴](0−)^(0+) = P`。该检验用于判别"满足齐次方程但源强度
  不对"的伪解（见 5.1）。
* **工具链**：`numpy` / `scipy.special`（`kv, iv, j0, j1`）/ `scipy.integrate.quad`（振荡积分面板分割）/
  `matplotlib`（图）/ `pytest`（`tests/test_elastic_foundation_validation.py`，27 例）。
  验证脚本 `scripts/p270w1_n09_elastic_foundation_verify.py` 程序化写 JSON，报告脚本从 JSON 注入（零手抄）。

### 2.3 与任务书两条闭式写法的偏差（自主采用更优路径，附理由）

任务书给出的两条公式经检验是**错误写法**，本节点采用正确闭式并在验证面中把它们作为**负控**保留：

1. 梁：`w = P/(2 k l) e^(−|x|/l) cos(x/l)`。它**满足齐次方程**（是齐次解之一），但中心值与正确解相同
   而形状不同；其剪切跳跃只有 `EI[w‴]/P = 0.5`（正确值 1），
   即只代表**一半源强度**的点载荷。偏差：`x=0.5l_b` 处 `-35.33 %`、
   `x=l_b` 处 `-60.9 %`、`x=2l_b` 处 `-184.4 %`
   （相对正确 Hetényi 解）。→ 采用 Hetényi 形式（含 `sin` 项）。
2. 板：`w = P/(8kl²)[ker(r/l) + kei(r/l)]`。`ker(r/l)` 在 `r→0` **对数发散**（`kei(0)=−π/4` 有限，
   `ker(0)=+∞`），中心挠度无穷大，物理上不可能；且 `kei` 幅值差 `4/π = 1.273` 倍。
   → 采用 `w = −P kei(r/l)/(2π k l²)`，由 Hankel 积分（独立）与 `w(0)=P/(8√(kD))` 双重确认。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

**5.1 满足齐次方程 ≠ 是点载荷解。** 任务书的余弦型梁公式满足 `EIw⁗+kw=0`，中心值也"恰好"对，
但源强度只有一半（`EI[w‴]/P = 0.5`）。**判别准则必须是源强度/跳跃条件**，不能只看中心值或曲线形状像不像。
板的情形同理：`[ker+kei]` 写法中 `ker` 是原点上奇异的齐次解，点载荷必须由正则性排除。

**5.2 点载荷的弯矩对数发散。** `kei″(r)` 在 `r→0` 对数发散 → 无限大板点载荷下中心弯矩无穷大
（任何点载荷都会开裂）。因此**首裂载荷必须用有限接触斑**（本节点 `a = 0.5 m`），不能沿用点载荷弯矩公式。

**5.3 轴对称 FEM 的 `1/r` 奇异。** 应变能含 `(w′/r)²` 项；若保留 `r=0` 处转角自由度，插值给出 `w′ = O(1)`，
`(w′/r)²·r = O(1/r)` 使单元能量**对数发散**。删除该自由度（等价于施加 `w′(0)=0`）后被积函数化为多项式，
6 点 Gauss 精确。此坑在实现初期即被 G7/G8 抓到（若不删除，中心挠度误差为 O(1) 量级）。

**5.4 振荡 Bessel 积分需要面板分割。** `∫uJ₀(ur/l)/(1+u⁴)du` 直接用 `quad(0, inf)` 会撞上
QUADPACK 的 200 次细分上限（相对误差 ~1e-4 且报 `IntegrationWarning`）。按半周期 `π/|ρ|` 分面板后
相对差降到 `2.761e-06`。

**5.5 Pasternak 的截断长度必须按最长衰减长度取。** `γ=6` 时最长衰减长度 `4.293 m`
远大于 `8 l_b = 20.12 m`，若固定 `8l_b` 会把自由端截断误差（1.1e-3）误判为 FEM 误差
（G2 首次运行即为 FAIL，改为自适应截断后降至 `7.85e-05`）。**报告的"FEM 误差"必须先排除离散与截断两个来源。**

**5.6 边界效应测量须避开近场与双精度地板。** 近场（`R ≲ 6l`）里高阶增长模态尚未被最慢模态支配，
拟合斜率会被抬到 1.7 以上；`R ≳ 25l` 之后误差降到 1e-15 已在双精度地板。本节点只用
`1e-12 < |Δw/w| < 1e-4` 的渐近带拟合。

**5.7 适用范围。** ①薄板 Kirchhoff 理论（`h/l ≪ 1`；冰板 `h/l ~ 0.07`，适用）；②线弹性、小挠度、
无开裂/无接触非线性；③Winkler/Pasternak 地基为静力（无附加质量、无阻尼、无孔隙水惯性），
动冰载荷（如碎冰冲击）需另建附加质量模型；④Pasternak 的 `G_p` 取值本身是模型参数（冰-水体系
物理标定见 P54-W3-N02），本节点验证的是**求解器/闭式面**，不是 `G_p` 的物理取值。
