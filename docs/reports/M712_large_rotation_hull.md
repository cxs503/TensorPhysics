> 仓库：TensorPhysics　分支：`agent/m712`　节点：`SIR-PC2|F08`　落地模块：`src/tensorphysics/structure/`

> 战役：冰区航行（structural_mechanics，风险 high，L1_foundation）


## 一、案例介绍

冰区航行的船体在冰载荷作用下同时发生两种运动：整体横摇（横剖面在横摇平面内的大角度刚体转动）与舷侧结构的弹性变形。当横摇超过 15° 时，`sinφ`/`1−cosφ` 不再可忽略——冰载荷的作用点随剖面转动而移动，重力的力臂 `mgH·sinφ` 从零变为一阶量。此时按“冻结几何”的小转动线性分析会把横摇效应整体丢掉，属于物理层面的漏项，而不是数值精度问题。本节点交付的正是这一环节的几何非线性（大转动 / 小应变）求解能力。

**理想化**：取一个肋距宽的舷侧冰带板格（板厚 30 mm × 0.8 m 肋距 + 400 mm T 型桁材）作为等效梁条，下端在双层底处固支、上端（冰带）受冰推力与世界系重力。结构在横剖面平面内弯曲，横摇即为该平面内的有限转动。



| 参数 | 取值 |
|---|---|
| 横摇角 φ | 15.0° |
| 冰推力（世界系固定方向） | 50.0 kN |

| 冰带距中纵剖面 | 10.0 m |
| 双层底至冰带高度 | 8.0 m |

## 二、怎么做的（方法 / 流程 / 工具链）

1. **共旋（co-rotational）梁单元**：2 节点、每节点 3 个自由度 `(u_y, u_z, θ)`。变形分解为沿当前弦线的轴向伸长 `ū = l − l₀` 与相对弦线转角的局部转角 `θ̄ = (θ − θ₀) − (β − β₀)`，应变能
```
U_e = ½ (EA/l₀) ū² + (2EI/l₀)(θ̄₁² + θ̄₁θ̄₂ + θ̄₂²)
```
   局部梯度精确复现经典梁端弯矩 `M₁=(2EI/l₀)(2θ̄₁+θ̄₂)`、`M₂=(2EI/l₀)(θ̄₁+2θ̄₂)`。由于减去了刚体转角 `β−β₀`，单元是客观的：任意有限刚体滚转下应变能严格为零（实测 0.0 J，判据见测试 `test_rigid_roll_stores_zero_energy`，覆盖 5°/15°/45°/90°/180°）。
2. **内力/切线由能量精确求导**：`f = dU/dq`、`K = d²U/dq²` 用 `torch.autograd`（float64）自动微分给出。好处是 Newton 切线天然一致（与差分梯度偏差 <1e-4），且显式积分与能量严格一致，使能量守恒可以作为几何非线性更新的机器判据。
3. **横摇的有限转动更新**：参考构形取“刚体滚转后的几何”，节点转角自由度度量滚转之上的弹性转角；纯滚转状态应变能为 0。载荷为**世界系固定**的冰推力与重力，作用于**当前**节点位置——这正是大转动效应进入的通道。
4. **解析参考解（统计确定，独立于离散）**：固支悬臂在世界系集中力下的根部内力由整体平衡唯一确定：
```
N = t̂ · ΣF_k,   M = (r_belt − r_root) × ΣF_k,   σ = |N|/A + |M|·c/I
```
   在刚体滚转构形上求值即得 15° 横摇的精确应力。另给出“冻结几何”小转动基线（载荷作用于直立构形）作为反例证据。
5. **大转动能量守恒算例**：剖面从 20° 纯刚体滚转（应变能 0）自由释放，根部以广义横摇复原弹簧（代表完整船的复原刚度）支撑，舷侧梁条为弹性体，受世界系重力。显式 leapfrog（内力为能量精确梯度 → 辛格式）积分，账本 `E = T + U_strain + V_spring + V_gravity`，记录 `max|E−E₀|/E₀`。
6. **工具链**：`pytest`（8 个用例）+ `matplotlib`（图 1–4）+ `scenarios/hull_roll_15deg/run_case.py`（一键复现全部数字与图）。

## 五、注意点（踩坑 / 局限 / 适用范围）

- **DOF 编号坑**：能量梯度按节点主序展平 `[x_y, x_z, θ]ᵢ`，若外部载荷向量按“先全部位移后全部转角”排列，载荷会误落到转角自由度上（首轮实现即如此，表现为根部弯矩≈0、残差却很小）。现已在 `pack/unpack` 中固定为节点主序并在文档字符串中声明。
- **大转角的分支切割**：`β−β₀` 与局部转角 `θ̄` 都必须做 wrap（`atan2(sin,cos)`），否则 180° 刚体滚转会得到 360° 的虚假局部转角（客观性测试立刻抓到）。
- **共线节点的刚体转角识别**：梁条节点共线，协方差矩阵秩亏，2×2 极分解不可用；截面转角必须用 Kabsch 闭合式 `atan2(Σ r×c, Σ r·c)`。
- **显式步长的真实瓶颈**：不是整体弯曲频率，而是**集总转动惯量**对应的局部转动模态（ω ~ 3.6 krad/s），dt 需取 ~1/4 稳定极限；本次基准 dt=0.00015 s。
- **15° 判据残差 2.3% 的性质**：来自参考解用“刚体滚转几何”而真实力臂随弹性变形移动（δ/H ~ 1% 量级的 O(δ) 修正），**不是**离散误差——网格 2→16 单元应力的变化仅 0.013%，且用变形后几何复核静力学的闭合误差为 1.5e-4。
- **适用范围**：小应变/大转动（船体钢结构的真实工况）。纯弯矩 45°/60° 算例为运动学验证算例（应力限制在弹性范围），超过屈服的大转动问题需要弹塑性本构。
- **局限**：二维横剖面理想化，无三维弯扭耦合、板格局部屈曲、塑性与接触；暂态为干结构（无附加质量/水阻尼/冰接触阻尼），横摇复原以根部广义弹簧代表。
