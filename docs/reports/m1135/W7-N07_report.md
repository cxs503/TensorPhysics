## 1. 案例介绍

### 1.1 物理背景

冰区螺旋桨叶片同时承受两类本质不同的循环载荷：(i) **冰冲击/铣削载荷** —— 叶片切削或撞击冰块时在桨叶根部产生大幅值、低循环数的应力脉冲；(ii) **水动力交变载荷** —— 伴流场一阶（每转一次）与高阶谐波在叶片通过频率上产生小幅值、高循环数（10⁸–10⁹ 量级）的交变应力。二者叠加后按 Miner 线性累积损伤判别裂纹萌生寿命，是冰区推进器设计的核心疲劳问题。

本节点建立完整的物理链：冰扭矩包络 → 叶片级冲击载荷时程（与叶片通过相位锁定）→ 非定常水动力交变应力 → 应力叠加 → 雨流计数 → Miner 累积损伤 → D=1 的裂纹萌生寿命与疲劳安全系数。

## 2. 方法与流程

### 2.1 工具链

- 纯 Python/NumPy/SciPy 实现，无 CFD 外部依赖；`scipy.special` 提供 Hankel/Bessel 函数。
- 模块划分：`materials_sn`（Basquin/Goodman）、`beam_impact`（梁冲击三路线）、`hydro_unsteady`（Theodorsen/Sears/Küssner 与叶元）、`ice_spectrum`（铣削与冲击谱）、`blade_stress`（几何与剖面应力）、`rainflow_miner`（雨流+Miner）、`pipeline`（编排）、`figures`（出图）。
- 运行：`PYTHONPATH=src python3 -m tensorphysics.propeller_fatigue.pipeline --out artifacts/m1135`。

### 2.2 关键建模设置

1. **冰扭矩包络**：W7-N06 的扭矩包络工件不在本 work-tree 内（见 §5 局限），因此按同一物理结构重建：铣削模型 `h = v_adv/(nZ)`，`Q_mill = σ_ice·h·∫c(r)r dr`，包络取 `Q_ice,max = k_ice·Q_design`（冰级规范的扭矩包络结构）。冲击幅值谱取中位数 = Q_mill、99 分位 = Q_ice,max 的对数正态分布。
2. **叶片级载荷分解**：冰扭矩由接触叶片单独承担，`F_t = Q/r_imp`，轴向伴随分量 `F_a = 0.60 F_t`；冲击起点随机，但受力叶片必为当前处于冰接触扇区（±0.35 rad）内的那一支，因此每次冲击相对该叶片自身通过相位是**锁相**的（§3.6 有机器判据测试）。
3. **水动力交变**：伴流场取 1P/2P/3P 谐波（w_mean=0.28, a1=0.45, a2=0.20, a3=0.10），沿展向 24 站叶元积分得到轴向推力脉动→根部弯矩；每个站的 1P–3P 分量按 `|S(k_r)|`（Sears 阵风函数，k_r = π f c/W）做非定常修正后再积分。
4. **应力叠加**：`σ(t) = σ_mean(推力+设计扭矩+离心) + σ_hydro(t) + DLF·σ_ice(t)`；冲击脉冲的峰值用悬臂梁动力放大系数 DLF=1.2446 折算（等价静载法）。
5. **损伤**：`D = Σ n_i/N_i`；`N_i` 由 Basquin `σ_a = σ_f'(2N)^b` 给出，平均应力用 Goodman 修正 `σ_a,eff = σ_a/(1-σ_m/σ_UTS)`；寿命取 `D=1`；`SF = N_allowable/N_actual = 1/D`。
6. **两条损伤通道**：(i) 确定性水动力循环与冲击时程在 200 转窗口上雨流计数（用于展示谱结构、图 2）；(ii) 统计精确的 Miner 积分（水动力循环数 × 1/N + 冲击幅值分布上的 `N_impacts·E[1/N(σ_a(Q))]`）。因 Basquin 指数 m≈10，损伤由极稀有的强冲击主导，蒙特卡洛窗口只有 ~10 次冲击无法收敛，故寿命数字取 (ii)，二者差异在 §5 中如实列出。

设计暴露：20 年 × 4000 冰区运行小时/年 = 80 000 h；单叶循环数 1.262e+09。Miner 指数 m = 1/|b| = 10.149。

**结论（判据 e）**：名义（光滑试样基准）设计冰级 SF = 5.016e+05 ≥ 1 → PASS。把根部圆角应力集中与海水/铸造缺陷折减合成为 κ = Kt·K_D 后，SF 按 κ^m 下降，κ 容许值（D=1 的临界应力放大系数）为设计冰级 3.64、重冰况 2.41。分档看：

- κ=2（仅根部圆角 Kt≈2）：设计冰级 SF=441.730、重冰况 SF=6.775，20 年暴露均满足 ≥1。
- κ=5（圆角 Kt≈2 × 海水腐蚀+铸造缺陷折减≈2.5）：设计冰级 SF=0.040（**<1**，不满足）、重冰况寿命仅 50 h。

因此**结论有条件的**：在光滑试样基准下疲劳完全不是控制因素（SF~10⁵–10⁸），但 m≈10 的 Basquin 斜率意味着 5 倍应力放大就会把损伤放大约 1.2×10⁷ 倍，一旦计入腐蚀疲劳/铸造缺陷折减，设计冰级与重冰工况都会翻转成疲劳控制。工程可用的稳健量是 κ 容许值 3.64 / 2.41：设计应保证真实 κ（Kt × 环境折减）低于该值，否则需降压运行、缩短冰区暴露或提高圆角/表面质量。

## 5. 注意点与局限

1. **W7-N06 扭矩包络工件缺失**：本 work-tree 内不存在 W7-N06 的冰扭矩包络文件，故按铣削破碎模型重建包络（`Q_mill = σ_ice h ∫c r dr`、`Q_max = k_ice Q_design`），结构上与冰级规范一致但**不是**上游工件的直接复用。若上游包络给出不同的 k_ice/时程形状，D 与寿命按 κ 关系同步缩放（m≈10，对包络幅值极敏感）。
2. **水动力参考级别为解析非定常薄翼理论，不是 RANS/LES**：判据 (b) 要求对标非定常 RANS/LES，本环境无 CFD 数据，故对标 Sears 阵风解析解（并用时域 Küssner 独立校核）。这只能证明“实现了正确的非定常薄翼理论”，不能证明“与粘性 CFD 一致”；证据等级按 L2（解析）而非 L3（CFD）。伴流场为参数化谐波，未取自实船伴流测量。
3. **损伤统计量的两条通道**：窗口雨流（200 转、4 个实现）与统计精确 Miner 积分给出不同的 D（重冰况差 4 个量级），原因明确——m≈10 使损伤由极稀有强冲击主导，~20 次/窗口的蒙特卡洛无法收敛。寿命/SF 一律取统计积分值，窗口雨流仅用于展示谱结构与循环计数正确性。这一点没有被粉饰：两条通道的数字都在 JSON 里。
4. **结构模型是等效均匀悬臂梁**（I 取 r/R=0.5，含 1.4 附加质量），未做三维叶形有限元；叶根真实应力会受侧斜、剖面形状、圆角 Kt 影响。DLF 用“动力放大系数×等价静载”折算，已在 §3.2 用闭式/数值/有限差分三路线验证（误差 0.62 %），但等效梁的 I 与真实叶片的一致性未独立核实（无 CAD）。
5. **S-N 数据为工程手册典型值（PROVENANCE=LIT_TABLE）**，非从原始论文数字化，带 ±5 % 表值散布；拟合残差已如实给出。若换用实测 NAB 海水腐蚀疲劳数据，应整体替换 `MATERIALS` 表并重跑。
6. **适用区间**：判据 (a) 的对比点 τ/T₁≈1.03（简支）/0.37（悬臂），处于非定常放大最显著的区间；对更长/更短冲击（τ/T₁<0.1 或 >3）单自由度法与多模态法差异会显著变化（见图 4）。
