# 几何保真契约成熟化（m5513 / P48-N03）：CAD 积分 vs 离散网格的闸门与网格入口 provenance

**一句话结论**：把「这块网格可信到能进物理验收吗？」变成机器可判的对象——一个
`geometry_fidelity_contract.v1` 文件，携带 CAD 侧两套独立积分（切片 Simpson vs 分层
Monte-Carlo N=1e6）互证、三族离散求解器（FVM 多面体 / LBM 体素 / BEM 面元）各自在同一
真值源上生成的网格、双 sha256 provenance 与 GATE_PASS/GATE_REJECT 判定；KCS、KVLCC2、
SUBOFF 三条船的合格网格全部过闸，三种破坏网格 3/3 全部被拒，被拒网格在结构化层面
（异常）无法进入物理链。

---

## 1 案例介绍

**物理背景.** 船舶总体性能链（阻力 / 推进 / 耐波 / 操纵 / 稳性）的所有结论都建立在
同一份船体几何上。一旦被求解器消费的网格与 CAD 型线不闭合（体积、湿表面积、Cb 漂移），
下游的阻力、推力、波浪载荷会在一个**错误的几何**上得到"精度合格"的假结论。工程上
这正是"网格可信性"问题的核心：物理误差预算必须与几何误差预算分离且可审计。

**研究对象（三船）.** 主尺度与合同系数取自公开值；CAD 真值源为**参数化型线**（见 §2），
其对合同量的闭合精度在 §3.1 给出。

| 船 | 族 | L [m] | B [m] | T [m] | 合同量 | 说明 |
|---|---|---|---|---|---|---|
| KCS (KRISO 集装箱船) | wall_sided_power | 230.0 | 32.2 | 10.8 | Cb = 0.651 | 单桨集装箱船，方形系数合同值 |
| KVLCC2 (油轮) | wall_sided_power | 320.0 | 58.0 | 20.8 | Cb = 0.8098 | 肥大船型，Cwp≈0.86 |
| SUBOFF (DARPA 裸艇体) | revolution | 4.356 | 0.508 | 0.508 | ∇ = 0.699211 m³, S = 5.998 m² | 轴对称，Lf/Lp/La = 1.016/2.229/1.111 m |

**闸门判据（GATE_PASS，全部满足才放行）**

| 检查 | 容差 | 物理含义 |
|---|---|---|
| CAD 体积自洽（切片 vs MC） | ≤ 0.1 % | 两套独立积分实现互证 |
| CAD 湿表面自洽（求积 vs MC） | ≤ 0.3 % | 同上 |
| 离散 vs CAD 体积 | ≤ 0.5 % | 网格是否守恒排水量 |
| 离散 vs CAD 湿表面积 | ≤ 1.0 % | 网格是否守恒湿面积 |
| 离散 vs CAD 方形系数 | ≤ 1e-3（绝对） | 与合同 Cb 的一致性 |
| BEM 闭合曲面恒等式 `|Σ Aᵢnᵢ|/Σ Aᵢ` | ≤ 1e-12 | 面元法向闭合（散度定理） |
| provenance | 双 sha256 齐备 | CAD 与网格各自可追溯 |

## 2 怎么做的

**工具链**：`tensorphysics.geometry_fidelity`（新包，TensorPhysics 领域目录）
* `hulls.py` — CAD 真值源 `HullForm` + 两套独立积分（切片/参数求积、分层 Monte-Carlo）
* `mesh.py` — 三族离散积分 + 负控语料（`fvm_mesh / lbm_grid / bem_panels / corrupted_record`）
* `contract.py` — 契约文档、自包含 JSON-Schema 校验、闸门判定、`assert_admitted` /
  `physics_chain` 结构化准入
* `scripts/m5513_geometry_fidelity.py` — 一键复现：契约 JSON、负控、收敛表、图、验收 JSON
* `tests/test_geometry_fidelity_contract.py` — 25 条 pytest（C1–C7 全覆盖）

**CAD 侧（2）.** 船体由闭式半宽律给出：船型 `b(x,z) = (B/2)·w(x/L)·(z/T)^{1/m}`（`m`
由 Cb 反解，合同 Cb 精确闭合）；轴对称 `b² + (z-R)² = r(x)²`，fore/after 型线
`r = R(1-u²)^b`，指数用二分法把 ∇ 闭合到 0.699211 m³。积分落在 (x, s) 参数域上，
`z = T s^m`（船）与 `z = R - r cos πs`（回转体）两种映射都把龙骨/极点的奇异性消掉，
被积函数光滑，Simpson 收敛到机器精度量级（§3.4）。第二套积分是分层抖动的
Monte-Carlo（1e6 样本，`seed=20261106`），与求积不共享任何权重。

**离散侧（3）.** 三族都在同一真值源上真实生成网格并各自积分：
* **FVM**：贴体六面体（n_x×n_s×n_y，对称半体翻倍），每个六面体按标准 6 四面体分解求和
  （对所生成网格是精确多面体体积），湿表面取 j=n_y 面集 + 艉封板；
* **LBM**：均匀立方格点，体素占据数给体积（三套 ±Δ/4 抖动格点平均消去一阶阶梯偏差），
  湿表面用 IBM 方向修正重建（`P / <Σ|n_d|>`）；
* **BEM**：湿表面平板面元集，艉封板 + 水线面封闭，体积由散度定理
  `∇ = ⅓∮x·n dA`，同时输出闭合曲面恒等式残差。

**负控语料（3）**：① 全节点等向拉伸 2 %（FVM）；② 水线处删一层体素（LBM）；
③ 半单元错位——剖面宽度采样与自己所在层错开半格（FVM），即经典的
off-by-one-half-cell 索引错位。

**provenance / 幂等**：CAD 摘要 = 型线定义 + 求积设置的规范 JSON 的 sha256；
网格摘要 = 节点坐标（9 位小数）或体素位图的 sha256，逐族给出并汇总。契约用
`canonical_json`（sorted keys、固定分隔符、禁 NaN）落盘，同输入重跑字节级一致。

### 3.5 C5/C6/C7

* **C5**：三份契约过自包含 schema 校验，`cad_sha256` / `grid_sha256` 各 64 位十六进制；
  分辨率改变仅使网格摘要变化（CAD 摘要不变），删除任一摘要即 `ContractSchemaError`。
* **C6**：同一输入重跑两次，`canonical_json` 字节级一致（含 1e6 样本 MC 与体素位图）。
* **C7**：`physics_chain(contract, family, consumer)` 在 gate 失败时抛
  `MeshNotAdmitted`，consumer 计数保持 0（结构化断言，不是标志位）。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **LBM 湿表面 = WITHHELD（诚实欠账）.** 体素湿面积重建在当前实现里只有一阶精度：
   smoothed-coarea 在 KCS 上偏 +19…+26 %（且随分辨率增大而发散），方向修正门户面积
   偏 −21…−40 %，b̂+Jacobian 图重建在龙骨/极点发散。最终契约只接纳 LBM 的**体积与 Cb**
   （≤1.7e-4…6.8e-4），湿表面显式记 WITHHELD 并由 gate 记录证据等级——不把不达标的量
   混进物理链。改进路径明确：marching-cubes 级等值面重建（本环境无 skimage）。
2. **回转体参数化曾整体错位（已修）.** 初版用 x 无关的 z(s) 映射生成回转体，导致
   b 与 z 不自洽：∇ 虚高 8.4 %、FVM/BEM 全体偏 8.5 %。改用内在映射
   `(x, b=r sinπs, z=R − r cosπs)` 后，三族与 CAD 一致到 1e-3。
3. **SUBOFF 的 BEM 未进契约.** 平板面元在陡峭艉部收缩段上 |ΔCb| = 1.9e-3（体积 0.31 %
   已达标），超出 1e-3 绝对判据。按"闸门不回答它无法诚实回答的问题"原则，SUBOFF 契约
   只用 FVM+LBM，并在验收 JSON 里记录该排除（改进路径：曲率修正面元积分）。
4. **Cb 判据比体积判据更严（判据内部不一致）.** |ΔCb| ≤ 1e-3 等价于体积相对误差
   ≤ 1e-3·Cb⁻¹ ≈ 0.15 %（KCS），比 |Δ∇|/∇ ≤ 0.5 % 严 3 倍以上。因此有效分辨率由 Cb 决定，
   本次按更严者选网格（FVM 160×40×8、LBM n_x=600、BEM 120×40）。
5. **半单元错位对积分量不敏感（重要负面发现）.** 纯粹把格点整体平移半格，体积/面积
   几乎不变（实测 |Δ∇| ≤ 0.22 %，甚至小于 0.5 % 闸门）。**积分闭合判据对平移型半格错位
   天然不敏感**，能检出的是"宽度与自己层错位"这类几何-索引失配（+1.0…1.4 %）。要真正
   判半格对齐必须做场量级（梯度/壁面量）检查——这是本契约的适用范围边界。
6. **CAD 真值是参数化型线，不是官方型值表.** 三条船复现公开主尺度与系数（Cb 精确闭合、
   SUBOFF ∇ 精确闭合），但**不是**拖曳水池型值表：KCS 湿面积 8941.7 vs 文献 ~9530 m²
   （−6 %），KVLCC2 27233 vs ~27,000 m²（一致）。所以 C3 里"与已交付几何量一致"检验的是
   **积分器闭合性**，不是形状保真度；绝对湿面积不得直接用于阻力计算。
7. **SUBOFF 的 S=5.998 无法被"忠实几何"闭合到 0.1 %.** 交付对 (∇=0.699211, S=5.998)
   在 D=0.508 下互相张力过大：本次 ∇ 闭合后 S = 6.0095（+0.19 %），形状族扫描
   （艉部半径比 0.02…0.25 × 前体长 ±0.10 m，全部 ∇ 闭合）给出 S ∈ [6.00, 6.03]，即交付值
   落在族下界之外。建议战役侧复核 S 的来源或把该判据放宽到 0.5 %。
8. **幂等性依赖确定性抽样.** MC 用固定 seed 的分层抖动、网格生成无随机、浮点求和顺序固定，
   才做到字节级幂等；换 BLAS/并行归约需重新核验。
