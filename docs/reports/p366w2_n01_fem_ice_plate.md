## 1. 案例介绍（物理背景 / 几何 / 参数表）

**物理背景。** 平整冰层在船首挤压下的弯曲破坏（level-ice bending failure）是冰区船舶冰载荷链的核心环节：船首接触斑把冰板压弯，当弯曲正应力达到抗弯强度时出现第一条环裂。该链条的冰盖被理想化为**弹性地基上的 Kirchhoff 板**，此前（GAP-FEM-P0）地基为 Winkler 单参数弹簧 `p = k·w`，不传剪切。本节点把地基升级为 **Pasternak 双参数地基**

```
D ∇⁴w − G_p ∇²w + k w = q(x,y),   D = E h³/[12(1−ν²)],   k = ρ_w g
```

并在同一状态上补齐此前完全缺失的一环：**冰厚 h、冰温 T、加载速率 v 对最大弯曲应力 σ_max 的依赖律**（缺口：冰材料状态在旧链路里是硬编码常数）。

**几何与参考状态。** 无限大冰板用边长 200 m（≈ 13.8 l）的方形域加自由边近似，网格以载荷点为中心几何分级加密（中心单元 0.10 m，最外单元见 C1 表 `max_element_m`）。接触斑为半径 0.5 m 的均布圆（船首接触斑），参考载荷 P = 5.00e+05 N。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**2.1 独立数值面：2-D BFS Kirchhoff 板单元 + Pasternak 地基项。** 使用仓内已验证的 Bogner–Fox–Schmit（4 自由度/节点、16 自由度/单元）板单元，地基按 `∫ k N Nᵀ dA + g_p ∫ ∇N·∇Nᵀ dA` 组装（`BFSPlateSolver(foundation_model='pasternak')`）。网格 x、y 双向几何分级（`graded_axis_centered`），载荷为圆斑均布压力（4×4 Gauss，仅在斑内积分）。

**2.2 闭式锚：Hetényi / Vlasov–Kerr Green 函数。** 无限大板算子分解为 `D(∇²−m₁)(∇²−m₂)`，`m₁,₂` 为 `D m² − G_p m + k = 0` 的两根，集中载荷 Green 函数为 `w(r) = P/(2π√Δ)[K₀(br) − K₀(ar)]`；圆斑载荷用环积分把它正则化（`pasternak_patch_field`，`n_source` 个环源 × 径向场）。g_p = 0 时精确退化为 Kelvin/kei 解。

**2.3 判据 2 的 patch test（单元级一致性）。** 取均匀挠度场 `w ≡ w0 = 1 mm`（转角自由度置 0），对每个单元计算地基反力的积分等效值 `q_e = Σ(K_f^e u_e)/A_e`，要求 `q_e = k w0`；同时单独检查 Pasternak 剪切块 `∫ g_p ∇N·∇Nᵀ dA` 对常数场的贡献（应为 0）。Winkler / Pasternak / 分级网格三组都做。

**2.4 判据 4 的冰材料状态。** 新增 `tensorphysics.ice_sheet.ice_material`：

* `E(T, ε̇) = E_ref · [1 + 0.03(|T|−10)] · 1/(1 + (ε̇_ref/ε̇)^{(n−1)/n})`，`n = 3`（Norton–Bailey），`E_ref = 5 GPa @ |T| = 10 K`、`ε̇_ref = 1e-6 s⁻¹`（Michel 1978；Timco & Weeks 2010 的实测区间）；
* `σ_f(T, ε̇) = σ_ref · [1 + 0.04(|T|−10)] · min((ε̇/1e-5)^{1/3}, 2)`，`σ_ref = 0.7 MPa @ 10 K`（延性段按 `ε̇^{1/n}` 上升，越过延脆转变后饱和）；
* 板在载荷点的曲率速率 `κ̇ ~ v/l²`、最外层纤维应变速率 `ε̇ = (h/2)κ̇ = h v/(2 l²)`；`E ↔ ε̇ ↔ l` 用不动点迭代闭合（收敛 1e-12，本算例 7 次）。

**2.5 设计量。** 板是线性的，峰值弯矩与载荷成正比，故一次闭式求场即得 `M_max = P·m̂`：

* `σ_max = 6 M_max / h²`（给定载荷下的诱发应力）；
* `P_c = M_f / m̂`（首裂载荷，`M_f = σ_f h²/6`，无需二分）；
* `utilization = σ_max / σ_f`（给定载荷相对开裂的裕度）。

**2.6 工具链。** Python 3 + numpy/scipy（FEM 组装与求解）、matplotlib（图）、pytest（python -m pytest -q tests/test_ice_sheet_design_laws.py）、JSON 程序化注入。环境：Python 3.11.6，numpy 2.4.6，Linux-6.6.52-1.7.lns23.loongarch64-loongarch64-with-glibc2.38（loongarch64）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **接触斑分辨率决定 m̂。** 圆斑载荷的峰值弯矩落在斑内，径向采样必须分辨接触半径：`n_field=801, r_max=1·l` 时 `dr ≈ R_c/8`，与 `9601×96, r_max=8l` 参考解的相对差 2.06e-04；用 `r_max=8l` 的默认网格（`dr ≈ 0.19 m > R_c/3`）会把 m̂ 低估 4 %——**这是本节点最容易踩的精度坑**。

2. **相对误差在零点无意义。** Kelvin/kei 型挠度在 r ≈ 3.9 l 处变号，点式相对误差在那里爆炸到 20 %+，但绝对误差仍 < 1e-4 m。故判据同时报告两种度量：`max|Δw|/max|w|`（归一化绝对误差）与「仅在 |w_ana| ≥ 10 % 峰值处取相对误差」。**判据窗口取到 5 l 就必须这样定义误差**，否则任何解都过不了。

3. **β=1 的 Pasternak 剪切层把载荷铺到 ~400 m。** β=1 时 γ≈878（实数根区），长衰减长度由 `√(G_p/k)` 主导（数百米量级），因此闭式锚（无限域）与 FEM（有限域）**不具备可比性**：C1 因此选 Winkler（γ=0）与 γ=1 两档做对标，而不是直接拿 β=1 全尺寸做 FEM 对标——把 β=1 塞进 200 m 的域里，误差反映的是边界截断而不是离散误差。**这是本节点明确声明的适用范围。**

4. **温度/速率对诱发应力的影响是弱量级。** σ_max 对 |T|、v 的敏感性都只经由 `E` 进入（诱发应力不需要强度），量级 |dlnσ/dlnE| ~ 1e-2；而 σ_f、P_c 对 |T|、v 的依赖是一阶的（本算例 σ_f 0.38→1.40 MPa，即 +272 %）。**判据 4 的三条符号实际混用了两种不同的 σ_max 定义**，见 §3.7 与 §6 的如实判定。

5. **材料律是工程插值，不是本构。** `E(T,ε̇)`、`σ_f(T,ε̇)` 是穿过实测区间的单调内插（常数全部具名、可覆盖），未建模盐度/孔隙率、晶粒结构、高温蠕变损伤，也未建模延脆转变**之后**的强度软化分支（本节点只用饱和段）。用于量级与**符号**级别的设计律，不用于定量预报。

6. **分数模型的计算成本。** 每次 `pasternak_patch_field` 约 0.4 s，一因子扫描 + 网格共 40 次调用；FEM 解在 200 m/90 单元下 ~5 s。本节点所有数字在一台节点上 ~5 min 内可复算。

7. **作业环境坑。** 运行期间共享节点 overlay 一度 100 % 满（`No space left on device`），表现为 import/pytest 莫名挂起——排查时先看 `df -h`，不要误判为代码死循环。

|---|---|---|---|---|
| C1 位移（Pasternak γ=1，r/l∈[0.1,5]，掩膜） | 0.008915 | Hetényi/Pasternak 闭式解 | 0.05 | 是 |
| C1 位移（Winkler，r/l∈[0.1,5]，掩膜） | 0.008349 | Hetényi/Kelvin 闭式解 | 0.05 | 是 |
| C1 归一化绝对误差（Pasternak） | 0.001747 | 闭式解峰值 | 0.05 | 是 |

**判据 4 的逐条如实判定。**

* (4a) `∂σ_max/∂h < 0`：**满足**。Pasternak 下 dlnσ/dlnh = -0.959；Winkler 下 -1.807（更接近纯板 h⁻²）。

* (4b) `∂σ_max/∂|T| < 0`：**在战役标定 β=1 下满足，但效应极小**（|T| 从 2 K 到 30 K，σ_max 仅由 241369.7 Pa 变到 241325.2 Pa，即 -0.018 %）。**换 Winkler 地基则符号翻转**（1214261 → 1271162 Pa，+4.69 %，见 §3.6 的 β 扫描）。因此「∂σ_max/∂|T| < 0」**不是稳健的物理事实，而是地基模型的产物**：在剪切层主导（γ≫2）时，更冷→E 更大→剪切层 G_p ∝ E 更强→载荷铺得更开→局部峰值略降；而在 Winkler 下 E 增大使特征长度 l ∝ E^{1/4} 变长、峰值弯矩 ∝ ln(l/R_c) 上升，符号相反。

* (4c) `∂σ_max/∂v > 0`：**不满足（如实 FAIL）**。诱发应力在固定载荷下随速率**略微下降**（Pasternak dlnσ/dlnv = -1.62e-05，量级 < 0.01 %），因为速率只通过 E 进入诱发应力，且其效应与温度同号。速率律的物理在**强度/承载力**一侧：`σ_f` 从 0.38 MPa 升到 1.40 MPa（+272 %），`P_c` 从 0.779 MN 升到 2.900 MN——两条承载力判据（d σ_f/dv > 0、d P_c/dv > 0）**均为 PASS**。

补充：`σ_f` 的速率律在 ε̇ ≳ 8e-5 s⁻¹ 后进入饱和段（rate cap = 2），故 β=1 速率扫描的上半段 `dσ_f/dv = 0`（audit 表中 sign 记为 0）；这不影响 `dP_c/dv > 0`（m̂ 随 E 仍在下降）。

**结论（诚实声明）。** 判据 1、2、3 全部以远优于阈值的余量通过（1.1 % / 1.5e-12 / 3.3e-9）。判据 4 的三条符号判据**不能由同一个 σ_max 定义同时满足**（§3.7 审计表：四个候选定义 × 两个地基模型，无一满足全部三条）；按任务书字面（诱发应力、β=1）判定为 4a PASS、4b PASS（弱且不稳健）、4c **FAIL**。**honest FAIL 不被覆盖**：本报告不通过改定义的方式让 4c 变绿，而是把它作为「任务书判据内部不自洽」的否定性证据登记，并给出物理上正确的替代陈述：速率/温度的工程后果体现在承载力（σ_f、P_c）而非诱发应力。
