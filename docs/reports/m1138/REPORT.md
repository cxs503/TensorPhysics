## 1 案例介绍

### 1.1 物理背景

破冰船以低速（1–3 m/s）冲撞冰盖时，船首把冰盖压碎并在冰盖内激发弯曲波；当冰盖下表面最大主拉应力超过冰的弯曲强度 σ_f 时，冰盖发生**弯曲断裂**：先在接触区下方萌生**径向（星形）裂纹**，随后在距接触点若干特征长度处由**上表面**拉应力萌生**环向（周向）裂纹**。冰盖的动态响应由三层物理耦合决定：

1. 冰盖：薄弹性板（Kirchhoff–Love），含面内惯性 ρ_i h、弯曲刚度 D、分布阻尼 c；
2. 流体：势流，扰动速度势满足 Laplace 方程，冰-水交界面运动学条件 ∂φ/∂z = ẇ，水底不可穿透；
3. 耦合：流体压力通过非定常 Bernoulli 关系 p = −ρ_w ∂φ/∂t 反作用于冰盖，与板惯性合成**随波数变化的附连质量** m_a(k)；
4. 船首冲击：楔形船首以速度 V 侵入，碎冰压强服从经验压力-面积律，接触力推动冰盖（船体减速），形成冲击载荷时程。

### 1.3 控制方程（实现形式）

每个二维 Fourier 模态（波数 κ）上耦合系统化为单自由度阻尼振子：

```
m(κ) ẅ + c ẇ + K(κ) w = p̂(κ,t),   w>0 向下
m(κ) = ρ_i h + m_a(κ),   K(κ) = D κ⁴ + ρ_w g
m_a(κ) = ρ_w / (κ tanh(κH))          (H→∞: ρ_w/κ)
```

附连质量来自 Laplace 方程 + 冰-水运动学条件 + 水底不可穿透条件的解析解 φ = A cosh(κ(z+H))，与**独立的一维深度有限元解**逐点比对（相对误差 <2e-3）。κ=0（整体铅垂平动）模态被显式排除：刚性底 + 无限覆冰下该运动需无穷侧向流量，附连质量发散；这与经典无限大板解（零均值挠度）一致。

断裂判据（Kirchhoff 板，w 向下为正，拉为正）：

```
σ_xx = −C (w_,xx + ν w_,yy),  τ_xy = −C(1−ν) w_,xy,  C = Eh/(2(1−ν²))    (下表面)
σ_1 = (σ_xx+σ_yy)/2 + sqrt( ((σ_xx−σ_yy)/2)² + τ_xy² )  ≥ σ_f  ⇒ 断裂
```

下表面拉应力峰值区 → 径向裂纹；远场板面上拱、上表面拉应力峰值处 → 环向裂纹。

## 2 怎么做的（方法 / 流程 / 关键设置）

1. **解析锚（色散，判据 a）**：`FlexuralDispersion` 实现 ω² = (Dκ⁴+ρ_w g)/(ρ_i h+m_a)。在时域求解器中放一个**单网格模态平面波**与一个**波包**，分别测量 ω（过零点序列）与 λ（空间谱）、群速度（能量包络质心漂移，右行初值 v̂ = −i·sgn(k_x)ω(κ)ŵ）；把测得 ω 代回解析色散求 λ，与测得 λ 比对。
2. **解析锚（静力，判据 b）**：`static_plate` 用 FFT 求解 `D∇⁴w + ρ_w g w = p`（13 点双调和格式 = (∇²_h)²，符号 (2cos+2cos−4)²/dx⁴），与 Hetényi/Kelvin 函数级数解 `w(r) = −P/(2πρ_w g ℓ_c²)·kei(r/ℓ_c)` 及**独立 Hankel 求积**（高斯斑载荷的解析 Hankel 变换 + 复合 Simpson，收敛到 2.6e-11）比对；并做周期域截断收敛研究（L/ℓ_c = 11.2→44.7）。
3. **船首冲击（判据 c）**：楔形船首接触宽 b=2δtanα（限幅），压碎面积 A=b·h，力 F=p(A)A；船体 M dV/dt = −F 显式耦合，穿透量 δ = ξ − w_contact（扣除冰面自身下沉）。解析锚：纯刚体冲撞的封闭解 F_peak = K^{2/3}((3/4)MV²)^{1/3}，K = C√(2 tanα·h)。同时校验冲量-动量定理 ∫F dt = M(V₀−V_end)。
4. **断裂（判据 d）**：每 20 步由谱导数恢复下表面主应力场，取首个超阈时刻/位置；同一时刻计算上表面主应力场的远端极值点 → 环向裂纹半径。
5. **能量账（判据 e）**：冰盖弯曲能 ½D∫(∇²w)²、浮力势能 ½ρ_w g∫w²、冰面动能 ½ρ_i h∫ẇ²、流体动能 ½∫m_a ẇ²（Parseval 求和，权重 A/N²）、阻尼耗散 ∫∫c ẇ²、压碎功 ∫F dδ、断裂能 G_c·h·L_crack（G_c=K_Ic²/E≈1.6 J/m²）。船首动能释放 = 以上各项之和。
6. **辐射工况**：等速移动载荷（V=40 m/s = 2.42 c_min，c_min=16.55 m/s 为冰-水系统最小相速度）→ 超声速弯曲波前 + 水下辐射压力场。
7. 工具链：NumPy/SciPy（FFT、Bessel/Kelvin 函数、求积、brentq）+ matplotlib（图 + Pillow GIF 动画）+ pytest（6 个测试文件，36 个用例）。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **周期域截断＝静力误差主因**：无限大板的 Kelvin 函数解有缓慢衰减的振荡尾，周期盒把它折回。L/ℓ_c=11 时误差 6.5%，L/ℓ_c=45 时降到 0.22%（§3.2 表即截断收敛证据）。**任何 ≥5% 的静力偏差先查域长，而非查格式**。
2. **谱方法中载荷的归一化**：模态方程里的强迫项必须是**离散** Fourier 变换（= 连续变换 ÷ dx·dy）。漏掉 1/(dx·dy) 会让挠度/能量整体放大 1/(dx·dy) 倍（本项目早期版误差达 1e4 量级）；已由 `test_patch_load_normalisation` 锁定。
3. **能量求和必须用 Parseval 权重 A/N²**（而非 A/N），否则能量随网格数漂移；已由自由振动 4e-15 漂移与 `test_free_vibration_conserves_energy` 锁定。
4. **接触斑抹平（主要定量局限）**：压碎面积 3.3 m² ⇒ 等效斑标准差 √(A/2π)=0.73 m，而网格 dx=0.75 m，程序取 σ=max(√(A/2π), 1.5dx)=1.125 m。静态敏感性（`contact_patch_sensitivity.json`，P=4.73 MN，dx=1.5 m）：σ=0.75 m → σ₁=5.75 MPa；1.125 m → 4.40 MPa（−23%）；2.0 m → −42%；4.0 m → −58%；6.0 m → −68%；而中心挠度仅变化 −11%（0.1142→0.1018 m）。**结论：积分量（力/能量/挠度）对接触斑不敏感，局部应力峰值与裂纹时刻敏感 ⇒ 裂纹时刻应视为 ±25% 量级的不确定量**。
5. **势流"准静态"假设**：忽略冰外自由面的重力波记忆项。冰盖连续覆盖时该假设合理；对破碎带/开水面附近的辐射（尤其超声速工况）会低估辐射阻尼，属已知偏差方向。
6. **刚性底与常水深**：水底不可穿透、水深恒定 50 m；浅水会显著增大附连质量（m_a ∝ 1/tanh κH）。
7. **无限大板、忽略冰缘自由边**：船首接触处实际是浮冰边缘。自由边会降低局部刚度、增大挠度，故本文的接触力峰值与应力峰值属**偏保守（偏大）**一侧。
8. **Kirchhoff 小挠度**：w_max=0.107 m vs h=1.5 m（w/h=0.07）满足小挠度；但断裂算例触发时刻的局部应力已远超弹性极限，断裂后行为（碎块、二次破碎、重复加载）不在本模型范围内——本节点只给**裂纹萌生**时刻与位置。
9. **弹性算例是 "energy-audit" 算例**：Case-IMPACT-elastic 关断断裂判据以覆盖完整冲撞时程做能量审计，其峰值应力 4.15 MPa 远高于 σ_f，物理上早已开裂；该算例的用途仅限能量账与载荷时程，不可当作"无损伤"结果引用。
10. **σ_f 依赖**：冰弯曲强度强烈依赖温度/盐度/尺度（0.3–1.5 MPa）。t_c ∝ (σ_f/σ_ref)² 量级，σ_f 加倍会使裂纹时刻后移约 4 倍（准静态近似）。
11. **阻尼模型**：分布 Rayleigh 型阻尼 c=2e3 Pa·s/m（≈5% 临界），非频率依赖；实际冰盖阻尼含破碎耗散，本模型把破碎耗散归入压碎功。
