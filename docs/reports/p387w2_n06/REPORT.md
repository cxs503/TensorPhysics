# p387w2-n06：J2 弹塑性梁/板三层验证面（M-κ · 塑性铰 · 卸载回弹）

**仓库**：TensorPhysics（`src/tensorphysics/plasticity/{beam_hinge,plate_limit,verification_hinge}.py`）  
**证据等级**：REAL（纤维截面径向返回映射 + 位移法弹塑性梁单元 + 经典极限分析闭式解）  
**验收**：37 条机器判据 37/37 PASS，3 条负控全部按预期 FAIL（证据 `artifacts/p387w2_n06/evidence.json`，`all_passed=True`）

## 1 案例介绍

船体梁/板在总纵极限强度、碰撞与屈曲后阶段的工作点落在弹塑性区间：结构先弹性承载，随后在弯矩最大截面形成塑性铰，卸载时保留残余曲率（回弹/残余变形）。本节点的验证面覆盖**从弹性到塑性铰到卸载回弹的完整路径**，为后续极限强度、碰撞、屈曲后行为提供可机器裁决的锚点。

物理模型：单轴 J2 流动理论（线性各向同性硬化 `σ_y = σ_y0 + H·ε_p`），平截面假定 `ε = κ·y`，截面弯矩 `M = Σ σ_i A_i y_i`（纤维积分），梁为 Euler-Bernoulli（Hermite 三次形函数，位移法有限元，跨内分布式纤维塑性）。

## 2 方法

### 2.1 截面层（Layer 1）

* `FiberSection`：以高斯求积 + 精确宽度函数把截面离散为纤维，同时给出**纤维积分值**与**闭式值**（`A, I, W_el = I/c, Z = ΣA|y|`），两条独立路径互校。
* `section_response`：单轴径向返回映射（含子增量），返回 `M(κ)`、算法切线 `EI_t`、可恢复弹性能与塑性耗散；另提供全束批量化版本 `_section_response_batch` 供有限元装配。
* `moment_curvature`：κ 单调加载至 20κ_y；`unload_from`：沿弹塑性路径反向卸载至 M=0，给出残余曲率（含反向屈服检测）。

### 2.2 梁层（Layer 2）

* `solve_beam`：位移法 Euler-Bernoulli 有限元，每个跨内高斯点独立积分纤维截面本构；Newton 迭代 + 残差型线搜索 + 增量失败二分 + 自由度的转动缩放（条件数 O(1e4)），带状 Cholesky（`scipy.linalg.solveh_banded`）求解。
* 两个基准结构：
  1. **门型悬臂梁（固支-简支）受均布载荷**——一次超静定，极限分析给出机构铰位置 `x/L = √2/(1+√2) = 0.585786` 与极限载荷因子 `q_c L²/M_p = 4/t + 2/(1-t) = 11.6569`；
  2. **简支梁受偏心集中力（a = 0.3L）**——静定，塑性铰位于加载点 `x = 0.3L`。
* 塑性铰定位器 `interior_hinge_centroid`：塑性曲率场在内铰邻域的加权形心（相对于 Gauss 点 argmax 具有超收敛性，见 §5 网格研究）。

### 2.3 板层与能量审计

* `plate_limit`：刚性-理想塑性屈服线（机构）上限解，内部功 = Σ M_p·ℓ·θ（铰线相对转角由两小面梯度差在铰线法向的投影给出），外部功 = ∫p·δ dA（小面线性场取形心）。实现三种机构：矩形四角铰（a=b 即经典金字塔机构）、条带中线铰、圆板锥形机构。
* 能量审计：截面级 `∫M dκ = U_el + W_pl`；梁级 `Σ λ_mid·f·Δd = U_el + W_pl`（梯形积分）。

### 2.4 判据与工具链

`verification_hinge.run_all_criteria()` 统一产出 `criteria` 列表（model / reference / error / tolerance / passed）与 `negative_controls`，`generate_p387w2_n06_figures.py` 落盘 JSON+图，本报告的全部数字由该 JSON 注入。工具链：numpy 2.4.6 / scipy 1.16.0 / matplotlib 3.10.8 / pytest。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **转动自由度缩放是硬条件**：不解缩放时梁刚度矩阵条件数 O(1e10)，细网格下 Newton 残差无法降到 1e-9（本机 numpy 每次 `linalg.solve` 约 50 ms，120×120 也要 41 ms），改为 `dof_scale(θ)=le` + 带状 Cholesky 后，同一算例从 25 s 降到 4 s，残差降到 1e-12。
2. **铰位置必须用形心估计器而非 Gauss 点 argmax**：argmax 受网格偏置，40 单元时内铰 argmax 给出 0.597（偏差 1.14 % 跨长，超门限），形心估计器给出 0.595（0.94 %），60 单元时 0.5863（0.05 %）。**20 单元不足以定位内铰**（见下表），验收用 60 单元。
3. **理想塑性 + 载荷控制会在机构点奇异**：有限元取 H = 1e-3·E 保证切线正定，并把载荷加到 0.99 q_c；真正的 q_c 由极限分析闭式给出，不与有限元（有硬化，略高）混淆。
4. **弹性卸载增量必须用 E·I 而非切线刚度**：理想塑性截面在塑性平台的算法切线近于 0，用它定卸载步长会一步跨过零点并触发反向屈服，导致 κ_res 误差 −39 %；改用 `M/(E·I)·1.5` 分 100 步后误差 ≤0.003 %。
5. **梁级能量残差对载荷步长敏感**：8 步时 2.1e-3、40 步时 7.1e-5；报告统一采用 40 步。截面级审计（半步子增量）本身已达 1e-5 量级。
6. **适用范围**：小变形、无膜力、比例加载、单轴 J2（平截面假定）；板层为理想塑性极限分析（不给出载荷-位移路径），膜力/大挠度（碰撞造形）不在包线内；圆板锥形机构与方板金字塔机构在长宽比 a/b ≳ 4 后不再紧致（12 M_p/b² vs 条带 8 M_p/b²），长板应使用条带机构。

## 6 误差判定（逐项 vs 基准，显式回答是否 < 3 %）

| 关键量 | 基准 | 最大误差 | 是否 < 3 % |
|---|---|---|---|
| 弹性斜率 EI | 闭式 E·I | 0.001 % | 是 |
| 屈服弯矩 M_y | 闭式 σ_y·W_el | 0.001 % | 是 |
| 全塑性弯矩 M_p | 闭式 σ_y·Z | 0.123 % | 是（门限 5 %） |
| 塑性铰位置 | 极限分析 0.585786 / 0.3 | 0.304 %（占跨长） | 是 |
| 卸载残余曲率 | 闭式理想塑性 / 弹性卸载恒等式 | 0.182 % | 是 |
| 能量守恒残差 | 0（恒等式） | 8.100e-05（相对） | 是 |
| 板极限压强 | 24 / 6 / 8 M_p 归一化 | 3.125e-04 % | 是 |

结论：全部判据均在门限内，且主要量（EI、M_y、铰位置、回弹、板极限）误差远小于 3 %；M_p 采用 5 % 门限（理想塑性需 κ→∞ 的渐近值，20κ_y 处截断所致 0.09–0.12 %）。无 MOCK/STUB：所有参考值均来自闭式解或独立极限分析，负控证明门限可被违反。
