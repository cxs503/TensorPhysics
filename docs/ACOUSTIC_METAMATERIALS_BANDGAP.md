# 局域共振声学超材料板弹性波带隙验证面

## 1. 案例介绍

### 物理背景
声学超材料通过亚波长尺度的局域共振单元实现弹性波带隙——一种传统材料无法实现的波传播禁阻频带。本验证面建立了局域共振周期板中弯曲波带隙的完整分析链：

- **周期单元**：正方周期单元 L×L = 50mm×50mm，内部附质量-弹簧谐振子
- **带隙机理**：谐振子在固有频率附近产生负有效质量密度，阻止弯曲波传播
- **工程应用**：振动隔离、噪声控制、波导设计

### 参数表

## 2. 方法

### 2.1 Bloch-Floquet 周期分析

对纯板（无谐振子），使用解析色散关系：
$$\omega = \sqrt{\frac{D}{\rho h}} \cdot k^2$$

通过 Brillouin 区折叠确保严格的 Bloch 周期性：ω(k) = ω(k + 2π/L)。

### 2.2 局域共振带隙

对超材料板，使用有效质量密度方法：
$$\rho_{\text{eff}}(\omega) = \rho h + \sum_r \frac{m_r}{L^2} \cdot \frac{\omega_r^2}{\omega_r^2 - \omega^2}$$

带隙出现在 ρ_eff < 0 的频带，即 ω > ω_r 区域。

### 2.3 带隙边界

- **下边界**：f_lower = f_r（谐振子共振频率）
- **上边界**：f_upper 由 ρ_eff(f_upper) = 0 确定

### 2.4 传递损失分析

使用等效介质方法计算有限板的传递损失：
- 带隙内：衰减 ∝ N_cells × ln(1 + |ρ_eff|/ρ_base)
- 带隙外：有限板共振控制（低频）或质量定律（高频）

## 5. 注意点

### 局限
1. **半解析模型**：使用有效质量密度方法而非完整 FEM，适用于长波极限
2. **1D 谐振子**：仅考虑横向振动，未考虑面内耦合
3. **无阻尼带隙**：实际带gap 边缘因阻尼而模糊
4. **有限尺寸效应**：传递模型使用简化假设

### 适用范围
- 薄板（h/L < 0.1）
- 亚波长带隙（f_r 对应波长远大于 L）
- 弱耦合（谐振子质量 ≪ 板质量时带隙窄）

### 改进方向
- 完整 FEM Bloch-Floquet 分析（Kirchhoff/Mindlin 板单元）
- 多谐振子、非对称单元
- 实验验证
