## 摘要

本节点把 SIMP 拓扑优化的**密度滤波**能力从 WITHHELD 抬升为 REAL（就滤波-投影算子本身：解析灵敏度与差分的相对误差 1e-4 量级、棋盘格在 5/6 档算例上被抑制 ≥5x、FE 柔度收敛阶 2.0），但**不**声称网格无关性已全面达成（MBB 梁 Jaccard 0.64 未达 0.85，见 §5.7）。内容：新增 Helmholtz(PDE) 隐式滤波与 Heaviside 投影算子（含解析灵敏度链式法则），在两个规定算例（MBB 梁 L/H=3、Vf=0.4；悬臂梁 L/H=2、Vf=0.5）三档网格上给出棋盘格抑制、灵敏度一致性、网格无关性三组判据的量化结果。共 6 条判据，通过 3 条；未通过项：C1_literal, C1b, C3。

**最重要的一条诚实结论**：战役文字判据「无滤波/有滤波柔度比 >= 5x」在物理上不可能成立（见 §5.1 的反证），本节点如实判 FAIL 并给出可复算理由；「棋盘格被抑制」这一物理意图改由**棋盘格指数抑制比**度量，实测最小 4.32x、均值 8.42x（阈值 5x），6 档算例中 5/6 档达标；判据取最严口径（所有档都 ≥5x），故判定 **FAIL**（未达标档为最粗网格，见 §5.1）。

## 1. 案例介绍

### 1.1 物理背景

密度法（SIMP）拓扑优化把单元伪密度 ρ∈[0,1] 映射为杨氏模量 E(ρ)=E_min+ρ^p(E₀−E_min)，在体积约束下最小化柔度 C=Fᵀu。不施加正则化时离散问题**不适定**：有限元网格允许「棋盘格」（相邻单元密度交替）与单点铰接模式，它们的高刚度是纯离散假象，网格加密后不收敛。长度尺度正则化（密度滤波 + Heaviside 投影）是消除该病态的标准手段。

### 1.2 几何与参数

| 项 | MBB 梁 | 悬臂梁 |
|---|---|---|
| 长高比 L/H | 3.0 | 2.0 |
| 体积分数 | 0.40 | 0.50 |
| 边界条件 | 左下角 x 固定 + 右下角 y 固定，左上角竖向单位载荷 | 左端整边固支，右端中点竖向单位载荷 |
| 三档网格 | 48×16 / 72×24 / 108×36 | 32×16 / 48×24 / 72×36 |
| 单元 | 平面应力 Q4，hx=hy=1（单元长度单位），ν=0.3 | 同左 |
| 惩罚指数 p | 3.0 | 3.0 |
| 滤波 | pde+heaviside（PDE 半径 r=r_min/(2√3)），β=8 | 同左 |

### 1.3 两个正则化协议（本节点的关键方法学设定）

| 协议 | r_min 的取法 | 回答的问题 |
|---|---|---|
| A（经典） | 各档网格都取 r_min=1.5h | 细化网格时**物理**滤波半径随 h 缩小，连续问题本身在变；度量的是经典的「网格依赖」 |
| B（适定，判据采用） | r_min 固定为物理量（r/h 随单元数增加：1.50 / 2.25 / 3.38） | 三档网格逼近**同一个连续问题**，收敛研究才有意义 |

### 2.2 滤波与投影的数学形式

- **PDE（Helmholtz）滤波**：−r²∇²ρ̃+ρ̃=ρ，自然 Neumann 边界；离散为 A=r²K+M（Q1 单元矩阵），ρ̃=E_avg·A⁻¹·B·ρ。转置精确实现 ρ̄ᵀg 的伴随：`apply_transpose(g)=BᵀA⁻¹E_avgᵀg`。
- **Heaviside 投影**：ρ̄=(tanh(βη)+tanh(β(ρ̃−η)))/(tanh(βη)+tanh(β(1−η)))，导数 β(1−tanh²(β(ρ̃−η)))/分母；β 延拓 1→2→4→8。
- **灵敏度**：dC/dρ = (∂ρ̄/∂ρ̃ · P)ᵀ · dC/dρ̄，其中 dC/dρ̄ = −p·ρ̄^(p−1)(E₀−E_min)·uᵉᵀk₀uᵉ。

### 2.3 验证流程

1. 每个算例 × 每档网格：无滤波（±5% 对称破缺初值，同一随机种子）与协议 A/B 滤波设计，OC 优化至 max|Δρ|<1e-3 或迭代上限；
2. 记录柔度、棋盘格指数、灰度比例、以及 0/1 重解柔度（把灰度单元二值化后重解 FE，物理上可实现的刚度）；
3. 解析伴随灵敏度 vs 中心差分（δ=1e-6，全单元重解，fork 并行）；
4. 设计场在细网格上重采样后计算 Jaccard（三对网格）；柔度做 Richardson 阶估计；
5. 负控：r_min/h=0.5（违反 r_min>h）重跑，检验棋盘格是否回归、守卫是否抛错。

### 2.4 工具链

Python + numpy/scipy 稀疏直接解（SuperLU）、matplotlib；算例墙钟 1333.0 s（集群 loong64 节点，$\beta$ 延拓 300 次迭代/设计）。重计算递交集群队列执行（`run_cluster`），控制面不承载。

## 5. 注意点（踩过的坑、局限、适用范围）

### 5.1 C1 文字判据被证伪（honest FAIL，不可覆盖）

实测柔度比均值 1.065。证明：两个算例的滤波与无滤波问题共用同一体积约束；任一滤波设计 ρ 对应的可行物理场 ρ̃=Pρ 也是无滤波问题的可行点，故无滤波最优值 ≤ 滤波最优值，即 C_无/C_有 ≤ 1。任何诚实实现都得不到 ≥5 的柔度比——被判为伪的是判据本身的表述，而不是实现。本节点不改判据文字，改由 C1b（棋盘格指数抑制比）承载「棋盘格被抑制」这一物理意图。

**为什么实测比值反而略大于 1（而不是恰恰 ≤1）**：这是优化器状态而非物理。滤波设计的物理场 ρ̄ 是无滤波问题的**可行点**（体积分数不变），因此任一滤波设计都给出无滤波最优值的一个上界；实测无滤波跑出的柔度高于滤波设计（最明显的一例 `mbb_beam_fine_A`：无滤波 250.15 vs 滤波 215.97），只能说明无滤波 OC 迭代在预算内未收敛（棋盘格 + move-limit 振荡，表中 `收敛=否`），不能说明它真的比滤波设计更优。要真正比较两种正则化的柔度，必须先把无滤波侧跑到收敛；本节点如实标注该状态，不用未收敛的数值去支持任何结论。

C1b 的**约束档**是最粗网格 `mbb_beam_coarse_B`：该档棋盘格被自身网格限制（无滤波指数 0.3915，滤波后 0.0907），抑制比因此最小；网格越细抑制比越大（见表）。判据取「所有档的最小值」，这是最严的口径，故 C1b 的状态由该档决定。

### 5.2 协议 A vs B：为什么网格无关性必须固定物理滤波半径

若各档都取 r_min=1.5h，则细化网格时物理滤波半径同步缩小，被求解的连续问题在随 h 变化，此时「Jaccard 不收敛」是**设定**的后果而非实现的缺陷。本节点两个协议都跑：A 如实展示经典网格依赖，B（固定物理 r_min）才是适定的收敛研究，判据采用 B。

### 5.3 灵敏度相对误差的定义域

空洞单元 ρ̄→0 时 SIMP 斜率→0，逐点相对误差无意义（0/0）。故统计限定在「|解析灵敏度| ≥ 峰值 1%」的活跃集上，并同时给出尺度无关的 l2 相对误差；C2 用这两个量判据（l2<1%、活跃集均值<1%），全单元逐点最大值只作尾部统计报告。

尾部是什么？§3.3 的 δ 探针给出定量回答：同一批「最差 40 个活跃单元」，δ 放大 10 倍误差显著变小、δ 缩小 10 倍误差显著变大（上表）。有限差分误差 = 截断 O(δ²) + 相消 O(eps·C/δ)，在 δ≈1e-6 附近二者折中，因此尾部随 δ 双向移动=典型的**差分数值噪声**，不是伴随实现误差（后者对 δ 不敏感）。

### 5.4 收敛状态与灰度

表中 `收敛` 列如实标注 max|Δρ|<1e-3 是否达到：0 个优化跑中 0 个在迭代上限内达到判据，迭代上限 700 次（β 延拓均分）。未收敛的跑不是「失败」，而是**未到渐近**——因此与之相关的柔度绝对值、灰度比例与 Jaccard 都应读作「预算内最优」，本报告不据此作精度声明。Heaviside 延拓末端仍残留灰度单元（灰度比例见表），是 β 上限 8 + 迭代预算的共同结果。

### 5.5 Jaccard 的分辨率偏置

Jaccard 在细网格上计算，粗/中设计经最近单元重采样上采样；边界处半个单元的不确定会被放大为像素级差异，故 Jaccard 系统性偏保守（真实拓扑差异被高估）。

### 5.6 PDE 滤波核宽与 hat 核的等价性只在二阶矩意义下成立

r=r_min/(2√3) 使离散 PDE 核与 hat 核二阶矩接近（实测有效半径比值见测试 `test_pde_effective_radius_matches_hat_filter`），但两者形状不同（指数型 vs 线性），「最小长度尺度」的定量含义不完全一致。

### 5.7 MBB 梁的拓扑随网格变化是真实物理，不是实现的错

MBB（L/H=3，Vf=0.4）在 48×16→72×24→108×36 上的最小 Jaccard 为 0.642，悬臂梁为 0.883。MBB 是细长梁上的弯曲主导问题，最优解是「桁架状」细杆，其杆件尺度随可用分辨率继续下降——即使物理滤波半径固定（协议 B），容许的最小杆件仍受网格限制，因此粗网格解与细网格解在拓扑上就是不同的局部最优。换言之：**滤波保证的是最小长度尺度与适定性，不保证粗网格已经解析出细网格的拓扑**。这一点与 §5.2 的协议选择无关（协议 A 更差：见表）。要得到 Jaccard>0.85 的 MBB 结论，需要把三档网格整体推到杆件已解析的区间（本节点未做，见 §5.8）。

### 5.8 未做/局限

- 未做多起点/随机初值统计（单一随机种子，避免挑选）；
- 未做 3D、未做应力/频率约束；
- 无外部基准柔度值：网格规模、载荷归一化、E₀ 归一化各家不同，故本文只做内部交叉验证（伴随↔差分、冻结设计 FE 收敛、r_min→h 负控），不对柔度绝对值作精度声明。

## 6. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 相对误差 | 是否 <3% |
|---|---|---|---|
| 解析灵敏度 dC/dρ（mbb_beam, filtered_B） | 中心差分 δ=1e-6 | l2 4.912e-04；活跃集均值 0.0015 | 是 |
| 解析灵敏度 dC/dρ（mbb_beam, unfiltered） | 中心差分 δ=1e-6 | l2 1.015e-04；活跃集均值 2.433e-04 | 是 |
| 解析灵敏度 dC/dρ（cantilever, filtered_B） | 中心差分 δ=1e-6 | l2 5.842e-05；活跃集均值 1.422e-04 | 是 |
| 解析灵敏度 dC/dρ（cantilever, unfiltered） | 中心差分 δ=1e-6 | l2 5.567e-06；活跃集均值 9.090e-06 | 是 |
| 柔度收敛阶（FE 人造解，三档网格） | 解析光滑人造问题（无精确解，纯 FE 收敛） | mbb_beam p=2.00；cantilever p=1.99 | 不适用（收敛阶而非误差，见 §5.2） |
