**节点** P493-N04 ｜ **仓** TensorPhysics ｜ **引擎** `src/tensorphysics/vv/mde.py` ｜ **驱动** `scripts/mde_calibration_p493n04.py` ｜ **台账** `artifacts/mde_calibration_p493n04/ledger.json` ｜ **测试** `tests/test_vv_mde.py`
> 本文件所有数字由 `scripts/mde_calibration_p493n04.py` 从同一次运行写入，零手抄；provenance（git head / 引擎与台账 sha256 / 种子）见 ledger.json。

## ① 案例介绍（对象、参数、判定口径）
对象不是物理场，而是**判据本身**。TensorPhysics 的验收门是判决器：对交付工件说 PASS / FAIL / WITHHELD。已发货的变异审计（IN50-W3-N08）回答的是「在 ε∈{1,3,15} % 阶梯上杀了多少 mutant」，却回答不了一个设计者必须回答的问题：**某个量错了 5 %，这条判据看得见吗？** 同一张 kill-rate 表里，「ε=1 % 就杀」与「ε=15 % 才杀」是同一个数字。
本节点校准的是**同一批判据对象**（直接 import `tools/audit/criteria_mutation.py` 的 `Criterion`，不重新声明，杜绝「审计的」与「校准的」两套分叉）：共 **17** 条，其中 **5** 条带连续数值字段（可注入相对偏差）、**12** 条是分类面判据（schema / 标识 / 量纲 / 闭包常数）。另加 **4** 条比例型（kill-rate KPI）判据：它的抽样噪声是二项分布固有的，不需要假设任何 σ。

| 参数 | 取值 |
|---|---|
| 偏差阶梯 | 1 % / 2 % / 5 % / 10 % / 20 % |
| 每判据每阶梯注入次数 | N = 100（Wilson 95 % 区间） |
| 证据散布阶梯 σ | 0 % / 1 % / 2 % / 5 % |
| 参考偏差（必须裁决） | 5 % |
| 平台精度红线 | 15 % |
| 注入模型 | `value → value·(1+δ)·(1+σZ)`，Z ~ N(0,1) |
| 检出定义 | 发货门对该 injected case 不再给 PASS |
| MDE_90 | 检出概率达 90 % 的最小偏差 |
证书分级：**STRONG** MDE_90 ≤ 5 %；**MARGINAL** ≤ 10 %；**WEAK** ≤ 20 %；**BLIND** > 20 %；**CENSORED** 阶梯内从未达 90 %；**NOT_APPLICABLE** 分类面判据。

## ② 怎么做的（方法 / 流程 / 工具链）
1. **同一批判据对象**：`load_shipped_ledger()` 以 importlib 载入已发货的变异审计模块，取 `GATE_ADAPTERS` 的 17 条 `Criterion`；校准器只消费 `value_fields` / `adapter` / `check`，门函数一行未改。
2. **注入器**：`gate_detector()` 把判据包成 `y → 是否拒绝`——对判据自己声明的 `value_fields` 做 `value·(1+y)`（复用发货的 `mutant_scale`，不是重写），再调用发货 adapter；判决从 `ContractResult.status`（或 GCI / vv 的 check dict）读取。
3. **四族 mutant**：系统性偏差（±1/2/5/10/20 %）、随机噪声（σ 阶梯，每级 N=100 抽样）、符号翻转（−5 %）、量级缩放（k = 1.05 / 2）。
4. **三路 MDE_90 估计 + 一路闭式对照**，并列上报，谁也不能盖住谁：
   - `mde90_exact`：确定性判据（σ=0）的决策边界，二分法精确取（台阶曲线无法用粗阶梯分辨）；
   - `mde90_mc_ladder`：N=100 检出曲线的 **probit 空间**插值（正态噪声模型下 Φ⁻¹(p) 对 δ 线性）；
   - `mde90_fit`：二项 IRLS logistic 拟合（坐标中心化 / 尺度化；近分离时显式报 `separation=True`，不硬给斜率）；
   - `mde90_theory`：有闭式的判据给对照——V&V 20 用 `delta* = (f_exp+U_val−f_sim)/f_sim`；比例型用精确二项功效。
5. **比例型判据**用 α=5 % 的边界检验（`k_crit = max{k : P(Bin(n,p_min) ≤ k) ≤ α}`），缺陷量 = 真实合格率相对 `p_min` 的下降；同时报**认证读数**（n 次全通过能否在 95 % 置信度下认证 p ≥ p_min）——两种读数不可混为一谈。
6. **工具链**：纯 Python + matplotlib（无新依赖）；`pytest tests/test_vv_mde.py` 覆盖闭式解、Wilson 覆盖、PAVA 单调性、logistic 复原、比例功效、端到端重放。

## ⑤ 注意点（坑、局限、适用范围）
1. **σ 不是判据的属性，是本节点的扫描变量。** 计算量（同一份代码、同一套网格）没有重复观测散布，因此 σ=0 是参考态；表 3a/3b 给的是「若这份证据带着 σ 的散布，MDE_90 与零偏差误报率变成多少」的敏感性面。把 σ=0 的结论外推到实验对比判据是错的。
2. **σ 一旦接近门带，判据就失去分辨力。** 本台账 13/20 个 (判据, σ) 组合进入「噪声饱和」：零偏差处就已触发（P_fa ≥ 50 %），此时 MDE_90 形式上是 0 而实际无信息——证书把它标成不可辨识，而不是记一个漂亮的 0 %。例如 `P20H-H6` 的门带是 1e-12 相对量（MDE_90 = 1e-10 %），任何 ≥1 % 的证据散布都会让它 100 % 触发。
3. **粗阶梯分辨不了台阶，也够不着亚百分点门带。** 节点规定的 1–20 % 阶梯对四条判据（门带 0.2 %–1.2 %）只能给出「≤ 1 %（阶梯下限）」；以粗阶梯插值当 MDE_90 平均会偏 174 %、最大偏 400 %。所以证书以二分法边界为准，阶梯曲线只作可复现实验证据。
4. **logistic 在近分离时不可用**：台阶曲线没有有限 MLE，代码显式报 `separation=True` 并把 MDE_50/MDE_90 置空，而不是输出一个看起来很确定的巨大斜率；σ=0 那一列的 「censored」就是这个机制。
5. **判据的判决必须按声明的子检查读。** 本节点第一版把门的整体判决（`result.status`）当检出判据，结果 GCI 门的 `noise-certificate` 警告让三条子检查（全 PASS）在零偏差处就「触发」，MDE_90 全部退化成 1e-12。改用台账自己的 `status_from_result(result, criterion.check)` 后基线误报为 0/9。**当一个判据声明了 子检查，整体判决不是它的判决。**
6. **比例型判据的两种读数必须分开**：「检出」（α=5 % 边界检验的功效）与「认证」（k 次全通过能否在 95 % 置信度下认证 p ≥ 90 %）是两个不同的判据。n = 22 时**没有任何观测结果**能认证 p ≥ 90 % @ 95 %（k_req 不存在，判据空转），认证所需最小样本量是 29。
7. **本台账只覆盖连续偏差可及的判据**：分类面判据（表 5）的 MDE_90 不是「很大」而是**无定义**——它们只对分类错误（schema / 标识 / 量纲 / 常数替身）有反应，必须由既有 kill-rate 审计认证，不能用本证书冒充。连续偏差覆盖率因此只有 29.4 %。
8. **最弱一环是平台自己的 KPI**：`KPIRATE-n22` 的 MDE_90 = 28.1 %——判据集合只有 22 条时，kill-rate 判据要看到 合格率下降 28 % 才有 90 % 检出；要看住 5 % 的下降需要 n ≈ 400（图 4）。这不是「判据写错了」，而是**小样本判据的检出强度上限**，只能靠扩大台账或改用 Wald/贝叶斯读法解决。
9. **适用边界**：结论仅对本台账的 17 条判据、其自带 demo case 与题设注入模型成立；换几何/换基准后门带数值会变，但方法与证书字段可直接复用。

## ⑥ 误差判定（逐项，显式回答是否 < 3 %）
本节点的「误差」是估计量误差，不是物理量误差，因此逐项给出可比基准：

| 量 | 基准 | 实测偏差 | 是否 < 3 % | 备注 |
|---|---|---|---|---|
| VVVAL-ratio MDE_90（二分法精确边界） | 闭式 `(f_exp+U_val−f_sim)/f_sim` | 4.665e-09 % | **是** | 二分法 vs 闭式，无插值 |
| 粗阶梯（1–20 %）插值 MDE_90（均值） | 二分法精确边界 | 174.3 % | **否** | 粗阶梯不足以分辨台阶 |
| 细化阶梯（对数 12 点）插值 MDE_90（均值） | 二分法精确边界 | 8.372 % | **否** | 阶梯离散度 |
| logistic 拟合 MDE_90（均值） | 细化阶梯 MC 插值 | 1.899 % | **是** |  |
| MC 抽样误差（N=100 vs N=1000） | 同一曲线的两次独立抽样 | 2.938 % | **是** |  |
| `KPIRATE-n22` MDE_90（N=100 MC） | 精确二项功效 28.1 % | 12.42 % | **否** | N=100 抽样波动 |
| `KPIRATE-n29` MDE_90（N=100 MC） | 精确二项功效 23.5 % | 6.795 % | **否** | N=100 抽样波动 |
| `KPIRATE-n100` MDE_90（N=100 MC） | 精确二项功效 10.6 % | 2.177 % | **是** |  |
| `KPIRATE-n400` MDE_90（N=100 MC） | 精确二项功效 4.89 % | 2.342 % | **是** |  |

**结论**：9 项估计量核对中 **5 项 < 3 %**、4 项 ≥ 3 %。确定性判据的 MDE_90 与闭式基准一致到机器精度（4.7e-9 % 量级），是因为二分法直接解出判据自身的门带，不经过任何插值——**这一项严格 < 3 %**。超过 3 % 的三类都属方法论预期而非物理误差：(a) 粗阶梯插值受阶梯分辨率限制（故证书不用它）；(b) 细化阶梯插值仍有约 8 % 的离散度（对数阶梯的相邻档间隔所致）；(c) N=100 的 MC 抽样在比例型判据上带来 2–13 % 波动——报告以精确二项为准，并把 MC 值作为可复现实验证据并列上报，不粉饰。
