## 1. 案例介绍

### 1.1 物理背景

船体板（甲板、舷侧、上层建筑、冰带加强板）越来越多采用纤维增强层合板。与均质各向同性板
相比，层合板有两个本质差别：

1. **刚度分层**：面内刚度 `A`、耦合刚度 `B`、弯曲刚度 `D` 三块矩阵独立（`B ≠ 0` 即拉-弯耦合）；
2. **弯曲-扭转耦合**：铺层序列非正交各向（如 `[±45]s`）时 `D16, D26 ≠ 0`，弯曲刚度张量
   出现 `w,xx·w,xy` 型交叉项，Navier 双三角级数的模态解耦失效，板因此出现斜向（skew）
   变形与边界层。

因此「层合板板的解析验证面」必须同时给出：**精确解（闭式）**、**独立第二解法**、
**厚板修正（FSDT）** 以及**退化负控**，否则无法区分「实现正确」与「实现与自身一致地错」。
本节点正是这条验证面。

## 2. 方法：三重裁决 + 厚板修正 + 负控

| 解法 | 数学形式 | 适用面 | 在本节点中的角色 |
|---|---|---|---|
| **CLT-Navier** | 双三角级数 `w=ΣΣ W_mn sin(mπx/a) sin(nπy/b)`，逐模态闭式 `W_mn = q_mn / π⁴(D11 m⁴/a⁴ + 2H m²n²/a²b² + D22 n⁴/b⁴)`，`H = D12+2D66` | `B=0` 且 `D16=D26=0` | **精确解（第一裁决）** |
| **CLT-Levy** | `w = Σ_n Y_n(x) sin(nπy/b)`，每阶解四阶 ODE `D11Y'''' − 2Hλ_n²Y'' + D22λ_n⁴Y = q_n`（4 个特征根 + 特解，4×4 复线性系统） | `y=0,b` 简支；`x=0,a` 简支或固支 | **独立第二裁决**（SS 分支必须与 Navier 逐位一致） |
| **CLT-Ritz** | 双三角级数能量驻值 `K W = F`，`K` 含 `D16/D26` 交叉项（`∫φ_xx φ_xy = −α_m²α_pβ_q S[m,p]S[n,q]`） | 任意对称铺层（含各向异性） | **各向异性面唯一可用解法** |
| **CLT-Ritz(clamped-x)** | 固支-固支梁函数 × 正弦 + Gauss-Legendre 数值积分 | `x` 边固支 | **Levy(CC) 的独立交叉验证** |
| **FSDT-Navier** | 逐模态 3×3 系统（`W, Φx, Φy`），`k=5/6` 剪切修正 | `B=0` 且正交各向 | **厚板修正裁决** |
| **屈曲闭式** | `N_x,cr = min_{m,n}(D11α⁴+2Hα²β²+D22β⁴)/α²`；双轴 `/(α²+β²)` | 正交各向对称 | 单轴/双轴临界载荷 |
| **屈曲特征值** | `K w = N G w`；`K` 为 SPD → Cholesky 白化得实对称 `C = L⁻¹G L⁻ᵀ`，`N_cr = 1/μ_max` | 任意对称铺层（含 `D16/D26`），纯剪同样适用 | 铺层角扫描、剪切屈曲 |

**负控（退化极限）**：

* (a) 各向同性单层（`E1=E2`、`G12=E/2(1+ν)`）→ 经典板理论常数 `0.00406 / k=4 / k=2 / k_s=9.34、5.34`；
* (b) `h/a → 0` 时 FSDT → CLT，收敛阶应为 `O((h/a)²)`；
* (c) 对称**正交各向**铺层 `D16=D26=0`；对称角铺层 `B=0` 但 `D16≠0`（见 §5.2 纠正）。

**流程图**：`铺层串 parse_layup → Lamina.qbar(θ) → A/B/D 积分 → 几何闸门 validate_plate_geometry
→ 选解法（是否正交各向/是否对称）→ Navier/Levy/Ritz/FSDT → 场量与判据`。

## 5. 注意点（坑、局限、适用范围）

### 5.1 本节点修掉的两个真实缺陷（矩阵级交叉验证发现）

| # | 缺陷 | 后果 | 发现方式 | 回归保护 |
|---|---|---|---|---|
| 1 | 纯剪几何刚度阵 `Gxy` 的 `y` 向积分表索引错位（`Sy[n,q]` 误写成 `Sy[q,n]`） | 纯剪屈曲系数偏低约 20%（方板 `k_s` 7.47 vs 9.34，长板 4.29 vs 5.34） | 用 120 点 Gauss 积分直接算二次型 `WᵀGW` 与解析阵对比（相对差 3.16，即完全对不上） | `test_shear_geometric_matrix_matches_quadrature`（<1e-9） |
| 2 | Ritz 弯曲刚度阵 `D16/D26` 交叉项漏掉 `φ_xx = −α²φ` 的负号 | 弯-扭耦合效应符号反向（±45 板的剪切屈曲载荷从「升高」变「降低」，量级差 2.3 倍） | 同上（逐元素 Gauss 积分对比，失配 0.58%） | `test_bending_matrix_matches_quadrature`（<1e-9） |

两处都是「测试绿但结果错」的类型：**单靠三方解法互相印证不够**（三者共用同一个 `K`），
必须有**对积分本质的独立数值校验**。这条经验已固化为两条常驻用例。

### 5.2 任务书两处物理表述的纠正（honest correction）

* **「对称铺层 `D16=D26=0`」不成立**：对称性只保证 `B=0`。对称**角铺层** `[±45]s`
  的 `|D16|/D11 = 0.567`（表 §3.5），弯-扭耦合依然存在。
  正确表述：`D16=D26=0 ⇔ 正交各向铺层`（cross-ply / 准各向同性）；`B=0 ⇔ 关于中面对称`。
  模块用 `is_orthotropic()` / `is_symmetric()` 两个独立判据分别记录。
* **「`[0/90]` 非对称铺层产生 `D16,D26≠0`」不成立**：0° 与 90° 铺层的 `Q̄16 = Q̄26 = 0`，
  故 `D16=D26=0`（本文算得 2.7e-19），只有 `B11, B22 ≠ 0`（拉-弯耦合，`B11/(A11h)=0.223`）。
  弯-扭耦合需要**非 0/90 的角铺层**。

### 5.3 「`[0]` 最优抗压」在屈曲意义上不成立（falsified intuition）

面内轴向刚度确实以 `[0]` 最大（§3.6），但**薄板屈曲载荷**不是面内刚度的单调函数：
单向板 `D22`、`D66` 极低，方板 `N_x,cr(0°) = 23.30 N/m` 反而低于 `N_x,cr(45°) = 31.44 N/m`。
这是薄板（`h/a ~ 1e-4`）的固有性质，不是实现问题：`[0]` 板的闭式解
`N_cr = 2π²/b²(√(D11D22)+D12+2D66)` 与特征值解一致到 1e-12（判据 C18）。
`[±45]` 抗剪优势（3.0 倍）在方板与长板都成立，可以放心引用。

### 5.4 局限与适用范围

1. **各向异性面（`D16,D26≠0`）只有能量（弱）意义下的精确解**：Ritz 试函数满足几何边界
   `w=0`，自然边界 `M_n=0` 只能以变分形式满足（Whitney 1987 讨论过该问题），
   因此各向异性板的挠度是**上界收敛的近似**，不是严格 Navier 精确解。
   收敛证据：`[±45]s` 的 `w_max` 序列 47.11(8×8) → 48.67(12×12) → 49.20(20×20) mm，
   20×20 与 14×14 差 0.8%，故 §3.5 的耦合放大系数应读作 **1.21 ± 0.02**。
2. **弯曲/屈曲解析面只接受对称铺层（`B=0`）**。非对称铺层本模块只给 `D* = D − BA⁻¹B`
   的「面内不动」等效（缺省不做全耦合的三场（`u,v,w`）求解），故 `[0/90]` 的挠度
   （1.158 m）只作量级参考，不作为验证基准。
3. **剪切修正只进入弯曲（FSDT-Navier）**；屈曲锚是 CLT 的，`h/a > 1/10` 时屈曲载荷
   同样需要剪切修正（本节点未实现 FSDT 屈曲，属明确未完成项）。
4. **无几何非线性**（von Kármán 大挠度、后屈曲）与**层间分层/损伤**；这些不在本验证面范围。
5. **材料数据为教材典型值**，未做 spline/温湿效应；横向剪切模量缺省取 `G13=G23=G12`。
6. 数值实现**不依赖 scipy**（本环境 `scipy.linalg.eigh` 会段错误），白化后全部走 `numpy`。
