# J2 Flow Theory Elastoplastic Constitutive Model

## 1. 案例介绍（物理背景）

J2 流动理论（von Mises 塑性）是金属塑性力学中最经典的本构模型之一，广泛应用于结构工程、航空航天、船舶结构等领域。本模块实现了带线性各向同性硬化的 J2 流动理论，并通过三个经典验证面进行严格校验：

### 1.1 物理背景

J2 塑性理论基于以下核心假设：
- **屈服准则**：von Mises 等效应力 `σ_eq = √(3/2 s:s)` 达到当前屈服应力 `σ_y(α)` 时发生塑性流动
- **流动法则**：关联流动，塑性应变率方向沿屈服面法向 `n = ∂f/∂σ = 3s/(2σ_eq)`
- **硬化规律**：线性各向同性硬化 `σ_y(α) = σ_y0 + H·α`，其中 α 为等效塑性应变
- **返回映射**：隐式后向 Euler 径向返回算法，保证数值稳定性和二次收敛性

### 1.2 材料参数表

| 参数 | 符号 | 典型值（结构钢） | 单位 |
|------|------|-----------------|------|
| 杨氏模量 | E | 210 | GPa |
| 泊松比 | ν | 0.3 | — |
| 初始屈服应力 | σ_y0 | 250 | MPa |
| 硬化模量 | H | 2 | GPa |

### 1.3 验证面

| 验证面 | 物理场景 | 解析解来源 |
|--------|---------|-----------|
| 单轴拉伸 | 各向同性硬化应力-应变曲线 | 双线性解析解 |
| 厚壁圆筒 | 内压作用下的弹塑性膨胀 | Tresca/von Mises 解析解 |
| 卸载路径 | 加载至塑性后卸载再加载 | 弹性卸载+历史最大应力重屈服 |

## 2. 方法实现

### 2.1 核心算法

**径向返回映射（Radial Return Mapping）**：

1. **弹性预测**：`σ_tr = C_el : (ε - ε_p)`
2. **屈服判断**：`f_tr = q_tr - σ_y(α)`，其中 `q_tr = √(3/2 s_tr:s_tr)`
3. **塑性修正**（若 `f_tr > 0`）：
   - 塑性乘子：`Δλ = f_tr / (3G + H)`
   - 更新应力：`s_new = (1 - 3GΔλ/q_tr) · s_tr`
   - 更新塑性应变：`ε_p_new = ε_p + Δλ · (3/2) · s_new/q_new`
   - 更新等效塑性应变：`α_new = α + Δλ`
4. **一致切线模量**：解析推导的算法切线，保证全局 Newton 迭代的二次收敛

### 2.2 工具链

- **语言**：Python 3.11+
- **依赖**：NumPy（数值计算）、SciPy（稀疏求解，用于 FEM 集成）
- **测试框架**：pytest（35 个测试用例）
- **可视化**：Matplotlib（应力-应变曲线、厚壁圆筒应力分布、卸载路径）

### 2.3 关键设置

- Voigt 约定：应变 `[ε_xx, ε_yy, ε_zz, γ_xy, γ_yz, γ_xz]`（工程剪应变）
- 应力 `[σ_xx, σ_yy, σ_zz, σ_xy, σ_yz, σ_xz]`
- 单轴验证使用 1D 返回映射（避免 3D 侧向约束效应）
- 厚壁圆筒使用平面应变假设

## 5. 注意点与局限

### 5.1 适用范围

- **小应变假设**：本实现基于小应变理论，不适用于大变形/大旋转问题
- **各向同性硬化**：仅支持各向同性硬化，不支持随动硬化或混合硬化
- **率无关**：本构模型为率无关塑性，不考虑应变率效应
- **等温假设**：不考虑热-力耦合效应

### 5.2 数值注意事项

- **3D vs 1D**：3D 返回映射在单轴应变条件下（仅施加 ε_xx）会产生侧向应力，因此单轴验证使用专门的 1D 返回映射
- **卸载压缩屈服**：当从较大塑性应变卸载时，应力可能穿过零点进入压缩屈服区，这是各向同性硬化的正确物理行为
- **一致切线**：算法切线模量保证全局 Newton 迭代的二次收敛，但对单步验证非必需

### 5.3 与现有代码的关系

本模块 (`tensorphysics.plasticity.j2_flow`) 与现有的 `tensorphysics.solid_fem.material.J2Material` 共享相同的物理基础（J2 塑性、径向返回映射），但：
- `j2_flow` 专注于**本构理论验证**（解析解对标、能量守恒）
- `solid_fem.material` 专注于**FEM 集成**（一致切线、单元组装）
- 两者可互补使用：`j2_flow` 提供验证基准，`solid_fem` 提供工程求解能力
