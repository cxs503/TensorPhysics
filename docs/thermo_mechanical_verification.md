# Thermo-mechanical coupling verification (thermal structural FEM)
Campaign node `p315w1-n05-fem-thermo-mechanical`, repository TensorPhysics, module `src/tensorphysics/thermo_mechanical`.
## 1. Case introduction (physics, geometry, parameters)
Three classical thermal-structural benchmarks are solved with a single thermo-elastic kernel in which the temperature field enters the constitutive law as an *initial (eigen) strain*:

```
sigma = C : (eps - eps_th),      eps_th = alpha * dT * {1, 1, 0}
```

| # | benchmark | geometry | anchor |
|---|---|---|---|
| A | bimetallic strip under uniform temperature rise | 2 layers, h1 = h2 = 1.0e-03 m, L = 0.10 m | Timoshenko (1925) composite-beam curvature + tip deflection |
| B | thermal stress concentration at a circular hole | annular plate, a = 0.01 m, b = 0.2 m (b/a = 20) | exact Timoshenko-Goodier thermo-elastic solution for a traction-free annulus |
| C | transient thermal shock of a semi-infinite solid | half-space, surface temperature step 20 degC -> 0 degC | Carslaw & Jaeger erfc similarity solution + blocked half-space thermal stress |

Bimetal parameters: E1 = E2 = 200 GPa, alpha2 = 6e-6 1/K, alpha1/alpha2 in {2, 3, 5}, dT = 100 K, nu = 0.3 (plane stress).
Hole problem: E = 2e+11 Pa, alpha = 1.2e-05 1/K, nu = 0.3, T_hole = 100.0 degC, T_outer = 0.0 degC, steady radial conduction, both edges traction free.
Thermal-shock material: k = 50.0 W/(m K), rho = 7800.0 kg/m3, c = 500.0 J/(kg K) -> kappa = 1.2821e-05 m2/s, E = 2.1e+11 Pa, nu = 0.3, alpha = 1.2e-05 1/K, T0 = 20.0 degC, Ts = 0.0 degC.
## 2. Method (solver chain, key settings, tool chain)
1. **Thermal solver** (`thermo_mechanical/heat.py`): 1-D steady/transient Fourier conduction finite elements with Dirichlet, Neumann (prescribed flux) and Robin (convection) ends, consistent capacitance matrix and theta time integration; a 2-D Q4 steady conduction solver is used for a manufactured-solution check.
2. **Thermo-elastic element library** (`thermoelastic.py`): 8-node serendipity (Q8) and bilinear (Q4) plane-stress continua with eigenstrain nodal loads `f = int B^T C eps_th dV` (3x3 / 2x2 Gauss), a composite Euler-Bernoulli frame element with layered section integration (`N_T`, `M_T` about the elastic centroid), and axisymmetric ring elements for the annulus.
3. **Bimetal** (`bimetal.py`): the Timoshenko (1925) closed form is evaluated and independently cross-checked against a modular-ratio layered-section solution (`kappa = M_T/EI`); the FE chain (frame element and 2-D Q8 continuum) solves the strip as a free-response problem (clamped root, uniform dT), curvature recovered from a least-squares fit of `eps_xx(y)` and tip deflection from the free-end nodes.
4. **Hole** (`hole_thermal.py`): steady radial conduction `T = A ln r + B` is fed to ring elements; the exact plane-stress solution is obtained by closed-form integration of `int_a^r T rho d rho`.
5. **Thermal shock** (`thermal_shock.py`): graded boundary-layer mesh, theta-method conduction with a temperature-step Dirichlet surface, then a 1-D plane-strain-blocked elasticity FE with eigenstrain; the surface is left traction free so `sigma_yy -> 0`.
6. Tool chain: pure numpy/scipy (sparse direct solves), matplotlib figures, pytest suite; the driver `scripts/thermo_mechanical_verification.py` writes the verdict JSON and this report (numbers injected programmatically).

## 5. Notes, limitations, scope
* The bimetal and shock problems are **plane stress** and **blocked (uniaxial) half-space** idealisations respectively; through-thickness gradients of real structures are not covered here.
* The hole benchmark uses a *radial logarithmic* temperature gradient in an annular plate with b/a = 20 as the infinite-plate approximation. The classical Florence-Goodier uniform-heat-flux hole solution is a different closed form and is not used.
* `K_t` is normalised by `E alpha dT`; a free plate under an in-plane gradient has no far-field mechanical stress, so no Kirsch-type nominal stress exists. The value is therefore a dimensionless thermal stress concentration, negative for a hot hole (hoop compression).
* The surface stress of the thermal shock is time independent (`-E alpha dT/(1-nu)`) and is reproduced *exactly* because the surface temperature is imposed as a Dirichlet step; the non-trivial content of criterion (d) is the depth profile agreement reported in section 3.3.
* The bilinear Q4 continuum locks in in-plane bending (measured rate 1.12); Q8 is required for quadratic convergence. This is reported as a limitation, not corrected by reduced integration.
* Time integration is the theta method (backward Euler for the reported runs) with sub-stepping (400 sub-steps on the first interval, 40 afterwards); the reported profile errors include that time-discretisation error.
* Temperature-dependent material properties (k(T), alpha(T)) and plasticity are out of scope for this node.
