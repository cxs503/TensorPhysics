## 1. 案例介绍

### 1.1 物理背景

冰区船舶船体梁同时承受两类交变应力：艏部冰挤压/破碎载荷经模态叠加传到细部（含
**whipping**，即一阶垂向弯曲模态的惯性放大），以及波浪垂向弯矩（准静态，
`DAF ≈ 1`）。工程惯例是把 `D_ice` 与 `D_wave` 分别算出再相加。上游 `m7361` 已用
25 点扫描证伪了这个加和（`D_comb/(D_ice+D_wave)` 高达 1.635，偏差在**不安全侧**），
并留下两处未闭合的机器判据：

* (b) Dirlik/TB 对雨流真值误差 ≤10 % —— 上游实测 12.6 % / 48.2 %，FAIL；
* (c) whipping 双计放大 `A` 与 whipping 份额互推偏差 ≤2 pp —— 上游实测 16.3 pp，FAIL。

本节点的问题因此是**可判定性**问题：

1. 加和律在哪些 `(r, N)` 上仍然可用？给出闭式的判定边界与误差界（判据 a）；
2. 有没有**单参数干净**的谱方法能在分离频带上达到 ≤10 %（判据 b）；
3. `m5528 "<8 %"` 这个份额口径到底覆盖哪个加载域，双计放大与份额能否自洽（判据 c）。

## 2. 怎么做的

### 2.1 单一构造 `band_case`（避免"两个 PSD 不相等"的经典坑）

`bimodal.band_case(case, n_ratio, r, wave_kind, wave_kwargs, seed, duration, fs, m)` 一次给出：

* 组合 PSD（冰带高斯带 + 波浪 JONSWAP/双峰带，同一条 rFFT 网格）；
* 谷分割 `band_split`：谷点取两峰之间的 PSD 最小值，得到 carrier（低频）与 rider（高频）两带谱矩；
* 两带 Dirlik 损伤、组合谱 Dirlik / TB / 窄带损伤；
* **同一 PSD 合成**的时程雨流真值，以及两个**分量各自**的雨流损伤（加和律的真分母）；
* 记录长度随频带比自动加长（`ratio ≥ 20` 时 ×1.5…×3），保证 N = 100 时载波仍有 ~10 个循环。

所有下游（κ 标定、判据 (a) 扫描、判据 (b) 基准）都调用它，**不存在第二套 PSD 定义**。

### 2.2 先验声明（动手前定，事后不改）

| 判据 | 阈值 | 判读方式 |
|---|---|---|
| (a) 线性叠加 | `ρ ∈ [0.97, 1.03]`，在 `f_ice/f_w ≥ 10` | 逐点判；不满足则给非线性律 + 机理 |
| (a) 替代律 | 两带 riding 闭包误差 ≤10 %（全 3 谱宽 × 4 频带比） | 本节点新增 |
| (b) 谱方法 | Dirlik / TB / 两带闭包 ≤10 %，3 档谱宽 | 逐档逐比判 |
| (c) whipping | 准静态域内 `份额 < 8 %` 且峰值口径互推 ≤2 pp | 域定义见下 |
| (d) 可交换性 | 分段/闭合块重排 ≤1e-9 | 另设朴素反例 |
| (e) 负控 | 关波浪退化到 m5528，≤2 % | 15 量逐项 |

**两条先验声明（本节点的偏差与理由，属方法自主权声明）**：

1. **两带闭包的切换点 `N_SEPARATED = 5`**：取自 `tensorphysics.fatigue.spectral`
   模块文档已有的分离判据（Torhaug 1990 / Jiao & Moan 1990，`f2/f1 ≥ 5`），**不是拟合**；
   `N < 5` 时两带不构成两族循环，退回组合谱 Dirlik。
2. **(c) 的加载域由两个无量纲量定义**：`θ = τ_transition/T1`（跃变时间 / 一阶周期）
   与 `j = max|ΔF|/max F`（载荷最大单步跳变 / 峰值）。准静态 ⟺ `j ≤ 0.02 且 θ ≥ 0.5`。
   这两个阈值也是先验的（j 的门限取"无台阶过渡"，θ=0.5 取"跃变慢于半个模态周期"）。
   共振带 `f_load/f1 ∈ [0.8, 1.25]` **事先排除**（那里残差就是全信号，`share_rms > 1`，
   幅值口径无定义）。

### 2.3 工具链与实验设计（两级 + 标定/验证分离）

* **Level A（受控叠加）**：两个零均值限带高斯分量直接相加 → 雨流真值 → `ρ`、`κ`；
  种子 3–6 个，标准差一并报告。
* **κ 标定集**：`N ∈ {5,10,20,50,100}` × `r ∈ {0.15,0.25,0.35,0.5,0.7,1.0,1.5}` × 3 种子 = 35 点，
  谱宽固定 JONSWAP γ=3.3。
* **验证集（判据 b）**：3 档谱宽（含 γ=6、双峰 r_p=3）× 4 个频带比 × 3 种子，
  **谱宽与 r 均与标定集不同**（`r = N^{-1/3}` 只落在栅格之间）。
* **whipping 域扫描**：3 个平滑谐波 + 5 个 DEM 时基拉伸（同一波形，时间尺度 ×1…×40）。
* **判据 (d)(e)** 直接调用上游已验收实现（`segmentation_invariance`、`m5528_reproduction`），
  不复制代码。
* 环境/种子/记录长度/采样率/git commit 全部写入 `results.json`。

### 2.4 核心公式

带谷分割后：

```
D_comb ≈ D_rider + κ(r, N) · D_carrier ,   r = σ_rider/σ_carrier ,  N = f_rider/f_carrier
κ(r, N) = 1 + A N^b r^p / (1 + C N^c r^q)                  （两带闭包，本文律）
A = 1.1971, b = 0.3947, p = 1.3565, C = 1.0e-3, c = 1.2182, q = 0.0500
```

`ρ` 与 `κ` 的关系（**可判定性**的来源）：

```
ρ = D_comb/(D1+D2) = (1 + κ·D_carrier/D_rider) / (1 + D_carrier/D_rider)
⇒ 加和律可用 ⟺ |κ(r,N) - 1| ≤ tol·(1 + D_carrier/D_rider)
```

纯理论 riding 卷积锚（**不作闭包用**）：

```
κ_anchor = E[(R + |x_max| + |x_min|)^m] / E[R^m] ,  R ~ Rayleigh(√2 σ_c)，|x| ~ Rayleigh(σ_r)
          ⇒ m = 1 时 κ = 1 + √2 r（闭式，pytest 钉住）
```

  +39~45 %），只与 `r` 与 `N` 的乘积结构有关，由 κ 闭包定量表达。

* **c1（准静态域内互推 ≤2 pp）PASS**：两个准静态工况峰值份额 1.48 % / 5.74 %（< 8 %），
  `A` = 1.000 / 1.000，峰值口径偏差 **0.018 pp**。这就是 m5528 下 `<8 %` 结论的**有效域**。
* **c2（`<8 %` 不可外推到脉冲列）PASS**：DEM 挤压 `share_peak = 35.1 %`；
  即使把时间基拉伸 **40 倍**（θ = 3.35，早已慢于模态周期）份额仍是 **25.8 %**。
  机理**可测**：DEM 力的**单步跳变占峰值 27.0 %**（`residual_ratio` 不同的相邻事件在
  事件切换处形成台阶，其幅度不随时间基缩放）→ 任何拉伸都不能消除 whipping 激励。
  **结论：m5528 的 `<8 %` 是"光滑加载"的表述，降阶 DEM 的 35 % 是 DEM 台阶的模型属性，
  不能当作慢速冰载荷的真实 whipping 水平；DEM 也不能用来验证 whipping 份额。**
* **c3（口径排序）PASS**：损伤口径 `A = 1 + D_residual/D_true` 恒等式成立（误差 ≤1e-9）；
  峰值/RMS/力矩三个幅值口径在准静态域外**全部**超 2 pp（最大 99.4 / 4607 / 51.1 pp）。
  即：**份额→放大倍数不存在通用映射**，只有损伤口径可全域使用。

与上游一致性：本节点用上游 m7361 的"份额差"度量复算，最大偏差 **16.41 pp**，
与 m7361 报告的 16.3 pp 吻合（同一物理事实的两种度量）。

### 3.4 加和律的可判定边界（判据 a 的"误差界"部分）

`ρ − 1 = (κ−1)/(1 + D_carrier/D_rider)`，等分量损伤（比值 = 1）时求 ±3 % 的 `r` 上界：

| N | 2 | 3 | 5 | 10 | 20 | 50 | 100 | 200 |
|---|---|---|---|---|---|---|---|---|
| `r_max`（±3 %） | 0.0828 | 0.0753 | 0.0678 | 0.0527 | 0.0452 | 0.0377 | 0.0302 | 0.0302 |

工程含义：**riding 幅值必须小到 carrier 的 3–8 % 以下**，加和律才在 ±3 % 内；冰区实船
（`r ≈ 0.8–1.3`）远超此界。判定式 `|ρ−1| ≤ tol` 只需两条带谱矩 + `κ(r,N)`，**无需时域计数**。

## 5. 注意点（踩过的坑，按代价排序）

1. **"两带损伤相加"比单峰 Dirlik 更糟**（−37.4 % vs −11~14 %）：加和律的失效不是谱方法的
   细节，而是**漏掉了 riding 对 carrier 跨距的放大**。任何不加 κ 的分带方法都会低估 30 % 以上。
2. **纯理论 riding 卷积不能当闭包**：`m=1` 精确（`1+√2 r`），`m=3` 在 `r≈0.5` 高估 62 %。
   原因是它同时保留"放大后的 carrier 循环"和"全部 riding 循环"——双计的另一种写法。
   用它替代 κ 会让判据 (b) 变成 +231 %（prototype 实测），必须用标定闭包并如实标注半经验。
3. **κ 的方向不是单调的**：固定 r，κ 在 `N ≲ 20` 随 N 增长、`N ≳ 50` 又回落（r 大时回落更早）。
   单参数幂律 `κ = 1 + a r^b N^c`（上游 m7361 的形式）在 `r > 1` 处会无界外推；本节点的
   有理式闭包在角点 `r=1.5, N=50` 仍有 **−10.2 %** 残差（见局限），不要外推到 `r > 1.5`。
4. **记录长度是 N = 100 的隐性误差源**：`f_carrier = 0.0043 Hz` 时 1200 s 只有 ~5 个
   carrier 循环，ρ 的种子标准差 7–10 %。本节点把 `ratio ≥ 20` 的记录加长到 3× 才把
   标准差从 16 % 压到 7 %；再长的记录会更平滑，但趋势不变。
5. **峰值份额与损伤份额可以差三倍**（DEM 挤压：峰值 35 %、RMS 78 %、损伤放大 `A−1 = 1.15`）。
   用峰值份额论证"whipping 误计入只影响 15 %"会把风险低估近一倍（实测 2.15 倍）。
6. **DEM 的力台阶是 whipping 份额的地板**：`max|ΔF|/max F = 27 %`，与时间基拉伸无关。
   这是降阶 DEM 的模型属性；任何用该 DEM 反推"慢速冰载荷 whipping 水平"的做法都会
   得到 ~26 % 的假地板。
7. **共振带必须事先排除**：谐波加载在 `f_load ≈ f1`（本节点实测 1 Hz）时残差就是全信号
   （`share_rms = 4.43 > 1`），幅值口径失去定义；排除是**先验声明**的，不是事后剔除。
8. **同一条 PSD 是公平比较的前提**：谱矩必须在合成时程用的同一 rFFT 网格上积分，
   否则 Dirlik 的 `ν_p = √(m4/m2)` 会把截断误差算成方法误差。

## 8. 局限与适用范围

* **κ 闭包是半经验的**：6 参数在 Level-A 雨流网格（`N ∈ [5,100]`，`r ∈ [0.15,1.5]`，
  JONSWAP γ=3.3，载波为单峰波浪带）上标定；对 `r > 1.5`、`N < 5`、载波本身为强双峰
  （本节点 `wide_bimodal_rp3` 档）只在验证集上被检验过（误差 ≤4.7 %），**不外推**。
* **两带切换点 N = 5 是声明值**：`N ∈ (3.5, 7)` 的过渡带内两种分支差异可达数 %，
  该区间不建议用于设计。
* **判据 (c) 的结论是"域受限通过"**：准静态域内互推 0.018 pp；域外的幅值口径偏差达
  数十 pp，只有损伤口径可用。这是对上游 FAIL 的**解释**而非覆盖。
* **DEM 不能用于 whipping 份额的物理验证**（力台阶 27 %）；三分量/多轴、
  厚度方向裂纹、焊缝细节分类、低温脆断、共振带（`f_load/f1 ∈ [0.8,1.25]`）均未建模。
* **波浪绝对幅值未声明**（等损伤/等 RMS 归一化），受影响的只是 ρ 的绝对位置；
  律的形式由 `(r, N)` 决定，不依赖幅值标定。
* **单轴名义/热点应力法**：不含多轴临界面、不含缺口应力梯度。
