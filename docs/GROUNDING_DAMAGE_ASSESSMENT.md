# 冰区船舶搁浅损伤评估：冰脊/浅滩搁浅的板格塑性变形 + 舱室进水 + 残存稳性

*生成时间*：2026-11-10T09:02:16Z  
*战役节点*：p247w1-N02（TensorPhysics，物理域）

## 1. 案例介绍（物理背景 / 几何 / 参数）

冰区船舶在冰脊或浅滩上搁浅时，船底外板在刚性冰脊龙骨或沙质海床上被挤压，
板格以**膜应力**为主吸收动能；当等效塑性应变达到材料失效应变时板格撕裂，
形成破损开口，海水经开口涌入舱室，导致浮力损失与 GM 退化，最终由残存 GZ 曲线
与 IMO 破损稳性判据裁决。本节点把这条链路做成可复算的模型链。

| 对象 | 参数 |
|---|---|
| 船（Polar 15 000 DWT） | L = 148.0 m, B = 23.0 m, T = 8.60 m, Cb = 0.760, KG = 7.60 m |
| 板格 | a × b × t = 3.60 × 0.90 × 22.0 mm，σ_y = 355 MPa，ε_f = 0.18 |
| 材料 | NV-FH36 船体钢，E = 206 GPa，ν = 0.3，E_t = 1.0 GPa，各向同性硬化 |
| 冰脊 | 刚性楔形龙骨，h_ridge = 4 m，坡角 α = 12°，接触长度 30 m |
| 浅滩 | 弹性沙床 p = min(k_s δ, q_ult)，k_s = 200 MN/m³，q_ult = 1.0 MPa |

## 2. 怎么做的（方法 / 流程 / 关键设置）

链路（模块→物理）：

1. **接触力学** `contact.py`：`HertzContact` 用 Love 均匀圆压解析解构造环平均柔度矩阵，
   以 Signorini 主动集求解球-半空间接触；`RidgeGeometry`/`RidgeContact` 把刚性冰脊楔形
   龙骨映射为船底各板格局部压入深度 δ(y) = max(0, δ_apex − |y| tanα)，接触压力由板格
   阻力曲线给出（非线性 Winkler 基础）；`ShoalContact` 为沙床弹性模型。
2. **板格大挠度弹塑性** `panel.py`：von Karman 板理论，w 用固支余弦基、u/v 用不可移边
   正弦基的 Ritz 离散，厚度方向分层 J2 平面应力返回映射（子增量积分），路径相关累积 ε_pl；
   接触压力由虚功（Rayleigh 商）从当前弹塑性应力状态提取。
3. **损伤判据** `damage.py`：ε_pl ≥ ε_f 即撕裂（单元删除语义），计入撕裂面板比例得到
   破损开口面积 A_damage；同时校核纵骨腹板剪切屈曲、面板屈曲与塑性弯曲。
4. **进水** `flooding.py`：Q = C_d A √(2gΔh) 显式积分 + 增重法下沉耦合，得到平衡进水量；
   内底被穿透（δ_apex > 双层底高度）时货舱进水，否则仅双层底进水。
5. **残存稳性** `stability.py`：剖面多边形与自由液面平面求交（Sutherland–Hodgman），
   鞋带公式求体积/浮心，自由漂浮平衡同时满足体积与纵倾力矩；KN = y_B cosθ + z_B sinθ，
   GZ = KN − KG_eff sinθ（含自由液面修正）。
6. **参数扫描** `scenario.py`：V ∈ [1,5] kn，h_ridge ∈ [2,6] m，α ∈ [5°,20°]。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **板格弹塑性阻力采用固定剖面（Rayleigh 商）估计**：变形剖面取自几何非线性弹性解并在
   挠度路径上插值，弹塑性应力状态按子增量返回映射真实累积。弹性/初塑性区与 FEM 吻合
   （+3.3% @ w/t≈0.19），但深入塑性区
   低估板格承载（FEM 对比见 3.1 的负号/正号方向）——即高估压入深度与损伤，偏保守。
   这是本模块最主要的局限，已如实登记。
2. **冰脊按刚性处理**（节点规定）：真实冰脊会被压碎并分担能量；`RidgeGeometry.crushing_pressure`
   预留了冰压溃能量项（本次算例为 0），用于敏感性研究。
3. **进水为准静态 + 增重法**：忽略了破口处的瞬态射流、舱室间流动与空气垫效应；
   自由液面修正仅在舱室部分充液时计入（满舱无自由液面），符合常规做法。
4. **残存稳性只计横倾（自由纵倾由平衡方程自动求解），未做破舱破口位置的概率组合**：
   即单一确定性破损场景，不是 SOLAS 概率破损稳性的 A 指数计算。
5. **应变失效判据为常数 ε_f**：未计入应力三轴度、网格尺寸效应与低温韧性转变；
   对极地钢（-50 °C）应通过 Charpy/CTOD 数据标定 ε_f。
6. **h_ridge 在刚性冰脊假设下不影响结果**（扫描表按 h_ridge 分组结果相同）：压入深度由能量平衡决定，只要 h_ridge 大于该深度，冰脊高度只起上限作用；这本身是一个可检验的模型推论——若计入冰的压溃，h_ridge 会通过压溃能量重新进入结果。
7. **FEM 参考解**为仓库内独立实现（Q4 膜 + Hermite 弯曲壳单元，弧长法），
   通过约束补丁把面内边界改为不可移以与本模型边界条件一致；网格 14×4 为节省时间所用，
   与 24×6 网格的差异约 1.7%。
